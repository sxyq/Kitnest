# 压缩图片

## 用来做什么

缩小图片长宽、调整画质或转换保存格式，生成一份更适合发送和放进文档的图片。

## 从哪里打开

在主面板搜索框输入「/tinypng」，选择界面中名为「TinyPNG」的图片压缩工具。

## 怎么用

1. 点击「选择图片」，打开要处理的图片文件。
2. 在「最长边」选择尺寸，在「输出格式」选择 JPEG 或 PNG；JPEG 可另调「JPEG 质量」。
3. 点击「执行」，查看图片预览和处理前后的文件大小。
4. 在结果的「输出文件」一行找到新文件位置，打开后使用。

## 使用小提示

JPEG 适合照片，PNG 适合需要透明背景的图片。处理后是否变小取决于原图和所选格式，可根据结果重新调整；「复制结果」复制的是大小和位置说明。
