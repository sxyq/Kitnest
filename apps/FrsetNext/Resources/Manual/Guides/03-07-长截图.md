# 长截图

## 用来做什么

把需要向下滚动才能看完的网页或长列表接成一张图片，方便一次保存和分享。

## 从哪里打开

在截图操作条中选择「长截图」，或使用「设置 → 快捷键 → 全部功能绑定」里设置的「长截图」按键。

## 怎么用

1. 打开目标页面并启动长截图，拖出覆盖正文的选区。
2. 在选区内缓慢滚动页面，让前后画面保留部分重复内容。
3. 到达需要的末尾后点击「完成」。
4. 查看拼接结果，确认内容连续，再点击「保存」。

## 使用小提示

固定侧栏或悬浮按钮会被重复拼进图片，尽量只框选正文。采集过程中可取消本次操作，再重新选择范围。
