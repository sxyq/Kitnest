## 这项功能能做什么

把几张截图收在屏幕边上，需要时再展开查看或拖给其他应用。

## 打开位置

先在「设置 → 截图与录屏 → 图帘」启用，再右键点击菜单栏 Kitnest 图标选择「图帘」。

## 操作步骤

1. 截图后，在操作条选择「挂到图帘」。
2. 打开图帘，点击卡片复制图片，或将卡片拖到其他应用。
3. 在卡片上选择保存、钉图或移除。
4. 想让新截图自动加入时，在图帘设置中启用「自动上架」。

## 提示

按住 Command 并滚动，可调整图帘显示大小。
