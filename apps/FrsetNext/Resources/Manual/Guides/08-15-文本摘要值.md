# 文本摘要值

<!-- demo: tools -->
<!-- symbol: number -->

## 用来做什么

为文字生成一串固定长度的摘要，便于比对两段文字是否一致。

## 从哪里打开

搜索框输入「/sha」，选择「哈希生成」。

## 怎么用

1. 输入需要计算的文本。
2. 选择 MD5、SHA1 或 SHA256。
3. 点击「执行」，查看生成的摘要值。
4. 点击「复制结果」，与另一份结果比对。

## 使用小提示

计算前会去掉文字首尾的空格。摘要只能用于比对，不能加密或还原原文；选择 SHA256 即可。
