# 暂停记录与隐私

## 用来做什么

暂时不保存新复制的内容，或设置不记录哪些应用里的复制内容。

## 从哪里打开

右键点击 Kitnest 图标，展开「暂停记录剪贴板」；长期选项位于「设置 → 剪贴板 → 捕获与隐私」。

## 怎么用

1. 复制敏感内容前打开暂停菜单。
2. 选择暂停 5、15、30 分钟，或暂停至手动恢复。
3. 查看主面板中的暂停提示，确认记录已停止。
4. 准备继续时，点击「立即恢复」。

## 使用小提示

暂停只影响之后复制的内容，不会删除已有记录。需要清理旧记录时，到「历史与备份」处理。
