## 用来做什么

查找让电脑持续忙碌的应用。CPU 就是电脑负责执行计算的处理器，使用率越高，表示它当前承担的工作越多。

## 从哪里打开

右键点击菜单栏 Kitnest 图标，选择「性能监测…」，再选「CPU」。

## 怎么用

1. 先读「系统」「用户」「空闲」三项，了解电脑总共忙到什么程度。「用户」主要对应你打开的应用，「系统」对应 macOS 本身的工作。
2. 看「核心占用」：每根小柱代表处理器里一个能分别工作的部分，可以看出任务是否集中在少数几处。
3. 往下找到「CPU 占用进程」，按应用名称辨认占用较高的项目；展开应用可看它所属的其他项目。
4. 回到对应应用，暂停不需要的任务或保存后退出，再观察 CPU 数字和曲线是否下降。

## 使用小提示

打开大型文件或导出视频时，短时间升高很常见。「平均负载」显示正在执行或等待的任务情况，读法与百分比不同；想找具体应用，优先看占用列表。
