## 用来做什么

JSON 是应用常用的一种数据文字格式，用括号、名称和值排列内容。工具可把它整理成分行缩进的样子，或压成紧凑的一段。

## 从哪里打开

在主面板搜索框输入「/json」，选中「JSON」工具并按回车。

## 怎么用

1. 粘贴完整的数据文字，包括最外层括号。
2. 在「操作」选择「格式化」便于阅读，或选择「压缩」去掉多余空白。
3. 点击「执行」，下方会显示整理结果；输入有问题时会出现错误提示。
4. 整理成功后点击「复制结果」，粘贴到需要它的地方。

## 使用小提示

普通文章不能直接作为 JSON 整理。报错时先查看原内容是否复制完整，尤其是括号、引号和逗号。
