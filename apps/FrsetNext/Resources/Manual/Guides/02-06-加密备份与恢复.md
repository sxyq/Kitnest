# 加密备份与恢复

<!-- symbol: lock.doc -->

## 用来做什么

用密码保存剪贴板资料，并把备份恢复到本机。

## 从哪里打开

「设置 → 剪贴板 → 历史与备份」中的「加密备份…」和「恢复备份…」。

## 怎么用

1. 点击「加密备份…」，输入密码并选择保存位置。
2. 阅读附件缺失提示，选择备份完整记录后等待完成。
3. 需要恢复时点击「恢复备份…」，选择备份并输入密码。
4. 读取完成后选择合并或替换，处理重复资料的取舍。
5. 点击「确认恢复」，完成后打开历史查看资料。

## 使用小提示

替换会覆盖本机剪贴板历史、笔记和标签。请保存好备份密码。
