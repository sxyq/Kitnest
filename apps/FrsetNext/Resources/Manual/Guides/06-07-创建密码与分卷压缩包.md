# 压缩包设密码和拆分

## 用来做什么

把多个文件装进一个压缩包，可设置密码；大文件也可拆成多个较小的压缩包。

## 从哪里打开

在访达选中文件，右键选择「服务 → 用 Kitnest 压缩」；也可从刘海工作台「压缩与解压 → 创建压缩包」选择文件。

## 怎么用

1. 选好文件，打开创建窗口并选择格式。
2. 确认压缩包名称和保存位置。
3. 需要密码时开启密码保护并输入密码；7z 还可隐藏包内文件名。
4. 要拆成小包时开启「分卷」，并填写每个小包的大小。
5. 点击「开始压缩」，等待完成。

## 使用小提示

「TAR.GZ」格式不支持密码和拆分。拆分后发送时要把所有小包放在一起，解压时缺少任何一份都无法还原完整内容。
