# 创建密码与分卷压缩包

## 用来做什么

把文件压缩为 ZIP、7z 或 TAR.GZ，按需要添加密码或拆成多卷。

## 从哪里打开

访达选中文件，右键「服务 → 用 Kitnest 压缩」；刘海工作台「压缩与解压 → 创建压缩包」也可选文件。

## 怎么用

1. 选好文件打开创建窗，选择用途预设。
2. 确认文件名、保存位置、格式和压缩强度。
3. 需要加密时启用密码保护并输入密码；7z 还可勾选加密文件名。
4. 需要分卷时启用分卷压缩，填写每卷大小。
5. 点击「开始压缩」，或将进行中的任务转到后台。

## 使用小提示

TAR.GZ 不支持密码和分卷。ZIP 只加密内容；隐藏文件名请选择 7z。分卷文件应放在同一目录并完整发送。
