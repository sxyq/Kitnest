# 30-测试

测试文档按**实际功能和使用场景**组织。重点区分四类状态，每份测试材料标注属于哪类：

| 状态 | 含义 |
|---|---|
| **已有测试方法** | 有可重复的测试步骤/脚本，但未必在本次执行过 |
| **已执行** | 真实跑过，有结果记录（日期 + 环境 + 结果） |
| **未执行** | 场景已识别但没有真实运行证据 |
| **真机结果** | 在真实设备上运行的截图/日志/数据 |

> **源码存在和编译通过不等于实际 UI、动画、触觉反馈或截图行为已验证。**
> 界面/交互类结论必须有真机截图或录屏支撑，引用 `截图/` 或 `assets/screenshots/` 的实证。

### `录屏/` 三份素材的拍法与口径

全部用 `screencapture -l <窗口id> -V <秒>` **只录目标窗口**，录制期间没有移动系统光标、没有切换前台 app：

| 文件 | 内容 | 拍法说明 |
|---|---|---|
| `2026-11-23-神灯漏斗-2.5s慢放.mov` | 面板被吸入菜单栏的漏斗形变（含面板快照贴图） | 临时 `defaults write … probe.genieDuration 2.5` 慢放 6.6 倍才录得到（真实 380ms 短于录制启动）；同一套帧序列/形变，仅时长不同，录完已删该键 |
| `2026-11-23-存储液态悬停-下钻Users-返回.mov` | 脚本化悬停巡航 → 下钻 Users（单子项提示）→ 返回根 | 悬停由 `probe.storageHover` 定时器驱动压力中心，走同一条压力场与 0.26/0.86 弹簧；下钻/返回走 `kitnest://storage?drill=` 深链 |
| `2026-11-23-存储液态悬停-下钻Applications.mov` | 悬停巡航 → 下钻 Applications（多图块，可见邻块被挤压） | 同上 |

> 悬停与目录切换的**输入源**不是真实鼠标（自动化不得抢用户光标），但**形变/回弹/导航本身**是产品代码真实执行的结果；真实鼠标手感仍需人工确认，已在变更记录标注。
