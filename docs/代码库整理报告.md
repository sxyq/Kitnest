## 5. 模块契约审计（跨模块引用）

项目纪律（CONTRACT）：Feature 模块之间经 `ServiceLocator` / 通知通信，不直接引用具体类型。粗查结果：

| 引用 | 形式 | 评价 |
|---|---|---|
| Monitor(StatsBarEngine) → Panel | `ServiceLocator.panel` ✅ | 合规 |
| Capture → 面板预览 | `ServiceLocator.panelPreview` ✅ | 合规 |
| Clipboard → 预览 | `ServiceLocator.panelPreview` ✅ | 合规 |
| Panel 预览 → Capture 标注 | 通知 `frset.clipboard.editImage` ✅ | 合规 |
| **Panel(PanelRootView 预览探针) → ClipboardManager** | **直接引用** ⚠️ | 排障代码，应改为发通知由 Clipboard 侧响应 |
| **TransferDock → Storage(ClipboardFileStore)** | Storage 属 Core 层 | 合规（Core 允许） |

> 结论：正式路径全部合规；唯一违例是排障探针，属已知妥协，建议用通知化收尾。
