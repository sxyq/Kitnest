## 3. 五个探明问题

### ① 自动滚屏驱动（Q1）
**不合成滚动**。`nm -u` 全量导入符号中无 `CGEventCreateScrollWheelEvent`、`CGEventPost`、`CGEventSetIntegerValueField`、AX Set 系、osascript/NSAppleScript（已逐一 grep）。唯一的 `CGEventPostToPid` 调用点 0x10014e3f8 是划词/快捷键的按键转发（keyCode 0x8/0x9），与长截图无关。
真实机制 = **NSEvent 全局监视器三件套**（`NSEvent.addGlobalMonitorForEvents(matching:handler:)`，选择器经 msgSend$ stub **0x100944920 = `addGlobalMonitorForEventsMatchingMask:handler:`**（/tmp/re14/stubs.py 解析实证））。全局监视器只观察不拦截——与被动采帧模型自洽；**keyDown 全局监视需输入监控/辅助功能权限**（与 docs/10-规格/17 权限引导衔接）：

| 掩码 | 事件 | 注册点 | 处理 |
|---|---|---|---|
| `0x400000` | scrollWheel | 0x100445e98（w2=0x400000） | Δ 过滤+累积+去抖调度（0x100446158） |
| `0xe0` | mouseMoved+左右拖拽 | 0x10045aa14 | 光标在选区内→调度捕获（0x1004461c0 区段，`CGRectContainsPoint` @0x100462 4c） |
| `0x400` | keyDown | 0x10045b1cc | keyCode==0x35(Esc)→主队列取消（0x10045b494） |

- 滚动量累积到 session+0xd0（double），反射字段实证：`scrollingDeltaY/X`（0x100b220b1/0x100b24f48）、`scrollingDeltaEpsilon`（0x100af9020，**=0.08**，0x1004395ec 三轴 fcmp）、`hasPreciseScrollingDeltas`（0x100b304ef）、`pendingAutoScrollWorkItem`（0x100af7220）、`autoScrollsToBottom`（0x100af72a0）。
- **节奏**：事件批间去抖 `DispatchTime.now() + 0.055`（0x3faeb851eb851eb8 @0x100446794）→ WorkItem 派发到串行队列；同一时刻仅一个 pending（[session+0xa0] 去重 @0x10044665c-0x100446764）。tick 本体再经 DispatchQueue.main.async → 捕获队列。
- 启动时另传入 (40_000_000 ns, 30_000) 常量对（0x10045a954→0x100436868，结果存 session+0x60）⬜ 精确语义未定（疑为异步循环的 sleep/超时参数）。

### ② 帧采集与拼接对齐算法（Q2 = 待查#4）
**采集原语 0x10045ae30**：
```
capture(displayID: x0, reqWidth: d0, reqHeight: d1, ctx: x1, windowID: w2, …):
  bounds = CGDisplayBounds(displayID)                    // v0-v3
  img = CGWindowListCreateImage(bounds, option=0x14, windowID, imageOption=8)
       // 0x14 = IncludingWindow|ExcludeDesktopElements；8 = BoundsIgnoreFraming（枚举名系推断⬜）
  scale  = imgWidth / reqWidth;  scaleH = imgHeight / reqHeight
  rect'  = 选区(rect 从 ctx+0x38 读) ∩ (img 尺寸换算)
  return CGImageCreateWithImageInRect(img, rect')
```
（对照 ScreenshotManager 直屏路径 0x1003a2c2c：option=1/OnScreenOnly + windowID=0 + imageOption=8。）

**对齐流水线**（全部使用 DeviceGray 8bpp 位图签名，`CGBitmapContextCreate(bps=8, DeviceGray)`）：
1. **恒等判定** 0x100436cf0：签名宽 = min(imgW, **512**)；`meanAbsDiff(a,b) < 2.5`（@0x100436da8）→ 视为画面未变，丢弃本帧。
2. **对齐签名** 0x100436dfc：签名宽 = min(imgW, **128**)（@0x100436e0c-0x100436e14）。
3. **相似度** 0x100456650：逐字节 `|a-b|` 累加取均值；2D 分支**行、列均步长 2 抽稀**（adds #2 @0x10045677c/0x1004567a8）。
4. **搜索** 0x100458b10：粗搜步进 24 行（umulh ÷24 @0x100458c68-0x100458c74），搜索上界 = **0.12 × 高度**（0x3fbe-b851-eb85-1eb8 = 0.12 @0x100458b54-0x100458b64）；另有**动态搜索带** = min(|累计δ|×scale×4 + 24, **64**) 行（@0x100447814-0x100447878，0x40=64 钳制）。
5. 辅助：0x1004431b0（内容边缘/留白量测）、0x1004432a4（谓词判定）、0x10045965c（精细搜索）、0x1004571d0（候选分类，返回枚举 0/2/3；2=放弃 0x1004370c0，3=完成）。
6. **最小新内容**：可确认新行 < **15**（0x100436fd4 `cmp x25,#0xf; b.le`）/< **16**（0x1004372c0 `cmp x8,#0x10; b.lt`）→ 不追加（等待继续滚动）。**最小重叠 2 行**（@0x100437044 `mov w9,#2; csel`）。
7. **合成**：画布规范化 0x100443340（裁剪→重绘 RGBA8888 `bytesPerRow=w*4`，interpolation .low/#0x1）。

**与重建版（apps/FrsetNext/Sources/Features/Capture/LongScreenshot/Stitcher.swift）逐项对比**：

| 维度 | 原作 | 重建版现状 |
|---|---|---|
| 触发 | 用户滚动+事件驱动，逐帧追加 | 用户手动提供多图一次性拼接 |
| 签名 | DeviceGray 8bpp，宽 128（恒等判定 512） | RGBA 行平均色 |
| 相似度 | 抽稀(步长2)平均绝对差（meanAbsDiff） | 行平均色差（同「平均绝对差」家族，等价降级） |
| 恒等帧 | <2.5 丢弃 | 无（多图模式不需要） |
| 搜索范围 | 动态带 min(24+4\|δ\|scale,64)，上界 0.12×h，粗搜步 24 | 2%~60% 全枚举贪心 |
| 最小重叠/新内容 | 重叠≥2 行；新内容<15/16 行不追加 | minOverlap=max(2, 2%) |
| 阈值 | 2.5（恒等）+ 动态带 | diffThreshold=22 |

### ④ 预览窗与编辑器（Q4）
- **编辑器布局**（已实证的片段）：`LongScreenshotEditorDocumentView` 初始**居中**且尺寸钳制——`size = min(请求尺寸, scrollView 可视尺寸)`，超限时 `setFrameSize` 后 `setFrameOrigin((fw-vw)/2, (fh-vh)/2)`（0x10044cdbc-0x10044ce74，0.5 常量 @0x10044ce40）。`LongScreenshotImageScrollView`/`EditorWindowController` 均有标准 Swift NSView/NSWindowController 骨架（init(coder:) fatalError 0x10044c060/0x10044cd00）。
- 工具集（裁剪/标注按钮/保存去向）⬜：编辑器文案全部走 .lproj（二进制仅英文键），工具项清单未能从反汇编可靠枚举。已知入口链：截图标注工具条 →「长截图」按钮 → 确认框（键 `Clear Annotations`）→ 启动会话。
- 会话收尾产物进入预览/编辑器（LongScreenshotPreviewController/Model），具体呈现 ⬜。

### ⑤ 与截图体系的复用（Q5）
- 采帧原语与 ScreenshotManager 直屏捕获共用 `CGWindowListCreateImage` 家族（对照 0x1003a2c2c），但长截图有独立封装（displayID+windowID+交集裁剪）。
- 入口在标注编辑器工具条（0x1003c3280 区段调用会话启动 2 处：0x1003c34c4/0x1003c3678——分别对应「无标注直接开始」与「清标注后开始」两分支）。
- WhatsNew 实证 1.3.12 本轮改动：`优化截图性能，提升长截图拼接效果。`（0x100b57360 → 引用 0x10077a330）。

## 4. 拼接算法伪码（重建实现建议）

```swift
// ===== 原作等价伪码（地址见 §3②） =====
final class LongScreenshotStitcher {           // ObjC 可见: _TtC5Frset22LongScreenshotStitcher
    static let epsilon = 0.08                  // scrollingDeltaEpsilon
    static let identityThreshold = 2.5         // 512 宽灰度 meanAbsDiff
    static let minOverlapRows = 2
    static let minNewRows = 15                 // 追加门槛（另一处 16）
    static let searchFraction = 0.12           // 上界: 0.12 × h
    static let coarseStep = 24

    func graySignature(_ img: CGImage, width: Int) -> [UInt8] // 0x1004564b4 (DeviceGray, .high)
    func meanAbsDiff(_ a: [UInt8], _ b: [UInt8], w: Int, h: Int) -> Double // 0x100456650, 步长2抽稀

    func append(frame: CGImage, pendingDelta d: Double, scale s: Double) {
        // 1) 恒等剔除
        if meanAbsDiff(gray(frame, 512), lastSig512) < 2.5 { return }        // 0x100436cf0
        // 2) 动态搜索带
        let band = min(Int(abs(d) * s * 4.0) + 24, 64)                       // 0x100447814-78
        // 3) 粗搜 + 精搜（128 宽签名）
        var best = searchCoarse(band: min(band, Int(0.12 * Double(h))), step: 24) // 0x100458b10
        best = searchFine(best)                                              // 0x10045965c
        // 4) 追加判定
        let newRows = frameH - best.overlap
        guard newRows >= minNewRows else { return }                          // 0x100436fd4
        // 5) 合成
        canvas.draw(frame, at: y - best.overlap)                             // 0x100443340 规范化 RGBA
    }
}
```
