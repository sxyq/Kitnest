# 03 - 规格：监测区与状态栏（M1 直用）

> 目标：Frset 现有轻量监控（5 项）→ Stats 完整体系（10 模块）+ 状态栏 SWidget 化。
> 上游：`frset/性能监测集成规划-v2.md`（信息架构定稿）＋ 01 号文档 §2/§16。

---

## 1. 范围与类清单

### 1.1 现状类（将被替换/升级，归属 191 类清单）
| 类 | 职责 | 处置 |
|---|---|---|
| `StatusBarController` | 主状态项（Item-0）管理 | **保留**（入口不变） |
| `MenuBarMetricsStatusBarController` | 网速/内存/SSD 状态项 | **替换**：→ Stats SWidget 体系 |
| `SystemMetricsCollector` | CPU/内存/磁盘轻量采集 | **替换**：→ Stats readers |
| `NetworkMonitor` | 网络速率轮询 | **替换**：→ Stats Network module |
| `NetworkInfoService` / `NetworkInfoPopoverController` | 网络信息弹层 | **升级**：→ Stats Network popover（Frset 化） |
| `DiskActivityLampsLayerView` | 磁盘读写灯（菜单栏小图） | **升级**：→ SWidget BarChart/Mini |
| `MemoryIconPinsLayerView` | 内存状态条小图 | **升级**：→ SWidget PieChart/Mini |
| `SystemStatusSectionView` / `SystemStatusInteractionGeometry` | 主面板监测区（曲线+三色条） | **重构**：→「监测中心」卡片流 |
| `NetworkSpeedChartLayerView` | 网速曲线 | 并入监测中心卡片 |
| `TimestampSettings` 等 | —（无关，排除） | |

### 1.2 目标体系（Stats 移植）
```
FrsetStats.framework（M1 产出）
├── Kit（Module 基类 / SWidget / PopupWrapper / PortalWrapper / Store / SystemKit）
├── Modules（10 个：CPU/GPU/Memory/Disk/Network/Sensors/Battery/Fan/Bluetooth/Clock）
└── 数据模型（Codable structs，如 CPU_Load/Memory_Data/Network_Data）
```

## 2. 行为清单（目标）

| # | 行为 | 细节 |
|---|---|---|
| B1 | 菜单栏多模块显示 | 每模块一个 NSStatusItem，可配置 5 形态（Mini/LineChart/BarChart/PieChart/Tachometer） |
| B2 | 点击监测项 | NSPopover（Frset 化容器）展示该模块面板（见 §3.3） |
| B3 | 默认配置 | 网络(Mini ↑↓)/内存(Mini %)/磁盘(Mini R/W)/CPU(LineChart)/传感器(Mini 温度)；GPU/电池/风扇/蓝牙/时钟默认关 |
| B4 | 兜底模式 | 只留主图标 + Combined 总览（Stats v3.0.21 模式） |
| B5 | 主面板监测中心 | 2 列卡片网格（图标+数值+迷你图），点击→模块 popover |
| B6 | 刷新率 | CPU/内存/网络 2s；传感器 5s；进程 5s（可配） |
| B7 | 性能预算 | 默认配置 +1~2% CPU / +30~60MB（已实测 Stats 基线） |
| B8 | 开关 | 设置→监测标签：模块开关/形态/颜色/刷新率；总开关（关闭后零开销） |

## 4. 源码还原与代码骨架

### 4.1 注入侧桥接（新代码，正向）
```swift
// FrsetStatsBridge.swift — 注入 dylib 的入口
final class StatsBridge {
    static let shared = StatsBridge()
    private var modules: [Module] = []          // Stats Module 基类实例
    private var statusItems: [NSStatusItem] = []

    func start() {
        // 1) 枚举启用模块（读 Frset 偏好 "monitor.<module>.<key>"）
        // 2) modules = [CPU(), Memory(), Network(), ...]（Stats 原类）
        // 3) 每模块创建 NSStatusItem + 默认 SWidget
        // 4) 点击绑定 NSPopover(contentViewController: Frset化容器(module.popup))
    }
    func stop() { /* 移除全部 statusItems、停 readers —— 总开关实现 */ }
}
// constructor: 注入后延迟 2s 启动（避免与 Frset 自身状态项竞争）
```

### 4.2 SWidget 移植（Stats 侧裁剪）
```swift
// Kit 移植清单（保留原类名，降低还原误差）
PopupWrapper / PortalWrapper / Module / SWidget 家族
(Mini/LineChart/BarChart/PieChart/Tachometer) / Store / SystemKit /
Constants（Popup.width 等布局常量）
删除：Widgets(桌面小组件)/LaunchAtLogin/Update/更新检查相关
```

### 4.3 偏好键（新，与 Stats Store 隔离）
```
monitor.enabled            Bool  总开关
monitor.<module>.enabled   Bool  模块开关（network/memory/disk/cpu/sensors/...）
monitor.<module>.widget    String 形态（mini/line/bar/pie/tachometer）
monitor.<module>.interval  Double 刷新秒数
monitor.<module>.color.*   String 颜色（沿用 Stats 语义色默认）
```
