# 21 · 文件中转（双栏）与网盘解析

> 2026-10-20 用户需求：中转站分「云端 / 本地」两栏；本地用硬链接暂存、可拖入拖出；
> 网盘链接要能识别 8 家、复制后在状态栏弹提示，点开进入下载/脚本配置窗口。

## 1. 本地中转（硬链接）

| 项 | 规则 |
|---|---|
| 暂存根 | `~/Library/Application Support/FrsetNext/transfer-local/` |
| 布局 | `<uuid>/<原文件名>`，索引 `index.json` |
| 普通文件 | `FileManager.linkItem`（`link(2)`）→ **硬链接**，磁盘只有一份数据 |
| 目录 | 不能硬链 → 符号链接（标注「目录链接」） |
| 跨卷（外置盘/U 盘） | `linkItem` 抛 EXDEV → 自动拷贝，标注「副本」，不冒充硬链接 |
| 移出中转 | 只删暂存目录里的链接，**不动原文件** |
| 拖出 | `NSItemProvider(contentsOf: stagedURL)`，Finder 拿到的是同源文件 |
| 索引自愈 | 启动时剔除暂存文件已被删除的幽灵条目 |

硬链接的可见后果（符合预期）：从任一入口修改内容，另一边同步变化；删除任一边只是减少链接计数。

### 交互落点

- 中转页右栏「本地」整栏是放置目标；空态有「拖文件到这里」提示；
- 面板顶部分段「文件中转」也是放置目标：拖上去 → 存入本地 + 切到中转页 + Toast；
- 行内悬停：Finder 显示 / 移出；双击打开；右键菜单同；
- 底部「打开目录」直达暂存目录；「清空」只清链接。

## 2. 云端中转（保留）

左栏沿用 OPPO 中转站 Python 桥（`frset_bridge.py`）：登录态、空间、列表、上传、下载、删除。
两栏各自独立放置目标——拖左栏上传云端，拖右栏进本地，不会串。

## 3. 网盘链接识别（8 家 / 17 域名）

实测（`CloudDriveLinkDetector` 探针，2026-10-20）：

| 网盘 | 样例 | 识别 | 分享页 |
|---|---|---|---|
| 百度 | pan.baidu.com/s/… | ✅ | ✅ |
| 阿里 | www.alipan.com/s/… | ✅ | ✅ |
| 移动 139 | yun.139.com/shareweb/#/w/… | ✅ | ✅（本次修正） |
| 天翼 189 | cloud.189.cn/t/… | ✅ | ✅（本次修正） |
| 迅雷 | pan.xunlei.com/s/… | ✅ | ✅ |
| 夸克 | pan.quark.cn/s/… | ✅ | ✅ |
| UC | drive.uc.cn/s/… | ✅ | ✅ |
| 123 | www.123pan.com/s/… | ✅ | ✅ |

修正两处判定：
1. `isSharePage` 原来只认 `/s/`、`/share/`；139 的 `/shareweb/`、189 的 `/t/` 会被判成非分享页。
   现在：`/share` 前缀、`/s/` 通用；189 加 `/t/`；139 加 `/w/`、`/m/`。
2. 裸域名被 `NSDataDetector` 补成 `http://` → 统一升级为 `https://`。

负例：普通网站链接（example.com/s/…）不识别；网盘非分享页识别为「非分享页」。

## 4. 复制后的状态栏提示

`CloudLinkPromptController` 监听 `ClipboardManager.$items`：

- 启动时记录基线，历史条目不弹；
- 新条目 → `detect` 命中 → 状态栏图标正下方弹出 322×64 胶囊（`.statusBar` 层级、非激活面板、不抢焦点）；
- 同一条链接只提示一次；12s 自动收起，可点 × 关闭；
- 点胶囊 / 「测试」→ 打开「网盘解析中心」。

## 5. 网盘解析中心（下载配置 + 诊断）

`frsetnext://cloudlink?url=<链接>` 可直接打开（排障用）。窗口 600×660：

1. **解析检测**（可重跑）
   - 链接识别：服务商 / 是否分享页 / 主机
   - 解析脚本：未配置 → 警告；文件不存在 → 失败；存在 → 读出 `@name/@version`
   - 分享页可达性：带该网盘 UA 的 GET，报 HTTP 状态 + `<title>`；401/403 提示需登录
   - 下载目录：存在 + 可写
   - 下载 UA：默认/自定义
2. **下载配置**
   - 解析脚本路径（选择 .user.js / 清除）
   - 保存目录（选择 / 打开）
   - 超时 5–120s
   - 下载 UA 覆盖（留空用网盘默认：百度 `pan.baidu.com`、夸克专用 UA）
   - 脚本自动更新开关
3. **支持网盘**：8 家网格，当前链接命中项高亮「当前」
4. 底栏「开始解析下载」→ `CloudLinkActions.resolve`（既有 WKWebView 抓链 + 原生下载）

UserDefaults 键：`cloudlink.scriptPath` / `downloadDirectory` / `timeout` / `autoUpdate` / `uaOverride`。

## 7. 下载配置扩展（2026-10-20 二次反馈）

用户指出窗口只有 5 项配置，缺少脚本/下载器的并发等参数。LinkSwift 侧的配置实际包含
下载方式（API/aria2/IDM/复制）、`split`/`max-connection-per-server`、
`max-concurrent-downloads`、`min-split-size`、`continue`、重试、下载 UA 等。
窗口补齐为「真配置 + 真生效」：

| 配置 | 范围/默认 | 生效位置 |
|---|---|---|
| 下载方式 | 内置 / aria2 RPC / 复制直链 | `CloudLinkDownloader.run` 分支 |
| 同时下载 | 1–6，默认 2 | 下载队列 `pump()` 并发上限 |
| 单文件连接数 | 1–16，默认 8 | aria2 `split` + `max-connection-per-server` |
| 分片大小 | 1/4/10/32 MB，默认 10 | aria2 `min-split-size` |
| 失败重试 | 0–10，默认 3 | 失败后 1.2s 重排队，计数到上限才报错 |
| 断点续传 | 默认开 | aria2 `continue` |
| aria2 RPC / 密钥 | 默认 `127.0.0.1:6800/jsonrpc` | JSON-RPC `aria2.addUri` |
| 同名文件 | 重命名/覆盖/跳过 | 落盘前 `destination(for:)` |
| 完成后 Finder 显示 | 默认开 | `finish(localURL:)` |
| 解析脚本 / 更新源 / 自动更新 | .user.js 路径、raw URL、开关 | 检测与后续解析 |
| 保存目录 / 超时 / UA | 默认 ~/Downloads、20s、网盘默认 | 下载请求与落盘 |

内置引擎为单连接 URLSession（不伪装多线程）；需要多连接时切 aria2，参数会原样下发。
aria2 不可达时按重试策略重试，最终 Toast 报错，不静默。

构建：`build.sh` 通过；检测探针与硬链接探针见 §3、§6。
