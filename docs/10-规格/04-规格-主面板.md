## 4. 源码还原与代码骨架

```swift
// 4.1 面板本体（AppKit NSPanel + 毛玻璃；与实测行为一致）
final class FloatingPanel: NSPanel {
    init(contentRect: NSRect) {
        super.init(contentRect: contentRect,
                   styleMask: [.nonactivatingPanel, .fullSizeContentView, .borderless],
                   backing: .buffered, defer: false)
        self.isFloatingPanel = true
        self.level = .floating                       // 浮在普通窗口上
        self.titleVisibility = .hidden
        self.titlebarAppearsTransparent = true
        self.isMovableByWindowBackground = true
        self.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]
        self.backgroundColor = .clear
        // 内容：SwiftUI 根视图（NSHostingView(PageRootView())）
        // 毛玻璃：NSVisualEffectView(material: .hudWindow, blendingMode: .behindWindow)
    }
    override var canBecomeKey: Bool { true }        // 可输入（搜索框）
}

// 4.2 内容根视图（SwiftUI，区段组装——对应截图布局）
struct PageRootView: View {
    var body: some View {
        VStack(spacing: 0) {
            ToolbarRow()            // 搜索入口 + ⚙️ + ⋯
            ScrollView {
                MonitorCenterSection()      // 03 号
                ClipboardSection()          // 05 号
                CalendarSection()           // 10 号
                ToolsSection()              // 10 号
            }
        }
        .frame(width: 400)
    }
}

// 4.3 开合（StatusBarController 侧，原有行为保留）
func togglePanel() {
    if panel.isVisible { panel.close() } else {
        panel.setFrameOrigin(rightEdgeOrigin())     // 屏幕右侧，菜单栏图标下方
        panel.makeKeyAndOrderFront(nil)
    }
}
```

## 2026-10-20 「点外/失焦收起」统一为唯一实现（用户实障）

**问题**：状态栏图标展开的界面（主面板 / 性能监测弹窗）点击别处不收起。
**根因**：工程里存在多套互不相干的收起实现，各自覆盖不全：
- `PanelController.windowDidResignKey` 只守 resignKey（窗口没当上 key 时永不触发）
- `MonitorPopoutWindow` 自建五路冗余（resignKey / app 失活 / 全局监视 / 本地监视 / 按键轮询）+ 幂等锁
- 另有预览窗、动作条的独立 outside monitor

**统一实现**：新增 `Core/Runtime/TransientWindows.swift` → `TransientWindowCenter`
- 收起信号：① 本 app 失活（不依赖 TCC，最可靠）② 本 app 内点击落在注册窗口外
  （菜单栏区域、菜单/弹层、注册的兄弟窗口除外）③ 窗口 resignKey 转发
- 注册即互斥：`register` 会收起其它已注册窗口（主面板 ↔ 监测窗不会并存）
- `PanelController.show` 注册、`hide` 注销、`windowDidResignKey` 转发 `requestDismiss`；
  原三条例外（自家 sheet / 剪贴板预览窗 / 面板预览 popover）收拢到注册参数 `allowsClickIn`
- `MonitorPopoutWindow` 删除五路监听与四个监听属性，`open` 注册、`finishDismiss` 注销，
  `windowDidResignKey` 转发中心

**实测**：⌥M 开监测窗 → 点击其它 app → 收起（windows 1→0）；⌥A 开面板 → 点击其它 app → 收起；
⌥M 后 ⌥A → 监测窗自动收起、只剩面板（互斥）。

**边界**：预览浮层（hover 驱动）与截图动作条不是窗口级浮层，保留各自的点外仲裁，不并入中心。

## 2026-10-20 网盘「解析下载」从占位改为真实下载

- 新增 `Features/Panel/CloudLink/CloudLinkDownloader.swift`：
  - 直链（路径即文件扩展名且非分享页）→ URLSession 直接下载到 `~/Downloads`（同名自动加序号，不覆盖）
  - 分享页 → 隐藏 WKWebView 打开 + 注入 JS 抓文件直链候选（a[href] 与页面 HTML 内嵌 URL），
    同步网盘域 cookie 给 URLSession 后下载第一个可用直链
  - 解析失败（需登录/验证码/客户端）→ 明确 Toast 报错并打开页面，不假装成功
- `CloudLinkActions.resolve` 从「打开网页 + 接入中」改为调用下载器
- 排障探针 `FRSET_CLOUDLINK_TEST_URL=<直链>`：启动 3s 后走一次直链下载
- 实测：探针下载 `speed.cloudflare.com/__down?bytes=200000` → `~/Downloads/__down` 200000 字节，
  日志「下载完成」+ Toast「已下载」
