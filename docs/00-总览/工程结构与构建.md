> 正向重建工程（对应逆向工程 `~/Desktop/Project/frset/`）。零外部依赖、纯系统框架、可独立构建。

## 2. 解耦设计（为什么模块能并行开发）

功能模块之间**禁止直接引用彼此的具体类型**，一律通过：

| 通道 | 用途 |
|---|---|
| `PanelSectionRegistry` | 模块把自己的 UI 区段挂进主面板 |
| `SettingsPaneRegistry` | 模块把自己的设置页签挂进设置窗口 |
| `StatusItemRegistry` | 模块把自己的状态栏项挂进菜单栏 |
| `ServiceLocator` | 共享能力：LLM 服务 / OCR 服务 / 面板控制 / 设置窗口控制 |
| `*EventBus`（各模块内定义，App 层接线） | 跨模块事件（截图完成→入剪贴板、AI 产出→入剪贴板等） |

因此每个模块可**独立类型检查**（只带 Core/Models/Storage + 自身目录），互不阻塞。

## 3. 构建与运行

```bash
cd ~/Desktop/Project/frset-rebuild/apps/FrsetNext
./build.sh
open build/FrsetNext.app
```

- 编译器：Swift 6.4（`-swift-version 5` 语法模式），target `arm64-apple-macosx13.0`
- 链接：`-lsqlite3` + AppKit/SwiftUI/Combine/CoreGraphics/CoreImage/ImageIO/Vision/ScreenCaptureKit/EventKit/ServiceManagement/UniformTypeIdentifiers
- 签名：ad-hoc（`codesign -s -`）；首启需授权屏幕录制/日历（按各自弹窗）

## 4. 单模块类型检查（开发时）

```bash
cd apps/FrsetNext/Sources
SDK=$(xcrun --show-sdk-path)
swiftc -typecheck -sdk "$SDK" -target arm64-apple-macosx13.0 -swift-version 5 \
  Core/*.swift Models/*.swift Storage/*.swift Features/<模块>/*.swift
```

## 5. 启动顺序（App/AppBootstrap.swift）

```
Panel → Settings → StatusBar → Monitor → Clipboard → Capture → AI → Toolbox
```

启动后由 `AppBootstrap.wireEventBuses()` 连接跨模块事件（截图/OCR/AI/工具产出 → 写入剪贴板历史）。
