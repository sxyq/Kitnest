## 4. 本轮视觉升级（Liquid Glass + 过渡动效）

### 4.1 Liquid Glass

| 面 | 实现 | 说明 |
|---|---|---|
| 主面板 | `NSGlassEffectView`（macOS 26+，`LiquidGlass.makeView`） | 圆角 14、`windowBackgroundColor@55%` 底衬；旧系统回退 `NSVisualEffectView(.hudWindow)`；「降低透明度」时改不透明 |
| 监测详情 sheet | `LiquidGlassBackground`（把 sheet 窗口置透明后铺玻璃） | 圆角 18；面板内容透出，形成层叠关系 |
| 悬浮剪贴板 | 同上（Midnight 主题保持实底） | 窗口原本已是 clear |
| 录屏设置窗 / 计时窗 | ObjC `FSRecMakeGlass` 升级为 `NSGlassEffectView`（tint 78%，弹窗更实） | 旧系统回退原毛玻璃 |
| 卡片 | `GlassCardBackground`：斜向高光 + 0.6pt 亮边 + 内阴影 | 不逐卡叠模糊（性能与可读性） |

### 4.2 动效

| 交互 | 动效 | 参数 |
|---|---|---|
| 面板弹出/收起 | 缩放 0.93→1（锚点顶）+ 上移 10pt + 淡入 | spring 0.32 / 0.78 |
| 主页 ↔ 性能 | 交叉淡入 + 横向 16pt 位移；搜索框上移淡出 | spring 0.30 / 0.88 |
| 监测中心展开/收起 | 上缘锚定缩放 0.97 + 淡入；chevron 旋转 180° | spring 0.34 / 0.82 |
| 监测详情模块切换 | 选中胶囊 matchedGeometry 滑动；内容上移 8pt 淡入 | spring 0.32 / 0.82 |
| 设置页签切换 | 页签高亮块滑动 + 内容位移淡入 | spring 0.34 / 0.84 |
| 卡片悬停 | 放大 1.015 | spring 0.26 / 0.80 |
| 图标按钮按下 | 缩放 0.88 + 透明度 0.65 | spring 0.22 / 0.62 |

> 动效只作用于 `transform/opacity`；不使用无限循环；键盘高频操作不额外加延迟。

### 4.3 实测

- 主面板：玻璃层渲染正常、文字对比可读（同机截图）。
- 监测详情 sheet：玻璃背景 + 模块胶囊滑动 + 内容切换正常。
- 录屏设置窗：玻璃面板 + 全部控件可读。
- 页面切换/收起展开的状态保持与滚动位置不回退（G4 结论仍成立）。

## 5. v130 主页与性能页 1:1 复刻（2026-10-17）

### 5.1 主页（PanelRootView 重写）

原版实测（400×700，`screencapture -l <window>` 逐帧对照）：

```
[截图][取色][悬浮剪贴板]        主页 │ 性能监测        [设置]   40pt
🔍 搜索或输入 / 使用工具                                    34pt
（建议位留白 96pt）
‹ 2026年10月 ›                                        ⌄     日历卡
周日 周一 周二 周三 周四 周五 周六
 11   12   13   14   15   16  [17]
 初二  初三  初四  初五  初六  初七  初八
[缩略图 50] 标题（1 行）                         ↓  ↵       剪贴板行 68pt
            3分钟前 · 341 个字符
```

实现要点：
- 工具条三图标 `.focusable(false)`（否则打开面板时首个按钮被系统画成蓝色焦点块）；
- 分段自绘胶囊：仅选中项有浅蓝底，无外层灰底容器；
- 日历从「整月 6×7 网格 + 今日事件 + 授权横幅」改为「两周 2×7 + 农历/节气 + 折叠」，
  今天蓝底白字、节气橙色、法定节假日去掉「节」后缀（重阳节 → 重阳）；
- 剪贴板去掉标题/搜索框/过滤栏，行改为 50pt 缩略图 + 单行标题 + 「时间 · 详情」，
  hover 出 ↓（复制）/ ↵（复制并粘贴）；行高 68 + 行距 8；
- 底部「退出 / 设置」栏与「⋯」菜单删除（原版没有）。

### 5.2 性能监测页（StatsPageView + StatsModulePanels）

- 标签行 7 项（第 6 项原版文案是「传感器」）、选中胶囊 matchedGeometry 滑动；
- 各模块按原版版式重绘：
  - CPU：温度环 + 红蓝灰分段总占用环 + 图例（系统/用户/空闲/启动时间）+ 负载历史 + 每核方块条 + 集群占用 + 平均负载三列 + 高占用进程；
  - 内存：半圆仪表（正常/警告/严重）+ 已用环 + 键值 + 使用历史 + 构成条 + 四段图例 + 进程；
  - GPU：三环（总/渲染/Tiler）+ 负载历史 + 详细信息；
  - 磁盘：卷名折叠 + 读写图例/双线图 + 容量条 + 总量键值 + SMART 分组 + 进程；
  - 网络：速率历史 + 峰值/累计 + 连通性 5×24 网格 + 延迟/抖动 + 接口 + 进程；
  - 传感器：温度/电压/电流/功率 四组（名称 + 横条 + 值）+ 风扇；
  - 电池：电量环 + 状态/剩余/循环/健康 + 电池键值 + 适配器段；
- 窗口高度按内容自适应（`statsPageHeightDidChange` → PanelController，300~700，顶边不动，±8pt 防抖）；主页固定 700。

### 5.3 同期修复

| 问题 | 根因 | 修复 |
|---|---|---|
| 图片预览一直转圈 | `item.imagePath` 是**相对路径**（`images/xxx.png`），预览用 `URL(fileURLWithPath:)` 解析到工作目录 → 文件不存在 → 解码恒 nil | 改走 `ClipboardFileStore.url(forRelativePath:)`；同时补「无法预览」失败态；`PreviewPopoverContentModel.imagePixelSize` 同源修复（高度预估此前恒为默认值） |
| Markdown 目录在文首且是蓝色链接 | 目录拼在正文头部、链接用 `NSColor.linkColor` | 拆出 `renderBody`，目录改为**左侧独立侧栏**（宽 172，点击滚动到标题、当前项高亮），链接改中性色 + 下划线 |
