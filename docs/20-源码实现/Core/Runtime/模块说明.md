## 模块职责

进程级基础设施，无 UI 归属、被全部 Features 消费：

- **可观测性**：`LogArchive`（分天日志 + 主线程卡死看门狗 + 心跳/挂起标记）。
- **状态真源**：`Personalization`（15+ 个 `@Published` 个性化参数，防抖落盘）。
- **装配骨架**：`ModuleRegistry` / `AppModule`（见 [Core/UI/模块说明.md](../UI/模块说明.md)，物理在 Support.swift）+ `Registry`（面板区段 / 设置页签注册表 + 协议槽）+ `ServiceLocator` 扩展。
- **兼容层**：`StateCompat`（`@Stored`，本机缺 SwiftUIMacros 时的 `@State` 替代）、`Preferences`、`L10n`。
- **窗口行为仲裁**：`TransientWindowCenter`（点外/失焦收起唯一仲裁器）、`WindowReveal`（"从哪来回哪去"锚点动效，**功能归属 [Core/Motion](../Motion/模块说明.md)**，物理在本目录）。
- **排障与自更新**：`RenderProbe`（白屏探针，默认关）、`AppUpdateChecker`（HTTPS 清单 + 签名校验整包替换）。

## 入口与主要调用链

- **日志**：任意代码 `Log.write`（Core/UI/Support.swift:8）→ `LogArchive.append` → `appendRaw`（锁内按天切文件、超 4MB 丢 DEBUG）。`Log.breadcrumb` 绕过 `isVerbose` 直通 `pushBreadcrumb`。
- **卡死取证**：`start()` 装 `CFRunLoopObserver`（beforeWaiting/afterWaiting/beforeTimers 记心跳）+ 看门狗 timer（2s）→ `checkHang`：预热期 10s 跳过、`stalled > 2.0s` 记 HANG（每 5s 一次）并写 `hangMarker` 文件 + 抓栈（`captureHangStack`）→ `AppDelegate` 的 InstanceLock 接管判据读 `freshHangMarker()`。
- **个性化**：设置页滑块 `didSet` → `persist()`（150ms 防抖）→ `flushPersist` 写 defaults + post `personalization.didChange`（AppKit 侧窗口/材质订阅）；退出 `flushPendingPersist()` 兜底。
- **注册表**：`ModuleRegistry.register/startAll`（AppBootstrap 9 模块）；`PanelSectionRegistry.register`（priority 排序）；`SettingsPaneRegistry.register` + `all`（按 `order` 数组排序）。
- **更新检查**：`checkOnLaunch` → `check`（URLSession 拉 HTTPS JSON 清单）→ `notifyUpdate`/`presentUpdate`（NSAlert）→ `installUpdate`：下载 → 流式 SHA-256 比对 → `ditto` 解压 → **`codesign --verify --deep --strict --test-requirement`（钉死证书指纹）** → 写 `frset-swap.sh`（参数化传参，非字符串插值）→ `NSApp.terminate` → `prepareToTerminate` 起替换脚本（等旧进程退出 → mv 暂存 → ditto 装新版 → 失败回滚 → 轮换 `.bak`）。

## 数据流与状态变化

1. **分天日志**：`logs/YYYY-MM-DD.log`（走 `AppDirectories.sub("logs")`，v210 起 DEBUG/正式版隔离），3 天 / 单文件 4MB 上限，6h 清理。
2. **`Personalization` 三态**：加载期 `isLoading` 抑制回写（否则逐属性赋值互相覆盖、用户设置失效）→ 运行期防抖 150ms 落盘 → 退出 flush。`@Published` didSet 触发 SwiftUI 立即重绘；`didChangeNotification` 在**落盘时**才 post（AppKit 侧"晚 150ms"，可接受）。
3. **瞬态窗**：`register` 即"同一时刻只保留一个浮层"（`dismissAll(except:)`）；收起信号四路：didResignActive / 本地点击落在窗外 / `resignKey` 转发 / 全局监视器（需辅助功能权限，仅补充）。
4. **更新可用性状态**：`availableBuild`/`notifiedBuild`/`cachedFeedJSON` 落 defaults，WhatsNew 与状态栏通过 `frset.update.feedDidUpdate` 通知消费。

## 依赖关系

- **上游**：Foundation/AppKit/QuartzCore/CryptoKit（SHA256）/libproc（footprint/线程数）。
- **下游**：全部模块。`Theme` 动态令牌（Core/UI/Support.swift）读 `Personalization`；`Toast`/`LiquidGlass`/`AppearanceTheme` 订阅个性化；`AppDelegate` 消费 `LogArchive.freshHangMarker` 与 `AppUpdateChecker.prepareToTerminate`。
- **协议槽**：Core 定义协议（`PanelControlling`/`SettingsWindowControlling`/`PanelPreviewPresenting`）→ Features 实现注入 → Core 只经 `ServiceLocator` 调用。**破例**：`RenderProbe` 直接引用 `PanelController`/`SettingsWindow`（Core→Features 反向依赖，探针默认关）。

## 异常和取消处理

- **写盘失败**：`appendRaw` 全 `try?` 静默；跨天切换若 `FileHandle` 重开失败，`handle=nil`，当日剩余日志静默丢弃。
- **更新安装**：HTTPS 强制（feed 与 zip 均校验 scheme）；SHA-256 缺失/非法直接取消；签名验证失败中止；替换脚本带 `fail()` 失败回滚（`mv` 回旧版 + `open`），`trap ... EXIT` 清理工作目录；用户取消退出（`terminateCancel`）时 `prepareToTerminate` 清理工作目录并 Toast。
- **瞬态窗**：`unregister` 不调用而窗口释放 → `entries` 条目泄漏（`window` 变 nil、遍历跳过但字典增长），已知限制。
- **`DatabaseManager`**（Storage 侧）v200 起两级降级（内存库 → 空实例），不再 `fatalError`（原 P1-2 已修）。

## 性能边界（实测数字，来源标注）

- **日志**（A1 测绘 2026-11-03 前 + v128 注释）：`appendRaw` 在锁内做完整文件 IO，热路径禁止打日志；看门狗 2s 周期 + 2.0s 阈值（v101 从 0.5s 放宽，2~4s 短阻塞**有意**不记录）。
- **个性化防抖**（v84 注释）：拖滑块场景从每帧 15 次 defaults 写 + N 个监听者重建，压到 150ms 一次；代价是 `kill -9`/崩溃丢最后 150ms 改动。
- **更新下载**：SHA-256 流式分块（1MB/次），不再整包读内存（旧实现在 >500MB 包上吃内存）；清单轮询 6h。
- **`L10n.bundleCache`**：`Bundle(path:)` 昂贵，`t()` 在 body 高频调用，故静态缓存（无锁，见限制）。
- **卡死预热期 10s**：bootstrap 主线程同步期间 runloop 不跳，删掉会误报"主线程阻塞 18s"。

## 已知限制 / 历史坑

1. **`@State` 不可用**是硬约束：`@StateObject/@Binding/@Environment/@AppStorage/@FocusState` 可用，`@Stored` 是唯一状态容器。
2. **`Preferences.value` 的 `as? T`**：数值键写入/读取类型必须一致（`Int` 写 `Double` 读静默回落默认值）。
3. **`Log.breadcrumb` 绕过 `isVerbose` 门控**：breadcrumb 的 DEBUG 行在 4MB 以下始终落盘，与 `Log.debug` 行为不一致（两套过滤并存）。
4. **`L10n.bundleCache` 无锁**：`t()` 可从后台线程调用，Dictionary 并发写风险理论存在（写只在首次未命中）。
5. **`TransientWindowCenter.entries` 无淘汰**（见上）；菜单栏白名单用 `NSStatusBar.system.thickness` 推算，多屏副屏顶部 22pt 会被误判为菜单栏。
6. **`RenderProbe.emit` 的异常标记**（A1 记录的死逻辑 `contains("alpha0|cvZero|…")`）**已修**：现按数组逐项判定（RenderProbe.swift:108）。
7. **更新脚本仍写 `/tmp`**（现为工作目录内 `frset-swap.sh` + 参数化传参）：P1 shell 注入风险已通过"HTTPS 强制 + SHA-256 强制 + codesign 钉证书"三重缓解，但替换动作仍依赖 `/bin/sh` 脚本（回滚语义需要）。
