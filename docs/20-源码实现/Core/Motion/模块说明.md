# Core/Motion（feature_id: CORE-MOTION）

> 窗口开合动效引擎：神灯（Genie）漏斗动画的网格计算与预渲染帧播放、内容侧动效闸门、窗口锚点展开/收回。对应源码：apps/FrsetNext/Sources/Core/Motion/（3 个文件 / 1,114 行；累计 22 提交，2026-11）+ 动效同族的 `Core/Runtime/WindowReveal.swift`（187 行，历史归位在 Runtime，见 §2）

## 模块职责

面板/窗口开合的全部动效供给：

- **GenieWarp**：把窗口开合做成 Dock"神灯"漏斗——抓真窗快照 → 整条动画预渲染成 CGImage 帧序列 → 覆盖窗 `CAKeyframeAnimation(contents:)` 按刷新率播放；支持**掉头反演**（随点随停、原速倒回）。
- **GenieMesh**：漏斗几何与两段时序（侧边"弯" + 整体"滑"），从 Dock（macOS 27.0.1）反汇编还原的公式逐行移植（the-genie-effect 方法，不引原项目代码）。
- **PanelMotion**：面板内容侧历史动效的总闸门（调神灯手感期间停掉 SwiftUI 内容动画，防"两套动画打架"）。
- **WindowReveal**（`Core/Runtime/WindowReveal.swift`）：窗口级"从哪来、回哪去"锚点缩放淡入淡出（弹窗类窗口统一入口）。

## 入口与主要调用链

**神灯主路径（PanelController 开合）**

```
PanelController.show/hide
 └ GenieWarp.shared.playIn/playOut(window:slot:duration:…)      [GenieWarp.swift:240/250]
    ├ 总开关 motion.genie（缺省开）→ 关闭时调用方直接落位（PanelMotion.fallbackAnimationDisabled）
    ├ 连点检测：running && 同窗 && frames.count>1
    │    ├ 反向 → switchDirection（speed 取反、原速倒回，不重抓不重渲染）
    │    └ 同向 → 直接返回 true（不重播）
    ├ 显示准备：skipInitialDisplay 时补 layoutSubtreeIfNeeded + displayIfNeeded + CATransaction.flush
    │    （v246：不 flush 会抓到整张单色空白帧；v279：show 路径刚 display 过则跳过）
    ├ 快照：ScreenSnapshot.legacyCapture(windowID) → 失败重试一次 → isBlank 兜底跳过动画
    ├ 真窗退幕后：alpha=0（收起时保持 isVisible，只清 alpha）
    ├ 降采样：整张快照一次降到「画布宽 × pixelScale」，之后每帧近 1:1 取图
    ├ 帧预算：refresh = clamp(screen.maximumFramesPerSecond, 60…120)；
    │    target = clamp(duration × refresh, 12…48)；pixelScale = 内存预算反推（≤1.25）
    ├ 并行预渲染：DispatchQueue.concurrentPerform × target
    │    每帧 GenieFrameRenderer.render（纯函数、各自 bitmap）
    │    进度缓动：展开 ease-out（1-(1-t)^e）、收起 ease-in（t^e），e 默认 2.0（probe.genieEase 可调）
    ├ 覆盖窗：GenieOverlayPanel（borderless/nonactivating、level=StatusBar+2、穿透、
    │    只盖漏斗外接框 bbox，不盖整屏）+ frameLayer.contents=frames[0]
    ├ startLeg(at:0, speed:1)：CAKeyframeAnimation("contents") discrete、fillMode=.both、
    │    isRemovedOnCompletion=false；模型层 contents 同步到当前帧（CATransaction 禁隐式动画）
    ├ 看门狗 Timer（remain+0.02s）兜底 finish
    └ finish：展开 → alpha=1 + 不可见则 orderFront（v280 连点收尾保证在屏）；
             收起 → 直接 orderOut（alpha 留 0，防"闪回来一帧"，v240）
```

**掉头（v244/v248，"随点随停"）**：`switchDirection` 取 `currentPosition()`（legPos + elapsed×speed）→ `startLeg(at: pos, speed: ±1)`——同一动画把 `speed` 取反，帧序列不动；`add(_:forKey:)` 同 key **原子替换**（v254：先 remove 再加会露一帧模型值 = 抽搐）；模型 contents 索引 = `floor(t·n)` clamp 到 n-1（v252：用 `t·(n-1)` 会差一帧，掉头时"闪一帧别的画面"）。`frameLayer.actions = ["contents": NSNull()]`（v257：手动子 layer 的 contents 隐式 0.25s crossfade 与离散帧叠加 = 收缩抽搐）。

**WindowReveal 路径（弹窗类）**：`playInFromMouse`/`playOutToLastAnchor` → 内容层显式 `CABasicAnimation`（transform + opacity）→ 模型值先设终态（防闪回）→ completion 双保险（CATransaction 回调 + `duration+0.08s` 计时兜底，`Once` 去重）。

## 数据流与状态变化

1. **帧序列生命周期**：`play` 时构建 `frames: [CGImage]`（一腿的全部帧）→ 存 `self.frames` 供反向复用 → `finish`/`cancel` 清空。反向播放把数组按播放序反转，从当前帧接着播。
2. **真窗与覆盖窗交接**：动画期间真窗 `alphaValue=0`（收起时保持 `isVisible`），视觉全部由覆盖窗帧序列承担；展开收尾 alpha=1（必要时 orderOut→orderFront 兜底），收起收尾 orderOut。
3. **排障开关**（defaults）：`motion.genie`（总开关）、`probe.genieDuration`（拉长整条动画逐帧核对）、`probe.genieHold`（定格在指定进度供截图）、`probe.genieEase`（缓动指数 1–4）、`probe.genieMesh`/`probe.genieDebug`（画网格/参考框）、`probe.genieFramePacing`（显式记录 CVDisplayLink 回调间隔，不代表实际呈现帧率，默认关闭）、`probe.reveal`（WindowReveal 中段采样 presentation 层）、`motion.panelContent`（恢复内容侧历史动效）。
4. **PanelMotion 闸门**：`contentAnimationsDisabled` 默认 true → SwiftUI 侧 `animation()` 返 nil、`transition()` 退化 identity；面板开合走不了神灯时**直接落位**（不再退到 WindowReveal 缩放，防"神灯+缩放播两遍"）。

## 依赖关系

- **上游**：QuartzCore（CAKeyframeAnimation/CALayer）、AppKit、`ScreenSnapshot.legacyCapture`（dlsym 的 CGWindowListCreateImage，按窗口 ID）、`Theme.Radius.window`（快照圆角裁切）、`Theme.Motion.caEaseOut/caEaseIn`（WindowReveal 曲线）、`Personalization.openAnimation.duration`（WindowReveal 默认时长）、`Log`。
- **下游**：Features/Panel（`PanelController`：开合主路径、`parkOrigin` 屏外停靠抓快照）；各弹窗类窗口（WindowReveal 通用入口）。
- **不依赖**：任何 Features 具体类型（纯动效层，Core 内自洽）。

## 异常和取消处理

- **快照失败 / 空白帧**：`Log.warn` 后返回 false，调用方退回缩放动画或直接落位——宁可不播，不糊一整块纯色（v246 实证：opacity 还原未提交到窗口服务器时抓到单色帧）。
- **帧渲染全失败**：`running=false`，展开时把真窗 alpha 拉回 1，返回 false。
- **`cancel(restoreWindow:)`**：停看门狗、拆覆盖窗、可选恢复 alpha、清全部播放态。动画被打断（新 play 覆盖）走 `cancel(restoreWindow: false)`。
- **掉头语义**：同窗反向请求不 cancel 重来（旧实现 alpha 一回 1 面板整块亮出 = "先展开再重播一遍"），而是时间反演续播。
- **WindowReveal**：`Once` 保证 completion 只跑一次；窗口被遮挡/动画被系统跳过时计时兜底触发；`reset` 在 orderOut/close 后复位内容层（防下次打开带着缩放态）。

## 性能边界（实测数字，来源标注）

- **历史对照**（GenieWarp.swift 头注，2026-11 实测）：第一版 Timer(1/60) 每帧重绘整屏 1710×1112@2x = **24 帧 / 464ms**；改 CADisplayLink + 只盖漏斗外接框（372×676）后展开 24 帧、**收起只剩 12 帧**（收起时主线程被 SwiftUI 重排占住）——这是"预渲染 + 渲染服务器播放"方案的直接动因。
- **内存预算 64MB**：`pixelScale = clamp(sqrt(64MB / (帧像素×4×帧数)), 1, 1.25)`（GenieWarp.swift:665，**上限 1.25x**；任务书口径 1.2x 与源码不符，以源码为准）。1x 下 48 帧 ≈ 62MB。
- **帧数**：与屏幕刷新率挂钩（60–120Hz），`target = clamp(时长×刷新率, 12, 48)`——**48 帧上限**（v243：原按 60fps 固定算，120Hz 屏上每帧重复两次 = "一顿一顿"）。
- **预渲染耗时**：`DispatchQueue.concurrentPerform` 铺满核；快照先整张降采样到目标宽度（v 注释：2x 快照 720 宽 vs 画布 446 宽，逐帧降采样累计一百多毫秒，整张降后预渲染砍一半）。
- **阶段计时日志**（2026-11-23，`80b1bf66`）：每次 play 打一行 `genie 阶段：显示准备 / 快照 / 降采样 / 帧构建 / 上屏 / 主线程总计 / 动画时长 / 内存 footprint 前后`（`footprintMB()` 用 `task_info(TASK_VM_INFO)`）；另打一行几何摘要（窗/图标尺寸、行程、弯/滑毫秒、弯完于百分比）与预渲染摘要（帧数、画布、pixelScale、刷新率、缓动指数）。
- **时长映射**：`duration(for:) = clamp(0.28 + (configured-0.18), 0.28, 0.44)`，三档 ≈ 280/320/380ms，开合共用同一时长（菜单栏点击展开更短促）。

## 已知限制 / 历史坑

1. **覆盖窗绝不允许成为 key/main**（`GenieOverlayPanel`）：普通 NSPanel 抢键盘焦点 → 主面板 resignKey → 0.9s 后被 TransientWindowCenter 自动收起，表现为"面板刚展开就自己关了"。
2. **抓快照前必须显示 + 提交**（v246）：同一 runloop 里改过的 layer 属性未提交时抓到整张单色帧；但 v279 起 show 路径自带 display，`skipInitialDisplay` 免掉重复整窗重绘（玻璃重采样正压在点击路径上）。
3. **`frameLayer` 的 contents 隐式动画必须关**（v257）：手动子 layer 赋 contents 默认 0.25s crossfade，与离散帧动画叠加 = 收缩抽搐。
4. **`add(_:forKey:)` 原子替换，不要先 remove**（v254）；模型帧索引公式 `floor(t·n)` 而非 `t·(n-1)`（v252）——两处都是"掉头闪帧/抽搐"的实证修复。
5. **收起收尾不能先把 alpha 拉回 1 再 orderOut**（v240）："吸进去了又闪出来"；展开收尾必须保证 `isVisible`（v280 连点时上一腿的 orderOut 可能刚好落在展开结束前后）。
6. **`genieSubdivide` 容量固定**（`3×(64+3)` 三元组）：细分超限直接截断，几何仍在但侧边曲线变糙（有意的上界）。
7. **WindowReveal 依赖显式 CABasicAnimation**（v198）：NSView 宿主层隐式动画默认关闭，直接改 `layer.transform` 会瞬间跳变（"没一点动效"）；探针 `probe.reveal` 采样必须走**后台队列** asyncAfter（主线程首开布局堵 100ms+，主队列计时会读到终态，曾误判"动画没跑"）。
8. **PanelMotion 是临时闸门**：手感定稿后 `defaults write com.frset.frsetnext motion.panelContent -bool YES` 可整体恢复历史内容动效。
