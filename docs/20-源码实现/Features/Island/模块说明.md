## 2. 刘海岛架构

### 2.1 单一透明舞台（v211 起持续）

- **一个 `IslandPanel`**（`IslandController.swift:947`，NSPanel 子类）承载全部内容：borderless + nonactivating，`level = statusBar+1`，`.canJoinAllSpaces/.fullScreenAuxiliary/.stationary/.ignoresCycle`，`sharingType = .readOnly`（不入截屏）。`canBecomeKey = true`（搜索框要键盘），`canBecomeMain = false`。
- **多屏**：每块可用屏一个「入口窗」`entries[displayID]`（`IslandEntryView`，`:903`——只画入口胶囊/搜索条，**无 SwiftUI 正文、无 DB 订阅、无采样器**）。刘海屏入口是黑色小胶囊（与硬件刘海融合）；普通屏入口是菜单栏下方「搜索…」短条（v329c2b33）。点击/悬停入口 → `activateDisplay` → 舞台窗整体 `move(to:)` 迁屏（预览会话随窗平移，不经 collapse）。
- **屏幕身份**（`IslandDisplay`）：`CGDirectDisplayID` 经 `CGDisplayMirrorsDisplay` 归一（镜像屏用源屏身份），UUID 作稳定 id；`hasNotch` = `safeAreaInsets.top > 0 && auxiliaryTopLeftArea != nil`。`IslandDisplayScope`（auto 刘海屏优先 / all / main / selected）过滤启用屏；v266 `lastActiveDisplayID` 记忆上次屏幕（重启回原屏）。

### 2.2 收起 / 展开状态机（collapse / expand）

- **状态位**：`expanded`（展开意图）、`showingContent`（正文在树上）、`contentOpacity`（v270 正文独立透明度）、`interacting`（交互中抑制自动收）、`openedExplicitly`（显式打开后不因移出收）、`editingText`（文本编辑中不收）、`menuTracking`（菜单跟踪中不收）。
- **展开**（`expand(takeFocus:useOpeningPage:)`，`:651`）：applyOpeningPage（fixed/remember 模式）→ 读 `AppBootstrap.readSelection()` → 刷剪贴板摘要 → `showingContent=true`、`contentOpacity=0` → 定位+上屏 → `expanded=true` → 0.08s 后 `revealContent`（220ms 淡入正文）。展开同步段有毫秒埋点（2026-11-23 阶段计时）。
- **收起**（`collapse()`，`:686`）：取消布局草稿 → 关面板预览（`dismiss(.panelCollapse)`）→ 正文 120ms 先淡出 → `expanded=false` → 外壳 300ms 收拢（`surfaceAnimation`）。`surfaceDidChange(size:radius:)`（`:428`）在几何收到收起态尺寸后执行 `afterCollapse` 收尾动作（resignKey/orderOut/刷入口）——**收起完成以几何到达为准**，不是以动画 completion 为准。
- **动画（v270 参考 NotchKit motion.md）**：展开 spring(response 0.42, damping 0.80)，收起 `.smooth(0.30)`（旧 0.46/0.94 高阻尼「笨重」、0.28/1 末端顿挫已弃）；reduceMotion → `.easeOut(0.12)`。
- **自动收起**：`endInteraction()` 后指针不在轮廓内且非显式打开 → `collapseDelay`（默认 0.30s）后 `collapse()`；`performOutside(_:)`（`:454`）=「收起后执行」队列（打开主面板/设置等外部动作先收岛）。

### 2.3 形变外壳（`IslandSurface` / `IslandMorph`）

- **`IslandMorph`**（AnimatableModifier，`IslandSurface.swift:164`）：**同一补间**驱动尺寸、曲率、材质与内容透明度（`animatableData = (width, (height, progress))`）——反向操作接续正在显示的几何，不跳变。
- **`IslandOutline`**（`:234`）：肩角（`radius*0.45`）+ 底角的连续轮廓（收起态小圆角 chip → 展开态 28pt 大圆角）。
- **材质（`IslandMaterialHost/View`，`:262`）**：`IslandMaterial`（liquidGlass 原生液态玻璃 / frosted 毛玻璃 / solid 纯色）；玻璃层**始终创建**只切显隐（补建陷阱注释 2026-11-23）；`shellOpacity`（外壳通透度补数）只改 tint 不重建采样层（`LiquidGlass.reapplyStyle`）。
- **黑幕纪律（刘海双黑幕修复 `bb98d6ba`）**：收起→展开的深色过渡只由**一层**黑幕负责——收起态恒 1（与硬件刘海融合），展开态恒 0（深色交给玻璃 tint）。旧实现 tint(0.32)+黑幕(0.32) 叠加成 0.54，「滑块写 68% 通透却糊成灰毛玻璃」。
- **v274**：原生液态玻璃不再叠仿玻璃亮边（系统自带折光，避免双重描边）；毛玻璃/纯色保留发丝线。
- **收起态 Peeks**（`IslandCollapsedView`，`:404`）：刘海左右两翼的常态数据条——`IslandPeek`（最近复制/播放状态/日期/功耗），`peekPlacements`（both/left/right/hidden 按屏配置）+ `peeksShowValues`（38/72pt 单元宽）+ `peeksQuickActions`（点按=快捷动作：复制最近一条/播放暂停/复制日期/打开功耗监测，否则跳对应页）。`collapsedWidth = notchWidth + 左右 peek 数 × 单元宽`。

### 2.4 页面与组件体系（`IslandSettings.swift`）

- **`IslandPage` 17 页**：tab 页 4 个（home 常用 / clipboard 剪贴板 / search 搜索 / custom 我的空间）+ 详情/功能页 13 个（monitor/media/calendar/tools/capture/recording/ocr/transfer/cast/ai/statistics/archive/downloads）。`pageOrder`/`hiddenPages` 可配置（全关保 home）；`openingPageMode`（fixed 固定页 / remember 按屏记忆 `lastPageByDisplay`）。
- **`IslandWidget` 16 组件**：每组件对应一页（volume→media），带标题/SF Symbol/语义色；`widgetOrder`/`hiddenWidgets`/`widgetSizes`（1×1/1×2/2×1/1×4/2×2 五档）/`widgetPositions`/`widgetColors`；「我的空间」页有独立的 `customWidgetOrder/Sizes/Positions` 套系。
- **`IslandMetric` 6 指标**（cpu/gpu/memory/network/power/battery）：单位/上界/颜色/预览样例数据 + `format`。监测详情横滑切指标共用 `metricOrder`。
- **`IslandConfiguration`**（`:113`）：全部配置一次 Codable 落 `UserDefaults["island.configuration"]`；`init(from:)` 逐字段 `decodeIfPresent` 兜底默认（旧配置向后兼容）；`load()` 时补全缺失 widget/page、防 `fixedPage` 失效、全隐藏时强制 home。

### 2.5 交互路由（`IslandController.installMonitors`，`:731`）

- **指针/热区**：全局 mouseMoved monitor → `updatePointer`——命中 `entryFrame` 热区（`hotspotWidths`，默认 210pt）则按 `entryTriggers`（hoverAndClick/clickOnly）+ `hoverDelay`（0.18s）自动 `move+expand` 或 `revealedEntryID` 显形；`.hidden` 入口只藏胶囊不藏热区。`panel.ignoresMouseEvents` 按轮廓命中动态切换。
- **滑动切页**：本地 scrollWheel monitor，精确滚动 + 水平主导 + 累计 >36pt 触发一次（`didSwipe` 门闩）。**作用域优先**：monitor 详情页横滑=切指标（`stepMonitorDetail`，绝不整页跳走）；home/custom 有多组件页时=翻组件页；否则=整页 `turnPage`。
- **键盘（`IslandPanel.performKeyEquivalent`）**：Esc 详情页先 `goBack` 再收起（v270 两段式）；⌘O 打开；⌥←/→ 切指标或切页；⌘1..N 直跳 tab 页。
- **点击外收起**：全局 mouseDown monitor——点在入口热区 → `activateDisplay`；点在岛外且非菜单/交互中 → `collapse()`。
- **抑制清单**：菜单跟踪（`NSMenu.didBegin/EndTracking`）、文本编辑（`NSText.didBegin/EndEditing`）、布局编辑（`editingLayout`）、预览窗内（`hasPreview(from:at:)`）——任一成立不自动收。
- **预览协同**：与 `MainPanelPreviewPopoverCoordinator` 深度联动——岛窗口点外监听放行（`IslandController.shared.containsEntry`）、`movePreview` 随迁屏平移、收岛先 `dismiss(.panelCollapse)`、`IslandFileDragView`/`RowHostingView` 命中链放行。

### 2.6 内容路由（`IslandRootView` / `IslandContent.swift`）

- `IslandRootView`（`:6`）：`IslandSurface` 内 `pageContent(controller.page)`（`:37` 起过渡：trailing/leading move + opacity）。近期记录列表（`IslandRecentRow`）在 home/clipboard/transfer（无工具）/custom 显示，支持收藏过滤、标签过滤（`clipboardTagID`）、`clipboardRecentLimit` 条数、拖拽源（`IslandFileDragView`）、记录预览（`IslandRecordPreview`，经 Panel 预览桥）。
- 数据驱动：`ClipboardManager.itemsDidChangeNotification` / `TagStore.didChangeNotification`（增量 applyTagChange）/ `.localTransferDidChange` → `reloadRecords`；监测可见性 → `MonitorSampler.shared.setIslandActive`（**岛是采样器第四可见性闸**）。
- `IslandFeatureContent`：功能页（capture/recording/ocr/…）+ `IslandMonitorFullContent` 监测详情（与 `MonitorCenterPresenter.monitorSelection` 共享选中态，`monitorDetailOrder` 与卡入口共用一份顺序）。
- `IslandWidgetGrid`：组件网格 + 多组件分页（`setComponentPageCount`）+ `IslandEditableWidget` 布局编辑（拖位置/右下角改尺寸/隐藏），草稿经 `layoutDraft` → `updateLayout` → `finishLayoutEditing` 落盘（previewOnly 时只写设置草稿）。

### 2.7 与设置窗的预览共生（previewOnly）

`IslandController(previewOnly: true)` 给 `IslandSettingsPane`（Settings 模块）做实时预览：无真实指针（不进移开计时）、样例数据（`IslandSample`/`SettingsPreviewSamples`）、布局改动只更新草稿（「布局已更新到设置草稿，保存后应用」）。`IslandSettingsPreviewViewport` 保证形变尺寸只进预览容器。

## 3. 关键数据流

### 3.1 悬停展开 → 移出收起

```
mouseMoved → updatePointer：命中热区/轮廓
  ├─ 非刘海入口 hoverDelay 后 move(to:) + expand()（hoverEnabled && hoverAndClick）
  └─ 刘海热区 hoverDelay 后展开
展开：applyOpeningPage → 读选区 → showingContent → position → expanded
      → 0.08s revealContent(220ms) → spring 0.42/0.80 外壳弹出
移出（非显式/非交互/非编辑）→ collapseDelay 0.30s
      → collapse：正文 120ms 淡出 → expanded=false → smooth 0.30 收拢
      → surfaceDidChange(收起尺寸) → afterCollapse 收尾（resignKey/orderOut/刷入口）
```

### 3.2 多屏切换

```
点/悬停他屏入口 → activateDisplay(id) → move(to: display)
  ├─ 舞台窗 setFrame 迁到目标屏（lastActiveDisplayID 落盘）
  ├─ movePreview：预览窗随帧平移并钳在屏内
  └─ expand(takeFocus: !hasPreview)；search 页发 frsetFocusPanelSearch
```

### 3.3 横滑与详情

```
scrollWheel（精确滚动、水平主导、累计 36pt、一次手势一次）
  ├─ page == .monitor → stepMonitorDetail（切指标，作用域优先）
  ├─ home/custom 且多组件页 → turnComponentPage
  └─ 其它 → turnPage（可见页循环，pageSlide 方向驱动 12pt 横移动画）
Esc：详情页 goBack(returnPage) → 再按 collapse
```

## 5. 不变量与陷阱

1. **收起完成以几何到达为准**（`surfaceDidChange` 匹配 `collapsedWidth × notchHeight` 才执行 afterCollapse）——不能只等动画 completion；反向操作时 `afterCollapse` 必须可被打断（`expanded` guard）。
2. **黑幕只一层**（刘海双黑幕修复）：收起态黑幕恒 1、展开态恒 0，深色程度只由玻璃 tint（`shellOpacity`）表达——双层叠加会「通透度滑块失效」。
3. **玻璃层始终创建只切显隐**（`IslandMaterialView.applyMaterial`）：`.id()` 契约下同 id 复用视图，init 提前 return 会导致切回玻璃永远无玻璃（2026-11-23 复核补建陷阱）。
4. **抑制清单缺一不可**（菜单跟踪/文本编辑/布局编辑/预览窗内/显式打开）——任一遗漏即「用着用着岛自己缩回去」。
5. **横滑作用域优先**：monitor 详情页横滑只切指标，绝不整页跳走；36pt 阈值 + `didSwipe` 一次手势一次。
6. **Esc 两段式**（详情页 goBack 再 collapse）不可合并——否则详情页一按 Esc 整个岛没了。
7. **入口窗不得承载正文**（`IslandEntryView` 注释）：只画胶囊，无 DB 订阅/采样——多屏常驻成本必须趋零。
8. **镜像屏归一**（`sourceID`）：同一块物理屏的镜像不得建重复入口。
9. **`IslandConfiguration` 解析必须逐字段兜底**：整包 decode 失败 = 全部配置重置；`load()` 的补全规则（widget/page 补缺、fixedPage 校正、全隐藏强制 home）不可去。
10. **面板预览协同**：收岛先 `dismiss(.panelCollapse)`；入口命中判定 `containsEntry` 是预览点外监听的放行依据。
11. **previewOnly 分支**：设置预览无真实指针/不落盘/样例数据——漏 guard 会把演示数据写进真实配置或对空指针排程。

## 6. 风险 / 待观察

| # | 项 | 说明 |
|---|---|---|
| I1 | 全局 mouseMoved monitor 常驻 | 每次移动跑 `updatePointer`（几何命中 + 轮廓 contains）；岛关闭时 monitor 仍持有（`stop()` 才卸） |
| I2 | `configuration.persist()` 在 `rememberPage`/`move(to:)` 每次换屏/换页落盘 | 高频操作下 UserDefaults 写放大（量级小） |
| I3 | `IslandMetric.values` 硬编码预览样例 | 仅 previewOnly 用；live 路径读 `MonitorSampler` |
| I4 | 舞台窗随动画保留「当前动画所需范围」（`position` 不提前裁小） | 极端快速反复展开/收起时窗口尺寸比内容大（刻意，防裁掉收拢中的外壳） |
| I5 | 悬停自动展开依赖 `hoverArmed` 门闩 | 快速扫过热区的误展开由 hoverDelay(0.18s) + hoverArmed 双重抑制；手感调参集中在 `hoverDelay/collapseDelay` |
