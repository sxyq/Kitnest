## 模块职责

- **Tools/**：工具元数据与注册表（`ToolRegistry`）、13 个内置工具（`BuiltinTools`）、纯函数转换器（`ToolConverters`）、图片压缩/二维码（`MediaTools`）、IP 查询（`IPAddressService`）、全局工具窗（`ToolRunnerWindow`）、工具设置页（`ToolSettingsPane`）。
- **Search/**：主面板搜索区段（`SearchSectionView`，工具/Spotlight 文件/剪贴板历史/网页结果四类）、模糊匹配（`FuzzyMatcher`）、⌥K 命令面板（`CommandPalette`）、斜杠命令（`SlashCommands`）、全盘文件名索引（`FileNameIndex`，补 Spotlight 盲区）。
- **Shortcuts/**：Carbon 全局热键（`ShortcutManager`）、录制控件（`ShortcutRecorder`）、工具级热键（`ToolShortcutStore`）、双击修饰键（`DoubleTapShortcut`）+ 权限提示窗（`DoubleTapTipWindow`）、快捷键设置页（`ShortcutSettingsPane`）。
- **Calendar/**：EventKit 授权与月视图数据（`CalendarService`）、日历卡（`CalendarSectionView`）、农历/节气（`LunarCalendar`）、法定节假日（`HolidayManager`）。
- **Shell/**：模块入口（`ToolboxModule`）+ 主面板工具区段（`ToolboxSectionView`，4 列网格 + `ToolRunnerView`）。

## 入口与主要调用链

**工具执行（任一入口：工具格 / 搜索结果 / 命令面板 / 斜杠命令 / 工具热键）**

```
ToolboxUIState.open(id) → ToolRunnerWindowController.show(toolID:)
 └ ToolRunnerView.run() → ToolRegistry.run
    ├ tool.execute(input, options)（async）
    ├ recordInvocation → tool_invocations + bumpStat("tool_count")
    └ applyDefaultAction：copy（写剪贴板）或 save（ToolboxEventBus → 剪贴板条目）
```

**搜索（输入 → 四类结果）**

```
TextField.onChange → scheduleSearch()                    [SearchSectionView]
 ├ generation += 1（每次 await 后 guard current == generation）
 ├ 250ms 防抖
 ├ `/` 前缀 → SlashCommandCatalog 命令模式
 ├ SearchHookRegistry.search（并发：ToolboxSearchSource 模糊匹配工具）
 ├ Task.detached(.utility) FileSearchSource.search（mdfind → FuzzyMatcher 精排）
 │    + FileNameIndex.shared.search（盲区 mmap 索引补漏，v264）
 └ previewQuery → 引擎支持列表时 fetchWebResults（WKWebView + JS 提取）
```

**热键**：`AppBootstrap.registerDefaultHotkeys`（默认表）与 `ToolShortcutStore.restoreAll`（工具自定义）→ `ShortcutRegistry.register` → Carbon 事件 → `handleCarbonEvent` 校 `'FRST'` → 反查 definition → **回主线程**执行 handler。

## 数据流与状态变化

1. **工具启用态**：`toolbox.tool.<id>.enabled`（默认 true）→ `ToolRegistry.enabledTools` 过滤 → `grouped()` 按 `ToolCategory.allCases` 分组。
2. **热键重绑**：`bind` → 已存在走 `reconfigure`（**新组合注册成功才撤旧**，失败保留原绑定）→ 落盘 `shortcuts.bindings` / `toolbox.toolShortcuts`。
3. **文件索引**（FileNameIndex）：状态 `.absent → building → ready`（`@Published state`）；查询 mmap 只读、命中项才解码；缓存落盘，「重建索引」才重扫。
4. **日历**：授权三分支（已授权/未决定/被拒）→ 未授权返回空事件 + 设置页提示入口；`monthDays(for:)` 42 格（周日起点，zh_CN）。
5. **埋点**：工具执行必经 `ToolRegistry.run`（漏则丢 `tool_invocations`/`tool_count`）；搜索执行埋 `searchExecute`/`webSearchOpen`。

## 依赖关系

- **上游**：Carbon HIToolbox（热键）、EventKit（日历）、CoreGraphics/CoreImage（压缩/二维码）、Darwin（getifaddrs）、`/usr/bin/mdfind` 子进程。
- **下游/协作**：`ClipboardManager`（`ingestToolOutput`/剪贴板历史分类数据）；`ServiceLocator.llmService`（translate/summary）；`TranslationToolSession`/`AISummaryAction`（AI 工具）；`FileTypeIconProvider` **已删**（文件图标直接走 NSWorkspace）；`Features/CodePreview`（代码高亮/卡片图从 ToolConverters 迁出后由 `codePreview` 工具引用）；`SettingsPaneRegistry`/`PanelSectionRegistry`（注册）；Storage（`tool_invocations`、`file_type_icons` 表）。
- **通知**：消费 `.frsetFocusPanelSearch`（⌘K）、`frset.openStatistics` 不在此；发出 `.frsetFocusPanelSearch`。

## 异常和取消处理

- **搜索防串台**：`scheduleSearch` 的每个 await 点后 `guard current == generation`（新增异步阶段必须带同样守卫，否则快速输入"旧结果覆盖新结果"）。
- **mdfind 封顶**：读满 512KB 或 EOF 即 `terminate`（单字符查询命中十万级）；Spotlight 语法字符只转义 `\` 与 `"`（`*?[` 是故意保留的通配）。
- **热键冲突**：`conflictsLocked` 只判 keyCode+modifiers 全等（无 ⌘ vs ⌃⌘ 归一化）；失败原因只在 `failureReason`（UI 需展示）。
- **AI 工具未配置**：返回 `.error("请先配置 AI 服务商")`，不抛异常。
- **JSON 工具**：解析失败带行号列号中文说明（`chineseDescription`）。
- **日历未授权**：`events(on:)` 返回空数组，UI 引导授权。

## 性能边界（实测数字，来源标注）

- **`runMdfind`**：512KB 封顶读取（不加会搬十万条结果）；`waitUntilExit` 在 `Task.detached` 后台线程。
- **FileNameIndex**（v264 注释，2026-11-08 实测）：Spotlight 不索引 `.` 开头目录/~/Library/包内部//usr/local//opt（`mdfind -onlyin ~/.workbuddy` 返回空实证）；盲区约 180 万条 ≈ 170MB 路径池，**mmap 而非常驻堆**（页可回收，顺序扫几十毫秒）；只索引盲区不重复索引整盘（整盘 350 万条会翻倍磁盘/内存）。
- **命令面板 `refilter`**：id 序列比对后才发布（v128：防 40 行列表重绘）；`CommandCatalog.build` 每次打开读注册表（若干 NSLock，量小）。
- **`ImageCompressor.compress`**：`maxDimension > 0` 走缩略图路径避免整图解码；≤0 会全解码（大图内存峰值高）。
- **哈希**：`HashGenerator` 纯 Swift 手写（SHA256/MD5/SHA1）——**未用于剪贴板指纹**（那条走 CommonCrypto）；若将来算大文件指纹须先与 `shasum -a 256` 对照三组向量。
- **搜索防抖 250ms** + 并发 `withTaskGroup`（单源失败不影响整体）。

## 已知限制 / 历史坑

1. **热键重绑必须"新注册成功才撤旧"**（`reconfigure` 语义）：反过来"改绑冲突 → 旧热键也没了"。
2. **快捷键录制期必须吞键**（返回 nil），否则同时触发系统快捷键。
3. **工具面板必须独立 `NSWindow`**（v88 + 文件头 2026-10-20 实障）：主面板 homePage 只渲染 search/calendar/clipboard 三区段，`tools` 区段不挂载 → `.sheet` 无宿主 = "点了没反应"。**不要改回 sheet。**
4. **`DoubleTapShortcutCenter` 需要辅助功能权限**：未授权时 global monitor 收不到事件（仅 app 前台时 local 生效）。
5. **`ToolRegistry.run` 必定埋点**：直接调 `tool.execute` 会漏 `tool_invocations`/`tool_count`。
6. **`moveInSearchBar` 的 `toOffset` 是移除前坐标**（向下拖 +1，换算责任在调用方 SearchSettingsPane）；搜索栏**至少保留 1 项**（`removeFromSearchBar` 门控 + `load()` 清洗回默认）。
7. **`FileTypeIconProvider.diskURL` 字符白名单冲突**（`a/b` 与 `a_b` 同文件）——随删除消失，但 `file_type_icons` 表仍在。
8. **`HashGenerator.sha256` 位运算风险**（与历史 `String.sha256` 崩溃同源：消息调度字被掩 32 位），见性能边界。
