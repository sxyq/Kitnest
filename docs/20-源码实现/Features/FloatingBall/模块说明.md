## 模块职责

提供第三类全局入口（与菜单栏、刘海工作台并列，由 `GlobalEntries` 统一开关）：一颗可拖动的悬浮球 + 展开态快捷小窗。小窗是**动作发射器**而非功能实现——宫格里的每个 tile 都 `run(id)` 转发到对应子系统（截图、剪贴板、命令面板、监测、收藏、统计、文件盒、OCR、各 IslandWidget 功能页）。模块本身单文件自包含：设置键族、控制器状态机、SwiftUI 球面/宫格、模块小窗宿主、NSPanel 子类。

## 入口与主要调用链

- **启动**：`StatusBarModule` → `FloatingBallController.shared.start()`——注册 `GlobalEntries.didChangeNotification`（入口开关）、`didResignActive`（失焦收起）、`didChangeScreenParameters`（屏幕变化钳位）三个观察者，随后 `applyEnabledState()`。
- **设置**：`Settings/Panes/FloatingBallSettingsPane` 读写 `FloatingBallSettings` 各键 → `applyEnabledState()`（开关球）/ `applyConfiguration()`（不重建面板，就地刷透明度/尺寸/布局）。
- **展开/收起链**：

```
点击球面 / hover 0.3s（expandOnHover）→ toggleExpanded/expand
  ├─ positionExpanded：球在屏左半 → 小窗贴左边，右半 → 贴右边（垂直以球心对齐，钳入 visibleFrame）
  ├─ selectPage(rememberPage ? 按屏记忆 : defaultPage)
  └─ installExpandedMonitors（本机+全局点击、Esc）+ makeKeyAndOrderFront
点小窗外 / Esc / 失焦(windowDidResignKey) / didResignActive → collapse
  └─ parkBall(halfHidden: autoHideEnabled) → 松手贴边，半隐藏露出 16pt
动作 tile → run(id)：先 collapse，再转发
  ├─ capture → ScreenshotManager.captureRegion（完成后回调 show() 复原球）
  ├─ clipboard/search/tools/monitor/favorites/statistics/archive/ocr → 各自窗口控制器
  └─ IslandWidget(rawValue:) → openModule(widget)：640×520 小窗装 IslandMediaContent /
       AudioMixerPane / CalendarSectionView / ToolboxSectionView / IslandFeatureContent
```

## 数据流与状态变化

- **状态**：`expanded`（小窗开合）、`page`（当前分页）、`ballOrigin`（球锚点）、`parkedHalfHidden`（贴边半隐藏）、`dragOffset`（拖拽中）、`activeDisplayID`（所在屏，`IslandDisplay.id` 稳定键）。
- **拖拽**：`DragGesture(minimumDistance: 4)` → `dragChanged`（按鼠标偏移移窗）→ `dragEnded`（记 `ballOrigin`、换屏更新 `activeDisplayID`、`savePosition` 落盘；**下一 runloop 才清 `dragOffset`**，见历史坑）。
- **位置记忆**：`floatingBall.positions` 按屏键存 `[x, y]`（相对 `visibleFrame.minX/minY`）+ `lastDisplay`；`rememberPosition` 关闭则每次回默认位（屏右缘垂直居中）。读取兼容 legacy 屏键（`NSScreenNumber` 字符串）。
- **分页**：`enabledActions`（按 `orderedActions` 过滤已启用）→ 按 `pageCapacity(窗口尺寸)` 切页；`rememberPage` 时按屏记 `floatingBall.pages`。
- **悬停计时**：`collapseTask` 单个 `DispatchWorkItem` 复用——进入 0.3s 展开、离开 0.85s 收起/半隐藏；拖拽中（`dragOffset != nil`）一律忽略指针事件。

## 异常和取消处理

- **拖拽/展开互斥**：`dragOffset != nil` 时 `toggleExpanded`/`pointerEntered/Left` 直接 return——不会「一松手就误展开」。
- **收起即卸载监视器**：`removeExpandedMonitors` 成对移除本机点击/全局点击/Esc 三个 monitor；`collapse` 反复调用有 `guard expanded` 幂等。
- **面板不释放**：`isReleasedWhenClosed = false`，`windowWillClose` 只清 `moduleWindow.contentView`，避免悬挂指针。
- **屏幕拔插**：`clampToConnectedScreen`——`activeDisplayID` 失效则按当前帧找最大交集屏，重放记忆位置后 `applyConfiguration` 全量钳位。
- **动作失败路径**：`capture` 用回调恢复 `show()`（球在录/截期间 orderOut，不悬空消失）；`run` 对未知 id `guard let widget` 直接返回。

## 性能边界

- 球与小窗共用**同一个** `FloatingBallPanel`（setFrame 换尺寸，不建第二个窗）；`NSHostingView(sizingOptions: [])` 关闭自动尺寸协商。
- `expand`/`collapse` 只是改 `expanded` + setFrame（`animate: true` 系统动画），无自绘帧循环；悬停计时是单个 `DispatchWorkItem`，无 Timer 常驻。
- `start()` 后即使球隐藏也持有 3 个 NotificationCenter 观察者（无事件时不产生成本）；NSEvent 监视器仅展开期间安装。
- 帧率/耗时**未实测**（模块无埋点）。

## 已知限制 / 历史坑

1. **半隐藏以 `visibleFrame` 为界**（v266 注释）：旧代码用 `screen.frame` 算贴边位置，侧边 Dock 常驻时球会退到 Dock 底下（可见 0pt）——`parkBall` 现按 `visibleFrame` 留 16pt。
2. **拖拽释放事件会二次到达球面按钮**（2026-11-21 注释）：`dragEnded` 若同步清 `dragOffset`，同一 mouseUp 还会走 Button 动作把小窗弹开；故 `DispatchQueue.main.async` 延后清空并重算 `pointerLeft`。
3. **悬浮球自己必须能进设置**（v266 注释）：关掉菜单栏/刘海后用户只剩这颗球，若无齿轮按钮就没有配置出口——展开态底部常驻设置入口是「入口统一要求」，不可省。
4. **动作 id 历史兼容**：`toolbox` 是旧 id，`orderedActions`/`enabledActions` 读取时统一映射为 `tools`；动作目录与 `IslandWidget` 全集 + `favorites` 对齐，新增动作先加进 `actions`。
5. **`windowSize`/`ballSize` 的 0 值回退**：UserDefaults 未写时 `double(forKey:)` 为 0，`clamped(to:fallback:)` 以 0 为「未设置」信号回退默认（48pt 球、220×180 窗）——新增数值键必须走同一模式。
6. **展开窗不吃安全区**（`safeAreaRegions = []`）：macOS 13.3+ 下显式清空，防止宿主推入的 safe area 把宫格挤偏。
7. **历史提交极少**（本路径 2 提交）：模块由早期「悬浮入口」演进合并而来，纵向演进需结合 `git log` 中 entry/floating 相关提交（如 `180cbf01`）阅读。
