# TransferDock/Cast —— 投屏模块说明（feature_id: TRANSFER）

> Android 投屏（scrcpy 镜像）+ 设备管理 + 扫码直连 + 外部控制条 + 应用目录。对应源码：`apps/FrsetNext/Sources/Features/TransferDock/Cast/`（**6** 个 `.swift` / **2 547** 行，2026-11-23 实测）。
> 源笔记：`docs/90-历史归档/深度阅读/C3-transfer-cast.md` §3.5（CastView）、§3.11（TransferCastEngines）。本说明按当前源码核实更新。

## 模块职责

Android 设备投屏：scrcpy 镜像启动/画质配置、设备发现与连接（USB/无线/扫码）、scrcpy 外部窗口控制条（返回/桌面/多任务）、锁屏保持（投屏中设备休眠自动唤醒到锁屏页）、手机应用目录（列表/启动）。

## 入口与主要调用链

### 投屏主链路

```
投屏页 onAppear → ScreenCastEngine.findScrcpy + connectedDevices("adb devices")
  → hasDevice → 「开始投屏」
  → ScreenCastEngine.startMirror(serial:maxSize:bitRateMbps:)
      └─ scrcpy --stay-awake --no-power-on [剪贴板参数] --max-size N --video-bit-rate NM --max-fps F --serial S
```

### scrcpy 外部控制条（v264）

```
scrcpy 窗口启动 → CastControlBarController.attach(to: scrcpyWindow)
  → 非激活面板（.nonactivatingPanel）浮在 scrcpy 窗口底部
  → 跟随移动/缩放
  → 点击按钮 → adb -s <serial> shell input keyevent <code>
      [返回 KEYCODE_BACK / 桌面 KEYCODE_HOME / 多任务 KEYCODE_APP_SWITCH]
  → 鼠标远离 → 淡到 35%
```

**为什么贴附面板**：scrcpy 4.1 是 SDL 自绘窗口，无可开启的按钮条、无插件机制，无法往窗口里塞子视图。非激活面板点击不抢 key。

### 锁屏保持（CastScreenKeeper）

```
投屏会话中 → 监听 mWakefulness
  → 检测到 Asleep/Dozing → input keyevent 224 (WAKEUP)
  → 设备亮起到锁屏页 → 镜像显示密码输入页
  → 每次休眠只唤醒一次，不阻止用户主动关屏
```

**注意**：会把物理屏幕也点亮（Android 语义，无法只亮虚拟屏）。

### 扫码直连（v264，Android/ 侧）

```
AdbQrPairing → Mac 生成 S/P → 二维码（WIFI:T:ADB; 前缀）
  → 手机系统相机扫码 → 自动跳无线调试 → enablePairingByQrCode(S, P)
  → adbd 广播 _adb-tls-pairing._tcp → mDNS 发现
  → adb pair + adb connect
```

## 数据流与状态变化

- `CastView`：`devices`（已连设备列表）、`selectedDevice`、`isMirroring`、`toolsExpanded`、`notifTick`（static Timer.publish 6s）
- `ScreenCastEngine`：`connectedDevices` → `adb devices` 解析
- `CastControlBar`：跟随 scrcpy 窗口 frame，鼠标远离淡出
- `DeviceAppCatalog`：`pm list packages -3` → 按 label 排序

## 异常和取消处理

| 场景 | 处理 |
|---|---|
| scrcpy 未安装 | `findScrcpy` 探测 4 个固定路径 + `which`，均失败提示安装 |
| 设备断连 | `connectedDevices` 刷新检测 |
| 非激活面板点击 | `NSApp.activate` + 0.12s 后 `perform`（空投/投屏同款） |
| 通知轮询 | v154 修：`static let notifTick` 共享单例（原 `onReceive` 内 `autoconnect` 叠定时器） |
| adb 命令卡死 | `ADBExtrasEngine.run` 60ms 轮询 + 超时 terminate |

## 已知限制 / 历史坑

1. **scrcpy 外部控制条是 workaround**：scrcpy 不提供插件机制，非激活面板方案在 scrcpy 移动/缩放时需同步跟随。
2. **`CastScreenKeeper` 会点亮物理屏幕**：Android 语义限制。
3. **通知轮询用 `dumpsys notification --noredact`**：文本解析，Android 各版本输出格式可能不同。
4. **`findScrcpy` 每次起 `which`**：投屏页/每次启动镜像/每次剪贴板探测都多一个进程。
5. **v154 修**：通知/存储/应用拉取从"进页面就拉"改为"展开工具区才拉"（不进工具区不起 adb 子进程）。
6. **`ADBWirelessEngine.pair/connect` 带 `-s` 是错的**（host 级命令）：已被 `AdbQrPairing` 取代，但旧代码仍在编译单元。
