### 翻译 Provider 体系

`TranslationProvider` 协议（`translate` / `translateLines` / 可选 `stream`）→ `LLMTranslationProvider`（id `llm`）、`QNWTranslationProvider`（id `qnw`）、`AppleTranslationProvider`（id `apple`）。`TranslationProviderRegistry`：auto 优先级 llm → qnw → apple。`TranslationToolSession` 对外唯一入口。

## 3. 入口与主要调用链

### 3.1 一次聊天请求

```
AIChatView 输入 → AIChatViewModel.send()
  ├─ LLMSessionStore.appendMessage(.user)       [SQLite]
  └─ Task → performStream
        → LLMService.send(messages, stream: true)
            ├─ bumpStat("ai_request_count")
            ├─ withSystemIfNeeded（补默认 system）
            └─ provider.send → LLMTransport.streamBytes
                  ├─ URLSession(ephemeral, delegate)
                  └─ LLMLineBuffer → parseStreamLine → delta
        → 每 delta: MainActor.run { streamingText }
  ├─ 成功 → commit() → appendMessage(.assistant)
  └─ 失败 → finishPartial()（保留部分输出）
```

### 3.2 翻译（三级回落）

```
调用方 → TranslationToolSession.complete/translate/translateDocument
  → TranslationProviderRegistry.resolve(preference)
  → attempt()：依次尝试
      ├─ LLMTranslationProvider → ServiceLocator.llmService
      ├─ QNWTranslationProvider → QNWTranslator（multipart 1200 字切块）
      └─ AppleTranslationProvider → TranslationSession.translate
```

### 3.3 设置页保存凭证

```
AISettingsPane「保存」→ AICredentialCommitCoordinator.commit
  ├─ CredentialStore.setCredential → PBKDF2(10万) → AES-CBC → ai-credentials.bin(0600)
  └─ AICredentialJournalStore.record → JSONL（SHA-256 前 12 位指纹）
  → LLMService.reload()
```

## 6. 异常和取消处理

| 场景 | 处理 |
|---|---|
| 流式取消 | `LLMTransport` `onTermination` → `task.cancel()` + `invalidateAndCancel()` |
| HTTP ≥400 | `didComplete` 统一处理（攒 errorBody），翻成 `LLMError.httpStatus` |
| continuation 只 finish 一次 | `didReceive response` 不抛错，等 `didComplete` 统一处理 |
| 凭证解密失败 | `load()` 空缓存但**不覆盖原文件**（防永久丢 key） |
| 模型列表拉取失败 | 回退陈旧缓存（避免 UI 空掉） |
| 翻译 Provider 全失败 | 抛最后一个错误 |
| Apple 翻译语言包未装 | `.supported` 直接抛错（不弹下载框，产品决策） |
| 360 行数不对齐 | 抛 `formatMismatch` → 回退逐块翻译 |

## 8. 已知限制 / 历史坑

1. **`AIConnectionService.test` 临时改写全局 baseURL**（高）：`defer` 还原，但期间并发 AI 请求会打到候选地址。
2. **360 免 Key 通道默认开启**（高，隐私）：auto 模式未配 Key 时翻译全文发到 `ai.api.360qnw.com`。
3. **Gemini `isTerminalLine` 未实现**：等服务端断连，网关不关连接时等到 60s 超时。
4. **`CredentialStore.setCredential` 同步加密落盘**：主线程调用卡顿（30–80ms）。
5. **`secretCache` 无失效**：换 keystore 后需重启。
6. **`AppleTranslationBridge` 单等待者**：并发翻译先到者以"超时"失败。
7. **`⟦n⟧` 协议行数必须严格相等**：不齐则回退逐块翻译（质量骤降）。
8. **`LLMSessionStore.renameSession/clearAll/snippet` 无调用方**：预留/死代码。
9. **三家 `normalizedBase()` 各写一份**：逻辑相近但版本前缀语义不同。
10. **`QNWTranslator` 用 `URLSession.shared`**：不可取消、不受 `LLMTransport` 管控。
11. **`LLMService` `_provider` 与 `AISettings` 存在时序窗口**：切厂商瞬间可能用旧 provider 发一次请求。
12. **`CustomAIToolStore` 用 Preferences 存 JSON**：工具多/提示词长时 UserDefaults plist 撑大。
