## 1.5 工作区外观对齐（ArcZip 1.2.5，2026-11-23）

取证与差异清单见 `temp/arczip/analysis/`（02 组件清单 / 03 交互 / 04 性能 / 05 现状 / 06 还原清单）。落地要点：

- **窗口**：`fullSizeContentView` + 透明标题栏；根视图 `.ignoresSafeArea(.container, edges: .top)`，46pt 标题行与红绿灯同基线（此前内容被标题栏安全区下推 28pt，标题落在三钮下方一截）。
- **标题行**：左侧文件名 + 下拉箭头（脏标记小圆点）；右侧三档视图分段、删除、绿色保存、搜索。控件尺寸 28–30pt，圆形白底细边；暗色改 7% 白底 + 12% 白边。
- **路径胶囊**：‹ 后退 › 前进 ↑ 上一级 │ 面包屑；≤4 段直接排（宽度随内容），>4 段横向滚动。历史栈 `backStack/forwardStack`（`navigateTo` 记账，`goBack/goForward` 走历史，`goUp` 走父目录）。
- **三档视图**：`ArchiveViewMode`（icons/list/columns），持久化到 `archive.workspace.viewMode`；分栏按「根→当前层」横向铺列。
- **列表**：行高 28、名称 12pt、大小/日期 11pt；`NSStackView` 里加 1pt hugging 的弹性占位，否则四段文字挤在左边（实测值与列头错位约 100pt）。列头改为 名称/大小/修改日期。
- **检查器**：`ArchiveInspectorContent` 值类型 + `ArchiveInspectorPanel`；压缩包态 = 矢量图标 + 名称 + 类型 + 大小/项目/加密/修改日期；条目态 = 预览画布（文本/图片/PDF 首页/占位）+ 四行元信息 + 用默认应用打开。画布点开走原大预览 sheet（文本编辑仍在 sheet 里）。
- **底部操作条**：左状态（共 N 项/已选 M/只读/读取中），右撤销/重做/「…」菜单/紫色「全部解压（所选）」。
- **Mini**：520×430；头部 34pt 图标 + 名称 + 「ZIP 压缩包 · N 个项目」+ 品牌角标 + 置顶；列表行 28pt；底部展开/全部解压 + 紫色解压胶囊。

**未做**（见 06 清单）：渐进式索引、Finder 式无限分栏、悬浮预览音视频与大包滚动暂停、Mini 只读切换保护、进度队列分组、右键菜单补齐、DMG 画布模式。

## 2. 目录与主要类型

### ArchiveCore（enum，纯静态）

全部真实压缩/解压/回写都落到随包 `7zz`（LGPL）子进程。关键能力：
- `isArchive(_:)`：33 种扩展名 + 复合后缀
- `isEditable(_:)`：只有 `zip` / `7z` 可写
- `isHardUnsafeEntryPath(_:)`：**硬拦截**空/`\0`/绝对路径/`~`/UNC/盘符/`..`
- `execute()`：双管道各起读线程 + watchdog 超时 + 注册进任务队列
- `runIn()`：带工作目录（`7zz a` 靠 cwd 保住包内路径）
- Windows 文件名安全：`windowsUnsafeName` / `sanitizeWindowsName` / `uniqueWindowsNames`

### ArchiveTaskQueue（ObservableObject 单例）

`maxConcurrent = 1`（硬约束：同一归档写操作不能并发）。串行泵 + 取消传播 + 进度聚合 + 退出保护（`confirmQuitIfNeeded`）。

### ArchiveBrowserModel（ObservableObject）

条目/选中/层级/搜索/预览/草稿/撤销栈的单一数据源。虚拟目录合成（zip 可能无目录条目）。

## 3. 入口与主要调用链

### 3.1 解压（含路径安全）

```
双击压缩包 / NSServices / Flow 推荐
  → ArchiveCore.extract(url:entry:to:password:)
  → ArchiveTaskQueue.enqueue(.extract)
  → pump() → 全局队列
      ├─ list(includeAuxiliary: true) → isHardUnsafeEntryPath 逐条筛
      │     ├─ 全部不安全 → 拒绝
      │     └─ 部分不安全 → restrictTo（≤1500 条）
      └─ performExtract → 7zz x -y -o<dir> [密码] [辅助排除]
            └─ execute()：双读线程 + watchdog + registerProcess
```

### 3.2 编辑回写

```
文本预览 → TextEditor 编辑 → ⌘S
  → ArchiveBrowserModel.saveDraft
      → ArchiveCore.updateEntry（staging + 7zz a 回写）
      → push(.editText) 到撤销栈
```

### 3.3 拖出到 Finder

```
列表拖行 / 磁贴拖拽
  → NSFilePromiseProvider（delegate 挂 userInfo 保活）
  → Finder 松手 → filePromiseProvider(writePromiseTo:)
      → ArchiveCore.extract(entry:, to: tempDir)    ← 此时才起 7zz
      → moveItem(tempDir/<entry.path> → 目标 URL)
```

### 3.4 创建压缩包

```
NSServices「压缩」/ 面板按钮 / 文件盒「压缩全部…」
  → ArchiveCreateWindowController.show(files:)
  → 选预设/密码/分卷/Windows 名修正
  → ArchiveCore.create
      ├─ 可选：Windows 安全名 staging
      ├─ tar.gz：两趟（a -ttar → a -tgzip）
      └─ 其它：a -t<ext> -mx=N [-v..m]
  → ArchiveSourceHandling：压缩后询问源文件处理
```

## 6. 异常和取消处理

| 场景 | 处理 |
|---|---|
| 7zz 超时 | 300s watchdog `terminate()` |
| 双管道互锁 | 双读线程并行 / "先读后等"（旧写法会与 stderr 缓冲互锁） |
| `Process.run()` 抛错 | 先关父侧写端，否则读线程永不 EOF |
| 取消传播 | `registerProcess` 后 `cancel(taskID)` → `terminate()`；注册前取消也在 `registerProcess` 里查 `isCancelled` |
| 被 terminate 的 7zz | `both()` 统一把"失败 + cancelFlag"改写成「已取消」 |
| 密码错误 | `looksLikePasswordError` 识别 6 种文案 → 自动弹密码框 |
| 路径穿越 | `isHardUnsafeEntryPath` 硬拦截 |
| 退出保护 | `applicationShouldTerminate` → `confirmQuitIfNeeded()`（NSAlert） |
| 双击 ⌘Z | `busy` 门禁防止弹栈错位 |

## 8. 已知限制 / 历史坑

1. **tar.gz 分卷产出错误文件**（高，功能 bug）：`volumeMB > 0` 时先 `7zz a -ttar -v<MB>m` 生成分卷，然后 `guard volumeMB == 0 else { finalize(0, ""); return }` —— 直接报成功但没有 gzip。
2. **`extract` 不安全条目回退**（高，安全）：`unsafe` 非空且安全条目 > 1500 时 `restrict = nil` → 整包解压，穿越条目也会被解出。
3. **`extractEntryToTemp` 临时目录永不清理**（高，磁盘）：每次预览/拖出/缩略图都新建 `frset-archive-<uuid>/` 不删。
4. **`textPreview` 后台线程 `NSImage.lockFocus()`**（高，稳定性）：AppKit 未保证线程安全。
5. **撤销快照目录不清理**（中高）：删除 N 个文件 = N 个临时目录常驻。
6. **`captureSnapshots` 串行起 N 个 7zz**（中）：删 50 个文件可能几十秒。
7. **`visibleEntries` 是 O(n) 计算属性**（中）：10 万条目归档每帧都算。
8. **`installApp` 不做签名校验**（中，安全）：直接写 `/Applications`，无 quarantine 处理。
9. **同一归档写操作必须串行**（`maxConcurrent = 1`）：`7zz a/d/rn` 都是整包重写。
10. **虚拟目录**：zip 可能没有目录条目，层级视图必须自己合成。
11. **`onMain` 必须 async**：`main.sync` 会在 work 体里死锁。
12. **拖出 UTI 必须 conform `public.data`/`public.folder`**：否则 `NSFilePromiseProvider` 抛异常。
