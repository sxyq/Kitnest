## 2. 核心类型说明

### 2.1 `SettingsModule`（`Shell/SettingsModule.swift`）

注册基础页签（general/search/statistics/about 等，其余由各模块自注册：monitor/clipboard/transfer/tools/shortcuts/capture/ai/island/pin/curtain…）；`ServiceLocator.settings = SettingsWindowController.shared`；`AppearanceManager.shared.applyCurrent()`。

### 2.2 `SettingsWindowController` / `SettingsUIState` / `SettingsWindow`（`Shell/SettingsWindowController.swift`）

- `SettingsUIState.selectPane(_:)`：旧 pane id → 三级侧边栏项映射（16+ 条 + `monitor.<module>` 前缀兜底）；未知 id 静默不动。
- **窗口纪律（全工程最危险注释之一，仍现行）**：
  1. 窗口 940×620，`contentMinSize == contentMaxSize == 940×620`，miniaturize/zoom 隐藏（⚠️ 口径：800×530 是 `StatusBar/StatisticsWindowController` 使用统计窗，不是本窗）。
  2. **禁用 `setFrameAutosaveName`**（autosave 旧帧与强制尺寸构成约束更新循环 → `_postWindowNeedsUpdateConstraints` 崩溃）。
  3. **SwiftUI 内容延后一个 runloop 装载**（占位 `NSView()`；同 cycle 建窗 + 首布局抛 NSException）。
  4. 根视图 `.frame(940×620)` == contentRect；`sizingOptions=[]`、`safeAreaRegions=[]`。
- `window` 字段在占位阶段即赋值 → `open()` 会先闪一帧空窗（防崩溃代价，S1）。

### 2.3 三级导航（`Shell/SettingsNavigation.swift`，v27x）

- `SettingsGroup`（`:12`）：一级目录（如「入口与交互」）。
- `SettingsSidebarSection`（`:5`）：二级可折叠小节（只有页面多的目录才分小节）。
- `SettingsPage`（`:160`）：三级页面——选中、搜索与旧链接（`open(pane:)`）仍以页面为单位。
- `SettingsSidebarView`（447 行）渲染该结构；about 置底、页脚常驻「使用手册」。

### 2.4 草稿编辑体系（`Shell/SettingsEditingSession.swift`）

- `SettingsEditableDraft`（`:15`）：页面设置项的可编辑草稿协议。
- `SettingsEditingSession`（`:52`）：**生命周期属于设置窗口；页面只借用草稿，切页不提交**——未保存更改在会话内保留，由窗口决定提交/放弃。
- `SettingsDraftEditor<D, Content>`（`:225`）：通用「草稿 + 保存/放弃」编辑容器（`SettingsDraftEditorContent`）。
- 各页草稿：`CalendarSettingsDraft`（`:22`）、`IslandSettingsDraft`（IslandSettingsPane）、`PinSettingsDraft`、`CurtainSettingsDraft`、Clipboard 的 `ClipboardHistorySettingsDraft`/`ClipboardCaptureSettingsDraft`。

## 3. 关键数据流

### 3.1 打开设置并直达某页（三级映射）

```
ServiceLocator.settings?.open(pane: "island")
  → SettingsWindowController.open(pane:) → ensureWindow（占位 + 下 runloop 装载）
  → uiState.selectPane → applyPaneMapping（id → SettingsPage，三级定位）
  → makeKeyAndOrderFront → SettingsRootView 分发 → IslandSettingsPane（借草稿渲染）
```

### 3.2 草稿编辑流（v27x）

```
进入页面 → SettingsEditingSession 借出草稿（SettingsDraftEditor）
  用户修改 → 只写草稿（不落盘）
  保存 → 草稿 commit（合并本页实际改变的字段）→ 落盘/发通知
  切页 → 不提交（草稿留在会话；窗口关闭/放弃时统一处理）
```

### 3.3 部件设置改一项配置

```
MonitorWidgetsPane setter → FSBarCfgSet → FSBarReloadFromStore() → bump()
  （bump = reloadCache 一次性重读 5 组 C 查询 + revision 自增重绘）
```

### 3.4 导出 / 导入配置

```
导出：performExport → NSSavePanel（主线程）→ 后台 exportAll + 白名单偏好 → JSON .frsetconfig
导入：选文件 → confirmationDialog → performImport
  → 校验 format/version → applyPreferences（白名单）→ importMerge（MAX）
  → 主线程 reloadFromDefaults → refresh → Toast（含 ignored 提示）
```

## 5. 不变量与陷阱（现行）

1. 设置窗尺寸三件套（contentRect == 根 frame == min/maxSize == 940×620）+ 禁 autosave + 延后装载 + `sizingOptions=[]`——四条缺一即复现约束异常崩溃（深读 §6.1–6.4）。
2. `AppearanceManager.isMidnight` 从 `mode` 派生；`apply(.system)` 删键。
3. `MonitorWidgetsPane`：C 查询只在 `onAppear`/`bump`；写配置 `FSBarReloadFromStore + bump` 成对。
4. 菜单栏图标四布尔键互斥（set 先清四键再置一）。
5. `PreferenceValue` 数值走 `objCType`；导入白名单 + `settings.invalid-<key>` 标记；统计导入 MAX 合并；`reloadFromDefaults()` 回主线程。
6. 草稿纪律：**页面只借用草稿、切页不提交**；Island 保存只合并当前页改动字段；预览容器尺寸变化不回写草稿。
7. 自测 `restore` 最后写 `NSPos_*`；`FSBarGlobalSet(key, nil)` = 删键语义依赖引擎。
8. 手册相关（id 全局自增、searchText 解析期固化、divider UUID 不稳定 id）见深读 §6.19–6.21，仍有效。
