## 2. 类型逐个说明

### 2.1 `DiskIndex.swift` —— 索引/扫描/缓存

**模型**

- `DiskNode`（`:27`）：树节点（path/name/isDirectory/size/ownSize/foldedCount/children/isAggregate）。`foldedCount > 0` = 超过每层上限被折叠成「其余 N 项」；`isAggregate` = 折叠聚合节点（带 `foldedCategorySummary` 分类小计）。
- `DiskIndexSnapshot`（`:80`）：整棵快照（scope/rootPath/根节点/统计），`recomputeDataCategories()` 重算分类。
- `DiskDataKind`（`:160`）：五分类——缓存/应用支持/日志/开发资料/其他；`match(path:name:)` 按目录名表（Caches/.npm/node_modules/DerivedData/Xcode.app/Library 下的 Application Support 等）归类。
- `DiskDataCategory`（`:205`）：分类小计 + `pathBytes` 明细；`Accumulator` 合并器；`summarize(_:)` 遍历求分类，两档失败（`foldedDetailsMissing` / `totalMismatch`）都有给用户看的重扫话术。
- `CleanupRecord`（`:317`）：清理历史（时间/路径/字节/成败）。
- `DiskScanScope`（`:325`）：`.home` / `.fullDisk`（v211 起默认整块启动卷，含点开头目录）。

**`DiskIndexScanner`（`:409`，v264 扩容）**

- `maxDepth = 64`（v264：原 6 层漏扫 78%——Xcode 内部与 `~/Library/Application Support/*/Caches` 常在 7 层以下；深度不限正确性只影响内存）。
- `maxNodes = 4_000_000`（原 30 万把 `~` 切成 1/13；400 万覆盖启动卷，折叠后实际 ~40 万节点、峰值 ~150MB，仅窗口打开+手动扫描的几十秒存在）。
- `schemaVersion = 6`（深度/大小口径变化递增；旧缓存作废提示重扫）。
- `childrenPerDirectory = 60`（每层保留上限，超出折叠「其余 N 项」）；`minimumFileBytes = 100MB`（大文件启发式候选）。
- `scan(scope:queue:progress:completion:)`：后台队列后序遍历累加大小、`cancel()` 可取消（`NSLock` 保护标志）、progress 主线程回调（条目数+当前路径）、排除前缀一次算好。2026-11 系优化：复用扫描分类（`24a92ac7`）、跳过删除树无关分支、defer 路径分配（`eaace042`）。

**`DiskIndexStore`（`:659`）**

- 单例 ObservableObject：`snapshot`（didSet 失效候选/清最大目录缓存/`indexRevision += 1`）、`isScanning`/`progressText`/`lastError`/`records`/`scope`（切换即取消+清空+重载缓存）。
- **缓存**：`AppDirectories/disk-index/index-<scope>.json`（实际为**二进制 plist**，v264：40 万节点 JSON 80MB/解码 2~3s → plist 小一半快 3 倍；先 plist 后 JSON 回落，兼容旧缓存）。**先读 schema 版本**，过期大树不再实例化。`cleanup-records.json` 另存清理历史。
- `loadIfNeeded()`：窗口打开只读缓存（后台解码），**不自动扫描**——v211 实测自动扫会立刻弹 TCC 授权模态把主线程堵死；索引由用户点「建立索引/重新扫描」显式触发。
- `reloadFromCache(autoScanIfMissing:)`：带 scope/revision/isScanning 三重校验防旧回调串台。
- 清理候选（`:821`）：`CleanupCandidate`（node/reason/safe）按常见缓存目录名 + 大文件启发式挑选；删除（`:906`）移到废纸篓（`NSWorkspace.recycle` 系），v `0df891b2` 合并废纸篓裁剪的重复树遍历。
- `StorageFormat`（`:1043`）：字节格式化。

### 2.2 `StorageManagerWindow.swift` —— 窗口/布局/手势/交互

**窗口（`StorageManagerWindowController`，`:23`）**

- 单例、**只点按钮才创建**；不进 AppBootstrap、不常驻定时器（「平常不用它」零负载）。1080×720（min 860×560），`fullSizeContentView` + `titleVisibility = .hidden`（v268：工具条顶到窗口上沿，不压红绿灯）。
- v272：`collectionBehavior = [.moveToActiveSpace, .fullScreenAuxiliary]`——修「重启后 `kitnest://storage` 深链开到非活动 Space 静默无效」。
- 深链排障参数：`show(autoScan:drill:openAgent:)`——`kitnest://storage?scan=1`（无人值守扫描）/ `?drill=Users`（下钻一层，`.storageDrillTo`）/ `?agent=1`（直接开 Agent 弹层，`.storageOpenAgent`）。

**`StorageBodyLayout`（`:83`，v268 几何唯一口径）**

- 动机：遮罩「轮廓左移 12pt」、行宽手减 12、卡片宽按 0.50W——三处比例改一处就互相错位。现在全部由该结构推导（`blobTopAnchor=0.50` / `tuck=6` / `seam=12` / `mapLift=96`（v274：液面外轮廓抬到按钮下方）/ `tileInset=81`），改一处全局一致。
- 派生：`mapTop` / `mapSize` / `listWidth(0.48W)` / `cardWidth` / `mapOutline`（`StorageMapShape`）/ `seamOutline`（轮廓左移 seam）/ `listMask()`（列表矩形减去轮廓，清单与液面咬合）。

**手势导航（`StorageSwipeRegion.SwipeView`，`:127`）**

- **28pt 阈值**（`navigateThreshold = 28`）：一次手势累计 28pt 才切一层——「轻扫（约 1/3 掌幅）即可触发，误触率可接受」。
- `NSEvent` 本地 `scrollWheel` monitor；**260ms 静默当作新手势起点**（旧实现只认 phase，部分设备完全划不动）；轴向判定（水平才导航，垂直放行给滚动）；`swipeDidNavigate` 一次手势只触发一次；命中区从 `hitTop`（图块画布上沿）以下起算——搜索/面包屑光条不参与手势。
- 目录浏览区保留同一滚动监听器，切层动画不重建手势状态（注释）。

**`StorageManagerRootView`（`:275`）**

- 分区：顶部大数字+说明+工具条（`:522`）→ 左栏可清理清单（`:618`，`StorageCandidateRow`）→ 正文上方目录操作区（`:754`）→ 正文画布（`:855`，图形/清单遮罩/手势共用局部坐标）→ 「让 Agent 清理」（`:1088`）→ 弹层（`:1208`）→ 动作（`:1317`，下钻/删除/重扫）。
- 「让 Agent 清理」（v212）：`buildAgentPrompt()` 生成结构化提示词（扫描概况 + 可清理候选（✅/⚠️ 分档）+ 占用最大目录 Top + 执行纪律：逐目录 `ls -la`/`du -sh`、结论具体到文件、优先 `mv` 到 `~/.Trash` 不用 `rm -rf`）——交给命令行 AI Agent 执行。

### 2.3 `StorageTreemap.swift` —— 气泡地图（液态挤压堆块）

- `DiskTile`（`:20`）：图块（id/label/size/color/level）。
- `DiskVoronoiLayout`（`:42`）：调 `VoronoiTreemap` 出各块多边形。
- `DiskLayoutCache`（`:150`）：**布局缓存**——hover 改状态会重算 body，17 块 × 90 轮 Voronoi ≈ 2–5ms，逐帧跑会明显掉帧；同输入复用缓存。`0d831fc0` 进一步复用 treemap 轮廓做采样。
- `LiquidTileDrawing`（`:183`，v268 液态压力场）：悬停挤压/回弹位移作用在**共享边采样点**上——所有图块用同一全局压力场函数（振幅 × 高斯衰减），相邻块公共顶点位移完全一致，**接缝不会被撑开**（恢复 `a0a6be85` 删掉的实现并改进）；只插值压力中心与强度三个标量，静态轮廓与文字不参与逐帧向量运算。
- `TilePressStyle`（`:253`，v267）：按压样式只透传 `isPressed`（果冻按压反馈见 `d4c3a844` jelly bounce）。
- `StorageMapShape`（`:262`）：液面外轮廓（手绘曲线，v `ee4a1ae8` 抬到按钮下方）；`StorageTileShape`（`:296`）：深色图块可占用容器（`top` 以下部分）。
- `StorageTreemap`（`:309`）：气泡地图视图本体。

### 2.4 `StorageVoronoi.swift` —— 权重 Voronoi 剖分

`VoronoiTreemap`（`:20`）：按节点大小加权的 Voronoi 迭代布局——初始站点（`:160`）→ 半平面裁剪求单元（`:198`，Sutherland-Hodgman 系）→ 收敛后输出多边形；几何工具（`:408`）。纯枚举命名空间，无状态。

## 3. 关键数据流

### 3.1 扫描 → 索引 → 展示

```
用户点「建立索引/重新扫描」（或深链 ?scan=1）
  → DiskIndexStore.rescan() → DiskIndexScanner.scan(scope:)
      后台 walk（maxDepth 64 / maxNodes 4M / childrenPerDirectory 60 折叠）
      → progress(nodeCount, path) → DiskIndexSnapshot
      → 二进制 plist 写 AppDirectories/disk-index/（schemaVersion 校验）
  → snapshot.didSet：失效清理候选 + 清最大目录缓存
  → UI：大数字 / 气泡地图（Voronoi 布局 → DiskLayoutCache）/ 左栏候选清单
```

### 3.2 手势下钻

```
scrollWheel（StorageSwipeRegion 内）
  → 260ms 静默判新手势 → 轴向判定（水平）→ 累计位移
  → ≥28pt → onNavigate(±1) 切层（一次手势一次）→ 目录树下钻/回退
```

### 3.3 清理

```
左栏勾选候选 → 移到废纸篓（合并树遍历裁剪，0df891b2）→ CleanupRecord 落盘
「让 Agent 清理」→ buildAgentPrompt() → 复制给命令行 Agent 执行
```

## 5. 不变量与陷阱

1. **索引绝不自动扫描**（v211 TCC 教训）：窗口打开只读缓存；扫描必须显式触发，否则一开机就弹全盘访问授权模态。
2. **缓存先读 schema 版本再解码**：过期大树不实例化（防 40 万节点白建）；plist 优先、JSON 回落。
3. **`maxNodes` 是内存闸不是精度闸**（v264 注释）：深度 64 = 不限；调小任何一项都会重现「索引不完整，没有索引到全盘」。
4. **折叠节点的分类摘要**：`isAggregate` 节点必须带 `foldedCategorySummary`，否则 `summarize` 报 `foldedDetailsMissing`；分类合计必须等于根 size（`totalMismatch`）。
5. **`DiskLayoutCache` 不可去**：Voronoi 迭代 2–5ms/次，hover 逐帧重算是掉帧来源。
6. **液态压力场必须作用于共享边采样点**（v268）：按块独立位移会撑开接缝（历史实障）。
7. **`StorageBodyLayout` 是几何唯一口径**（v268）：`tuck/seam/blobTopAnchor/mapLift` 只改这里；绕开它单独算比例必错位。
8. **手势 28pt 阈值 + 260ms 新手势静默 + 一次手势一次导航**：三者共同决定手感；`hitTop` 以上不参与手势（搜索条要能正常滚动/点击）。
9. **深链窗口必须 `.moveToActiveSpace`**（v272）：否则重启后第一条深链落到非活动 Space，`onScreenOnly` 列表里都没有它。
