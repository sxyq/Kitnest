## 2. 类型逐个说明

### 2.1 `CloudDriveProvider` / `CloudDriveLink` / `CloudDriveLinkDetector`（`CloudDriveLink.swift`）

- 8 家：百度 / 阿里 / 移动 / 天翼 / 迅雷 / 夸克 / UC / 123，`tint` 品牌色计算属性。`CloudDriveLink.requiresLogin`（139/189 无游客直链）。
- `CloudDriveLinkDetector`（`:62`）：`exactHosts` 12 条 + `wildcardSuffixes` 12 条；`isSharePage` 特判 123 的 `/123pan/<id>` 与 `share.` 子域（v 用户实证回归项）；静态 `NSDataDetector` + 静态裸域名正则（v101）+ 廉价预筛词（v172，先字符串包含粗筛再跑正则）。
- `detect(in:)`（`:152`）：NSDataDetector 首个网盘 URL → 裸域名兜底 → http 升 https（仅网盘域）；`recentLink(in:scanLimit:)` 默认扫前 40 条按类型过滤逐条 detect。

### 2.2 `CloudLinkBar`（`CloudLinkBar.swift:14`）

- 首页搜索框下方；命中最近条目（**实际 `scanLimit: 20`**，注释写「最近 3 条」——以代码为准）且未被 `dismissedURL` 屏蔽才显示；顶部滑入 + 0.28s 放大脉冲。
- `detectionKey(items:)`（`:28`）：父视图布局动画 key（链接出现/消失驱动日历与列表平滑下移，PanelRootView 消费）。
- `CloudLinkPreviewAction`（`:142`）：预览底部操作条——复制链接 / 打开 / 解析下载。
- `CloudLinkActions.resolve`（`:188`）：日志 + `record(.browserOpen)` + `CloudLinkDownloader.shared.start(link:)`。

### 2.3 `CloudLinkPromptController`（`CloudLinkPrompt.swift:14`，v201 重写）

- 单例；`start()` 幂等：记基线 `lastSeenItemID` → 订阅 `ClipboardManager.shared.$items` + `itemsDidChangeNotification` 双通道 → 2s 后 `catchUpRecentShareLink()`。
- `handle(_:)`：启动 1.5s 静默；只认「启动后入库」（`timestamp - startedAt > 0.3`）；同 id / 同 URL（`lastPromptedURL`）去重；命中即 `open(link)` → **`CloudLinkCenterController.shared.show(link:)`**（不再弹小胶囊）。
- `catchUpRecentShareLink()`：前 20 条、30 分钟内、未提示过的**分享页**链接补开一次（限一条）。

### 2.4 `CloudLinkSettings` / `CloudLinkTester` / `CloudLinkCenterView` / `CloudLinkCenterController`（`CloudLinkCenter.swift`）

- `CloudLinkSettings`（`:14`）：22 个 UserDefaults 键（脚本、目录、超时、UA、引擎、并发、连接、分片、重试、续传、冲突、Finder 显示、aria2 endpoint/token、更新 URL），裸 `UserDefaults.standard`。`maxConcurrent/connectionsPerFile/retryCount` getter 区间钳制（去钳制 → 0 并发死锁 / 16+ 打爆目标站）。`defaultUA(for:)`（`:140`）：百度返回 `pan.baidu.com` 标记串（非合法 UA，仅作约定 hack）、夸克定制、其余 Chrome UA。
- `CloudLinkTester`（`:165`）：5 项检查（链接识别/脚本/可达性/目录/UA）；`probe` 用 `URLSession.ephemeral` GET 分享页，12s 级超时，401/403 warn、200–399 ok（附 `<title>`）。
- `CloudLinkCenterView`（`:318`）：header / 诊断区 / 配置区 / 8 家支持列表 / footer；`@Stored` 镜像 + setter 双写（`CloudLinkSettings` 落盘）——外部改设置本视图不回读的旧风险仍在（R5 遗留）。v204 不再自绘窗底。
- `CloudLinkCenterController`（`:731`）：单实例；`show(link:)` 关旧建新 600×660 窗 + v198 从触发点神灯展开 + v209 原生标题栏。

### 2.5 `CloudLinkDownloader` / `LinkPageResolver`（`CloudLinkDownloader.swift`）

- **三档解析**（文件头注释）：① 直链（34 种扩展名白名单 `isDirectFileURL`）直接 URLSession 下载；② 分享页隐藏 WKWebView 注入 JS 抓直链候选（前 12）+ cookie 同步后下载；③ 失败明确提示并可选开浏览器，**不假装成功**。
- 队列：`@Published items` + `pending` + `active` 并发闸（`maxConcurrent`）；三引擎 builtin / aria2（JSON-RPC，不 spawn 进程）/ copy。重试：`handleFailure` 1.2s 后重插队首，`attempt < retryCount`。
- 落盘：`destination(for:)` 冲突策略 overwrite/skip/rename（`name 2.ext` 递增）；7984cef9 修「同卷暂存后替换同名文件、写盘错误停止重下」；`finish` 成功 Toast + `record(.fileDownload)` + 可选 Finder 显示。
- `LinkPageResolver`（`:388`）：隐藏 WKWebView（1280×900，`websiteDataStore = .default()` 复用登录态）→ `didFinish` +1.2s → `extractLinks`（`a[href]` + 整页正则，去重前 12）→ `syncCookiesFrom`（`:492`，**只同步 `cookieDomains` 白名单域**，327ce89b）→ 12s 超时。
- `sanitize`（`:377`）：trim + `/`→`_`。

## 3. 关键数据流（复制链接 → 下载落盘，v201 后）

```
用户 Cmd+C（任意 app）→ Clipboard 入库（1s 轮询）+ itemsDidChangeNotification
  ├─ CloudLinkPromptController.handle
  │     → detect 命中 → CloudLinkCenterController.show(link:)   [直开解析中心]
  │           → CloudLinkTester.run（5 项诊断，onAppear 自动跑）
  │           → 用户点「解析下载」→ CloudLinkActions.resolve
  └─ CloudLinkBar.link（ObservedObject）→ 首页条出现（日历平滑下移）
        └─ 「解析下载」同上
              → CloudLinkDownloader.start(link:)
                  ├─ copy 引擎 → 复制直链并完成
                  ├─ 直链：enqueueDownload → pump → downloadTask → destination → finish
                  └─ 分享页：LinkPageResolver.resolve
                        ├─ 隐藏 WKWebView load → didFinish +1.2s → JS 抓直链
                        ├─ 成功 → syncCookiesFrom（白名单域）→ enqueueDownload → 下载
                        └─ 失败 → Toast + 可选 openBrowserOnFailure
```

## 5. 不变量与陷阱

1. **分享页解析不得绕过登录**：`extractLinks` 只取页面已有直链；任何「伪造请求/绕风控」改动违反文件头自我约束。
2. **`CloudLinkSettings` 区间钳制不可去**（maxConcurrent/connections/retryCount）。
3. **cookie 同步只走 `cookieDomains` 白名单**（327ce89b）：放开白名单 = 第三方 cookie 灌进全 app（原 R12）。
4. **`downloadsDirectory` 每次访问都 mkdir**（幂等但有 IO 成本）。
5. `CloudLinkBar.detectionKey` 在父视图每次 body 求值都跑 detect（scanLimit 20 + v172 预筛降耗后可接受）。
