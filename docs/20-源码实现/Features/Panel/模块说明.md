## 2. Presentation/ 类型详解

### 2.1 `PanelModule`（enum, `AppModule`，`PanelModule.swift:5`）

- `identifier = "panel"`；`start()` 幂等：`PanelController.shared.prepare()`、注入 `ServiceLocator.panel` 与 `ServiceLocator.panelPreview = PanelPreviewPresenterAdapter()`。
- v206 起无副作用探针（原 `FRSET_JSON_PROBE` 已删）。被依赖：App 总控（ModuleRegistry）。

### 2.2 `PanelPresentationState`（ObservableObject，`PanelController.swift:6`）

- `@Published visible` / `anchored` / `originUnit`（v197：展开锚点的面板内归一化坐标，0,0=左上）+ `anchorRect: NSRect?`（v237：本次展开用的图标屏幕矩形，收起时复用同一格子）。
- 由 `PanelController` 私有持有，`@ObservedObject` 传给根视图；不落盘。
- 注意：动画已挪到窗口内容层（v197），根视图不再用它做 scaleEffect——它现在只驱动顶部三角与布局让位。

### 2.3 `PanelController`（NSObject, `PanelControlling`, `NSWindowDelegate`，`PanelController.swift:21`）

- **职责**：面板窗口全部生命周期与开合策略；`ServiceLocator.panel`。`static let shared` 常驻；`prepare()` 幂等建窗，`panel` 只 `orderOut` 不销毁。
- **意图位（v282，`intendedVisible`）**：开合方向的唯一真值。以前读 `panel.isVisible`，而预热/神灯停靠/收起动画中它与「是否打开」不一致 → 连点抽搐、「点了没反应」。现在 `toggle` 只看意图位，物理状态只决定怎么播动画。
- **收起后动作队列（v282，`pendingHideCompletions`）**：`hide(completion:)` 把截图类动作排队，`performHide` 的 `finish` 里统一放掉；`show` 时若队列非空也当场放掉（收起被打断时不卡死动作）。
- **预热（v173/v279）**：`scheduleWarmup()` 启动 2s 后 `warmupPanel()`；另有 `prewarmAtLaunch()`（AppBootstrap 启动 3s 调）。姿势：窗口停到屏幕上沿之外（`parkOrigin`，alpha 保持 1、真实参与显示周期）→ `presentation.visible=true` 强制布局 → 0.12s 后（下一轮 runloop）收尾 `orderOut`。**绝不再嵌套 `RunLoop.run`**（v173 复盘：重入 display cycle → NSInternalInconsistencyException → SIGABRT）。`warmupToken` 作废在途收尾；`lastWarmupAt` 20s 去重；`cancelWarmup()` 在真打开时兜底。`probe.warmup=NO` 可整体关闭。
- **开合（v237/v244/v282）**：
  - `show(atAnchor:)`（`PanelController.swift:246`）：意图位=true → `cancelWarmup` → 放掉 pending → 埋点 → `MonitorPopoutWindowController.dismissPopout()` 互斥 → 尺寸校准 → 若神灯启用先把窗停屏外抓快照 → 透明态完成首布局 → `CATransaction.flush()` 一次提交 → `GenieWarp.playIn`（22pt 格子漏斗展开）；失败退 `WindowReveal.playIn` 缩放。`finishShow` 兜底补 `orderFront` 并 `MonitorSampler.shared.setHomePanelActive(true)`。
  - `hide(completion:)`（`PanelController.swift:441`）：意图位=false → 等预览关闭（`MainPanelPreviewPopoverCoordinator.dismiss(.panelCollapse)`）再 `performHide`；0.6s 超时兜底（防预览回调丢失）；`GenieWarp.isOpening` 时立刻掉头不等预览。`performHide`（`:492`）用 `presentation.anchorRect` 吸回同一格子（「从哪来、回哪去」），完成后 `setHomePanelActive(false)` + 执行排队动作。`hideGeneration` 防旧回调串台。
- **尺寸**：宽度下限 320（`prepare`/`syncPanelFrameToPersonalization`/`persistSize` 三处钳制，v73 回归修复）；v260 修 `panelWidth` 默认值类型（`Double` 字面量，`as? Int` 必败导致设置无效）。`syncPanelFrameToPersonalization` v203 把材质重套挪到尺寸 guard 之前（否则「材质切换无效」）。
- **失焦收起白名单**（`windowDidResignKey`，`PanelController.swift:614` + `TransientWindowCenter` 仲裁）：sheet、`frset.clipboardPreview`、`frset.panelPreviewPopover`、v166.5 `frset.panelChild`（`PanelChildWindow.isPanelChild`，SwiftUI popover 打标）。排障 pin：`FRSET_PANEL_PIN=1` 或 `--panel-pin`（`debugPinned`）。
- **`isPinned`**：读写 `panelPinned`，同步 `panel.level`；开启时 `record(.alwaysOnTopEnable)`。

### 2.4 `FloatingPanel`（NSPanel，`FloatingPanel.swift:7`）

- nonactivating/borderless；`hosting.sizingOptions = []` + `safeAreaRegions = []` 不可去掉（防 SwiftUI fitting 反压窗口尺寸，v73 拉锯根因）。
- v166.5 起玻璃走 `LiquidGlass.makeView`（macOS 26 真 `NSGlassEffectView`，旧系统回退）；玻璃装在普通 `NSView` 容器里（v198：`NSGlassEffectView` 层不吃 transform 动画，动容器层才能整块缩放）。tint 随外观（深色近无色，避免深色壁纸脏灰）。
- `applyPersonalizedMaterial()`（`:107`）v282：按窗口实例缓存材质签名（圆角+reduceTransparency），**签名不变不重套**——每次 show 前重套会让 AppKit 作废整窗玻璃采样，是首屏顿挫主源之一。2026-11-23 起签名不含「背景材质」（该开关只管内容卡片）。
- `init?(coder:)`：`fatalError`（对齐原作 nib 陷阱）。

### 2.5 `PanelChildWindow`（`PanelChildWindow.swift:43`）

- 问题：SwiftUI `.popover` 起的窗口没有 identifier，被 `windowDidResignKey` 判成「点了外面」→ 面板连 popover 一起收（「闪一下就没了」）。
- 方案：内容宿主 `panelChildWindow()` modifier 挂 0×0 `TagView`，入窗时把 `frset.panelChild` 写到所在 `NSWindow.identifier`；`PanelChildWindow.isPanelChild(_:)` 按前缀放行。popover 窗口可能换实例，`viewDidMoveToWindow` 每次重打。

### 2.6 `PanelSegments` / `GlobalEntries`（`PanelSegments.swift`）

- **PanelSegments**（v177/v181）：四页显隐键 `panel.segment.home|monitor|transfer|cast`（`@AppStorage` 直绑）+ 顺序串 `panel.segment.order`（CSV，`decode`/`encode` 总是补全四页，防新增页被老顺序串吃掉）。`migrateLegacyVisibility()` 迁移旧键 `showSystemStatus` / `panelTransferDock`。旧总开关 `panel.transferDock`（`transferFeatureEnabled`）v181 起只表示「文件中转功能启用与否」，与分段显隐解耦、AND 门控（v260：功能关则中转/投屏分段一起消失）。
- **GlobalEntries**（v192）：菜单栏入口开关 `entry.home` / `entry.monitorPopout` / `entry.statsBar` + `FloatingBallSettings.enabledKey`；默认前三开、悬浮球关。变更发 `FrsetNext.GlobalEntries.didChange`（菜单栏菜单缓存的是 NSMenu 结构，需重建）。与 PanelSegments 独立：关顶部分段不影响独立窗入口。

## 4. 关键数据流

### 4.1 状态栏点击 → 面板神灯展开

```
NSStatusItem 点击 → StatusBar → ServiceLocator.panel.toggle(atAnchor:)
  → PanelController.show(atAnchor:)                    [意图位=true]
      ├─ cancelWarmup / 放掉 pendingHideCompletions
      ├─ StatisticsManager.shared.record(.panelOpen)
      ├─ MonitorPopoutWindowController.dismissPopout()  [互斥]
      ├─ syncPanelFrameToPersonalization() → 材质签名缓存 → 尺寸 guard
      ├─ GenieWarp：窗口停屏外 → 透明态 layout+display → CATransaction.flush
      ├─ GenieWarp.playIn(slot=锚点 22pt 格子)  ←失败→ WindowReveal.playIn
      ├─ TransientWindowCenter.register(allowsClickIn: sheet/预览/panelChild)
      └─ finishShow → MonitorSampler.shared.setHomePanelActive(true)
```

### 4.2 收起链（多入口、单收口）

```
点外/失焦/Esc/程序化 → TransientWindowCenter / hide(completion:)
  → 意图位=false → Coordinator.dismiss(.panelCollapse) 等预览关（0.6s 兜底）
  → performHide：GenieWarp.playOut 吸回 presentation.anchorRect 同一格
  → finish：orderOut + setHomePanelActive(false) + 执行 pendingHideCompletions
```

### 4.3 悬停一行 → hover 预览（详见 Preview/模块说明.md）

```
行 onHover → ServiceLocator.panelPreview.rowHover → Coordinator
  → 0.35s + hover-intent → present() → ClipboardPreviewWindowController.show
  → 点外/Esc/hoverOut/条目删除 → dismiss → closeAnimated（v197 收回动画）
  → handlePreviewWindowDidClose（唯一清理点）+ 抑制期等鼠标移动
```

### 4.4 复制网盘链接 → 直开解析中心（v201）

```
Clipboard 入库 → CloudLinkPromptController（$items + itemsDidChangeNotification 双通道）
  → detect 命中（启动 1.5s 静默；只认启动后入库；URL 去重 lastPromptedURL）
  → CloudLinkCenterController.shared.show(link:)     [直接开窗，不再弹小胶囊]
```

## 6. 不变量与陷阱（现行）

1. **缩放只发生一处**：窗口尺寸负责缩放，内容恒 1:1 填充（`PanelRootView` 134–138 注释纪律）。破坏 → 360×0.9=324 的「比例怪 + hosting 反压拉锯」（v73）。
2. **`NSHostingView.sizingOptions=[]` + `safeAreaRegions=[]` 不可去掉**（`FloatingPanel.swift:46`）。
3. **面板宽度下限 320**：`prepare` / `sync` / `persistSize` 三处钳制，任一放宽 → 窄值写进偏好永久污染（v73）。
4. **按页实例化纪律**：隐藏页不得回退到 opacity(0) ZStack（v136：每帧合成 4 页 + 隐藏页 body 重算）。
5. **意图位是开合方向唯一真值**（v282）：任何 `toggle`/`show`/`hide` 不得读 `panel.isVisible` 决定方向——预热/神灯停靠/收起中它都不可信。
6. **预热不得嵌套 RunLoop、不得 alpha=0**（v173 崩溃复盘）：两条都踩过 SIGABRT。
7. **`applyPersonalizedMaterial` 必须签名去重**（v282）：每次 show 前无条件重套 = 整窗玻璃重采样压在点击路径。
8. **神灯抓快照需「已渲染且不透明」**（v244）：先透明上屏会闪一整块；停屏外抓图有效。`skipInitialDisplay` 路径必须配 `CATransaction.flush()` 提交一帧（v282）。
9. **`hide(completion:)` 的动作必须排队而非丢弃**（v282）：截图/钉图「先收面板再执行」，直接 return = 点了没反应。
10. **失焦白名单四条**：sheet / `frset.clipboardPreview` / `frset.panelPreviewPopover` / `frset.panelChild`（前缀）。新增「面板弹出的窗口」必须打 identifier 或走 `panelChildWindow()`，否则一点就收面板。
11. **`handlePreviewWindowDidClose` 是预览唯一清理点**（详见 Preview/模块说明.md）；预览关闭只能 `close()` 系（borderless 的 `performClose` 静默无效，v83）。
12. **分段显隐是「个性化 ∩ 常规功能」AND**（v260）：只改一处不生效时先查另一处。
