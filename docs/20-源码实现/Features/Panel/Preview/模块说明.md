## 2. 类型逐个说明

### 2.1 `MainPanelPreviewPopoverCoordinator`（`MainPanelPreviewPopoverCoordinator.swift:60`）

- **单例 + 单槽**（`private var slot: MainPanelPreviewPopoverSlot`）：同屏只有一个预览；v206 起切换条目**复用当前窗**（`present` 的 `display` 闭包直接替换 `contentModel`），尺寸连续变化不闪旧关新开。
- **触发路**：
  - hover（`rowHover`，`:301`）：总开关 `hoverPreviewInMainWindowEnabled`/`…FloatingClipboardEnabled` → 抑制期拦截 → 0.35s `hoverPreviewOpenWorkItem` + hover-intent 0.06s → `present`。移出 `scheduleHoverClose(itemID:)`（v 新增条目校验与 `restoreAfterHover` 选中恢复回调）。
  - 空格（`requestKeyboardPreview`，`:354`）：0.30s 延时；首次消费 `clipboard_keyboard_preview_hint_consumed` 一次性提示。
  - 单击 / 程序：`present` 直接调用；`presentFile(url:)`（`:256`）支持 Finder 等外部磁盘文件预览（`FileHoverPreviewController.itemID` 造内存条目）。
- **`present(...)`（`:162`）**：支持 `anchorRectInScreen + sourceWindow`（外部窗口锚定）与旧 `anchorRectInWindow/anchorView` 两套口径。`previewPinned && hasActivePreview` 时拒新（固定态防抢窗）。文件条目两段式：先 `buildModel(false)` 出窗（`fileText == .loading`），后台 `global(.userInitiated)` 读完再 `display(buildModel(true))`——**不再主线程同步读全文**。
- **关闭仲裁**：`dismiss(reason:completion:)`（`:271`）——completion 链式串接（`pendingCloseCompletion`）；📌 固定时拒 hoverOut/panelCollapse/scrolledOutOfViewport/systemInterruption。`closeSlot` 走 `windowController.closeAnimated()`（v197 收回动画）；**唯一清理点** `handlePreviewWindowDidClose`（`:580`）：清槽/恢复/抑制期/卸 Esc/埋点/执行 completion。
- **点外监听（`:409`）**：全局+本地双 monitor；本地侧对「预览窗本体 / `RowHostingView` / `IslandFileDragView` 命中链 / Island 面板内条目」放行（行单击交给 `present` 切换内容）。Esc monitor（`:451`）编辑态放行。
- **抑制期（F3）**：关闭后 `suppressHoverUntilMouseMove`，`mouseMoved/leftMouseDragged/otherMouseDragged` 本地 monitor 解除。
- **`scheduleHoverClose` 兜底（`:533`）**：SwiftUI `onHover` 在 nonactivating 面板 / NSViewRepresentable 上方会丢——触发时若 `NSEvent.mouseLocation` 仍在预览窗 frame 内则递归重排（0.25s 轻轮询）。
- **滚动记忆**：`rememberMarkdownScroll`/`markdownScrollState`（键 = dedupeKey，内存字典，无上限）。
- **可调参数**：`hoverPreviewOpenDelay=0.35`、`hoverPreviewCloseDelay=0.25`、`activeHoverIntentThreshold=0.06`、`keyboardPreviewPresentationDelay=0.30`、`previewLoadingIndicatorDelay=0.40`、`maxPopoverHeight=620`、`popoverWidth=560`、代码尺寸阶梯等。
- **`MainPanelPreviewPopoverSlot`（`:31`）**：`state`(idle/presenting/presented/closing) + `contentModel` + `ClipboardPreviewWindowController` + `isEditing`（编辑中取消 hover 关闭）。

- `static var scale = 1.5` 全局可变系数（字号/间距统一乘它）。

### 2.5 `MermaidRenderer`（`MermaidRenderer.swift`）

- 单例；`image(for:maxWidth:)` NSCache（24 项/16MB）+ `autoreleasepool`。
- `parseStatement` **必须纯函数**（inout+闭包会触发 Swift 独占访问冲突崩溃，注释明示）；绘制用 `NSImage(size:flipped:)` 延迟绘制，禁 `lockFocus`（NSHostingView 桥接期 Fatal access conflict，2026-10-18 实测）。
- `draw`：最长路径分层（环状图跑满 `nodes*2` 轮上限后放弃收敛，刻意保护）；超宽按 `maxWidth`（默认 520）内容缩放（画布尺寸不变）。

### 2.6 `DocumentInlinePreview`（`DocumentInlinePreview.swift:8`，新增）

- `supportedExtensions`：doc/docx/docm/dot/dotx/rtf/rtfd/odt/webarchive、ppt/pptx/…/key/odp、xls/…/numbers/ods/csv、pages/pdf/epub。
- Word 系（`.docFormat`/`.officeOpenXML`）→ `WordInlineContent`：`Task.detached` 读 `NSAttributedString`；docx 额外走 `ArchiveCore`（7zz）提取 `word/document.xml` → `restoreOpenXMLFormatting`（修正系统导入器把 `w:b/i val=0` 当开启、忽略 `tblGrid` 的两个缺陷——按 run 移除粗/斜 trait、按 tblGrid 重算表格列百分比宽 + vAlign）。

### 2.7 `PanelPreviewPreferences` / `PreviewPopoverDataBridge`（`PanelPreviewPreferences.swift`）

- 与 Clipboard 的编译期隔离层：`fullTextProvider / ocrTextProvider / saveOCRTextProvider / recognizeImageProvider / richTextProvider` 闭包，App 总控接线。
- 未接线兜底仍存在（`fullText` 同步读盘；`richTextAttributed` 相对路径 bug——未接线时基本必然失败退化启发式）；`recognizeImage` 抛 `PreviewDataBridgeError.notWired`。**接线后 provider 优先，正常路径不再走兜底**。

## 3. 关键数据流

### 3.1 hover 触发到出窗

```
行 onHover(true) [Clipboard] → ServiceLocator.panelPreview.rowHover
  → Coordinator.rowHover：开关/抑制期 → 0.35s WorkItem + hover-intent 0.06s
  → present(for:anchor…)
      ├─ file 条目：buildModel(false) 先出窗 → 后台读文件 → display(buildModel(true))
      ├─ 其它：fullText（provider 优先）→ buildModel(true) → display
      └─ display：复用槽/建 Slot → windowController.show(anchorRectInScreen:…)
            → installOutsideClickMonitor + installEscapeMonitor → 埋点 exposed
```

### 3.2 关闭链

```
hoverOut / Esc / 点外 / itemRemoved / panelCollapse / programmatic
  → dismiss(reason) → closeSlot → windowController.closeAnimated()
  → onWindowClosed → handlePreviewWindowDidClose（清槽 + 抑制期 + completion 链）
面板收起：PanelController.hide 等 completion（0.6s 兜底）→ performHide
```

### 3.3 Markdown 预览渲染（异步化后）

```
PreviewMarkdownTextView / MarkdownFilePreviewBody
  → .task + Task.detached { PreviewMarkdownRenderer.renderBody(text) }
  → MarkdownPreviewBody：TOC(可关) + PreviewTextViewRepresentable
       ├─ scrollRequest → scrollToCharacter → scrollToVisible
       └─ boundsDidChange → rememberMarkdownScroll(dedupeKey) → 重开恢复
```

## 5. 不变量与陷阱

1. **槽只有一个**：`present` 必须先复用/关旧槽再建新槽；两窗并存会「叉号关错窗」。
2. **预览关闭只能走 `close()`/`closeAnimated()`**：borderless hover 窗 `performClose` 静默无效（v83 孤儿窗）。
3. **`handlePreviewWindowDidClose` 是唯一清理点**：绕过（直接 orderOut）会漏抑制期/监控卸载/completion → 面板收起卡住 + 悬停立即复弹。
4. **鼠标位置兜底与 `popoverHoverChanged` 双保险不可去其一**（v71 实障：鼠标移向预览想复制 OCR，预览先消失）。
5. **`parseStatement`（Mermaid）必须纯函数**；Mermaid 绘制不得在 `body/init` 里 `lockFocus`。
6. **`PreviewMarkdownRenderer.scale` 与任何高度估算必须同源**（现 `estimatedPopoverHeight` 已无调用方，遗留风险仅当重新接线时）。
7. **`cachedRe` 静态字典非线程安全**：渲染搬到后台队列前需加锁或改 actor。
8. **固定（📌）模式**：hoverOut/panelCollapse/scrolledOutOfViewport/systemInterruption 被拒，只留 Esc/叉号/itemRemoved/programmatic。

## 6. 重复实现 / 风险（现行）

| 项 | 说明 |
|---|---|
| 行号标尺 `PreviewLineNumberRulerView` vs `CodeLineNumberRulerView`（AI/Code） | 两套私有实现并存（职责相邻） |
| 文件缩略图 `PreviewFileThumbnailLoader` vs `PreviewImageLoader` | 两条独立 NSCache，同一张图可能解码两次 |
| JSON pretty-print | `PreviewJSONTextView` 与 `JSONRawView.pretty` 各自往返（规模已随内联合一缓解） |
| 网盘链接提取 | `CloudLinkBar.detectionKey` 在 body 求值时跑 detect（量级：scanLimit 20，廉价预筛 v172 已降耗） |

| `richTextAttributed` 未接线兜底把相对路径当绝对路径 | 桥内注释自认；正常接线后不触发 |
