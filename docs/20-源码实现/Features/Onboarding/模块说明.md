## 2. 类型逐个说明

### 2.1 `PermissionKind` / `PermissionStatus` / `PermissionCenter`（`PermissionCenter.swift`）

- `PermissionKind`（4 case）：`title/symbol/purpose/features/isCore/settingsFragment/settingsURL`（`x-apple.systempreferences:...?Privacy_XXX`）。
- `PermissionStatus`：granted/denied/notDetermined/unsupported + `label/symbol/tint`。
- `PermissionCenter`（单例 ObservableObject）：`refreshAll()` 走 `quickStatus`（屏幕录制 `CGPreflight` **可能假阴性**）；`probeScreenRecording()` 是**唯一权威判据**（macOS 14+ `SCShareableContent` 能枚举到显示器才算授权）；`request(_:completion:)` 四路（`CGRequestScreenCaptureAccess` / `AXIsProcessTrustedWithOptions` / `AVCaptureDevice.requestAccess` / `EKEventStore.requestAccess`；日历用 rawValue 兼容 macOS 14 `.fullAccess/.writeOnly`）。
- **不变量**：屏幕录制/辅助功能授权后系统**无回调**——只能靠请求后 1.2s 延迟刷新 + `didBecomeActiveNotification` 重探；`isCore`（屏幕录制+辅助功能）驱动欢迎页横幅。
- 风险：`PermissionCenter.init` 构造期同步探测 4 类权限（S17，启动路径毫秒级开销）；`PermissionStatus.unsupported` 仅日历 `@unknown default` 产生。

### 2.6 `QuickTutorialController`（353 行，新增）★

- **三课**（`QuickTutorial`）：`clipboard`（找回刚刚复制的内容）/ `screenshot`（截图并复制或识别文字）/ `transfer`（把文件发送到手机）；各带 SF Symbol。
- **状态机**：`QuickTutorialStatus`（notStarted/inProgress/completed）+ 每课步骤号（`step(_:)`/`setStep`），持久化（`onboarding.quickTutorial.selected` 及每课步骤键）。
- **完成判定走通知**（跨模块解耦）：`.tutorialScreenshotCaptured`（记录 capturePath、步骤 1→2）→ `.tutorialScreenshotCopied` / `.tutorialScreenshotOCRCompleted`（按 capturePath 匹配后 complete；OCR 文案按 `CaptureOCRNotify.isSilent` 分叉）；`.tutorialFileTransferCompleted`（按 targetPath 匹配）。通知名统一 `Kitnest.tutorial.*` 前缀。
- 辅助：`message` 引导文案、clipboard 打开重试（`clipboardOpenRetry` DispatchWorkItem）、Timer 驱动的演示/计时。

## 3. 关键数据流

### 3.1 权限引导

```
PermissionGuideWindowController.show()
  → PermissionCenter.refreshAll()（CGPreflight / AXIsProcessTrusted / AVFoundation / EventKit）
  → probeScreenRecording()（SCShareableContent 实探，修 preflight 假阴性）
  → PermissionGuideView 4 卡
用户点「授权」→ request(kind)（四路 API）→ 1.2s 后刷新 + 回调
从系统设置切回 → didBecomeActive → refreshAll + probeScreenRecording
```

### 3.2 首启欢迎

```
启动 → WelcomeWindowController.shouldPresentOnLaunch
  （onboardingWelcomeSeenVersion < 1 → 弹 760×620）
「开始使用」→ 写 seenVersion + close；Esc/叉号 → 只 close（下次还弹）
「权限引导」按钮 → PermissionGuideWindowController.show()
```

### 3.3 快速上手教程

```
用户选课（QuickTutorialController.selected 落盘）
  → 课程 UI 引导操作（如去截图）
  → 功能模块发 Kitnest.tutorial.* 通知（带 path/targetPath）
  → 控制器按步骤机匹配 → 推进步骤/complete（文案按静默设置分叉）
```

## 5. 不变量与陷阱

1. **`probeScreenRecording` 是屏幕录制唯一权威判据**：`CGPreflight` 自签/重签名下假阴性。
2. **授权无回调**：1.2s 延迟刷新 + `didBecomeActive` 重探缺一不可，否则「授权了但界面仍显示未授权」。
3. **三个窗关闭语义不同且不可混**：Welcome 的 Esc 不写 seen（稍后再说）；WhatsNew 的叉号/Esc **必须** `markSeen`；PermissionGuide 无 seen。
4. 建窗纪律四件套（固定尺寸/占位视图延后装载/`sizingOptions=[]`/`safeAreaRegions=[]`）与设置窗同族，缺一即约束异常。
5. 教程步骤键与通知 userInfo 的 path 匹配（capturePath/targetPath）是完成判定的锚——通知不带路径或路径不匹配不推进。
