# 录屏（feature_id: RECORDING）

> 屏幕录制五件套：整屏/区域录制、摄像头画中画、显示按键、点击动画、忽略指定 App，外加录后裁剪导出。对应源码：`apps/FrsetNext/Sources/Features/Recording/`（10 个文件 / 2198 行，2026-11-23 实测）

## 模块职责

「录屏」是一个独立 AppModule（`RecordingModule`，identifier `recording`）：一条 SCStream 采集屏幕（+可选系统声/麦克风），默认**原始帧直通**写 H.264 MP4；只有开启摄像头画中画 / 显示按键 / 点击动画时才走 Core Image 小画布合成。录制结束自动进「录屏编辑」窗（剪头剪尾 / 静音 / 导出）。设置面挂在「截图与钉图」总页（`CaptureHubPane` case `.recording` → `RecordingSettingsPane`），与截图同属一个工作流。

## 入口与主要调用链

1. **全局快捷键**（`AppBootstrap` 默认热键表）：`recordingToggle` → `ScreenRecorder.toggleRecording()`（活动则停止并编辑，否则录整屏）；`recordingRegion` → `startRegionRecording()`。
2. **刘海工作台**（`IslandFeatureContent` case `.recording` → `IslandRecordingContent`）：录整屏 / 录区域 / 打开设置（`ServiceLocator.settings?.open(pane: "recording")`，经 `performOutside` 先收岛）。
3. **主面板区段**（`RecordingModule.start` 注册的 `RecordingPanelSection`）与**设置页**（`CaptureHubPane` → `RecordingSettingsPane`）：状态灯 + 暂停/停止/录制按钮。

核心链路：

```
start(options)
  ├─ ScreenshotManager.ensureScreenRecordingPermission（屏幕录制权限）
  ├─ 按需申请麦克风/摄像头权限 → 未授权则降级并记 unavailableFeatures
  ├─ RecordingInputMonitor.start（辅助功能权限；失败则关按键/点击叠加）
  ├─ makeStream：SCShareableContent → SCContentFilter（按 excludedBundleIDs 排除 App）
  │    → SCStreamConfiguration（fps / sourceRect 显示器本地坐标 / capturesAudio）
  ├─ RecordingPipeline.prepareWriter：AVAssetWriter H.264（码率 = clamp(w*h*0.12, 4M, 24M)）
  ├─ SCStream.startCapture → state=.recording + HUD.show()
  └─ stop()：stopCapture → pipeline.finish（markAsFinished → finishWriting）
       → 成功文件 → RecordingEditorController.open(url:)（裁剪/静音/导出）
```

## 数据流与状态变化

- **状态机**：`idle → preparing → recording ⇄ paused → finishing → idle`。`preparing` 期间每次 await 后都有 `guard state == .preparing` 检查（用户可中途取消）；`stop()` 在 preparing 态直接返回 nil 并 Toast「已取消录屏准备」。
- **帧流**：SCStream `.screen` → `handleVideo`——无叠加时 `videoInput.append(sampleBuffer)` 直通；有叠加时从 `pixelBufferPool` 取目标帧，`RecordingCompositor.composite`（摄像头帧锁保护的 `latestCamera` + `currentKeys/currentClicks`）→ `CIContext.render` → `adaptor.append`。`.audio` / 麦克风 → `handleAudio`（`sessionStarted && !paused` 才写）。
- **暂停语义**：丢帧但 PTS 继续走（播放表现为画面停住，无需重排时间轴）；`setPaused` 在 `sampleQueue` 上翻转标志（与音视频写盘同队列，见历史坑）。
- **计时**：0.2s Timer 刷 `elapsed`（`accumulated + Date().timeIntervalSince(startedAt)`），HUD 随之刷新；HUD 每次刷新跟随鼠标所在屏定位。

## 异常和取消处理

- **权限降级不中断**：麦克风/摄像头/输入监听任一未授权 → 对应功能关闭并写入 `unavailableFeatures`（橙色提示 + Toast），录制继续。
- **SCStream 中止**：`stream(_:didStopWithError:)` → `onStopped` → 置 `errorText`「录制中断：…」并自动 `stop()`——已写入的部分仍会 `finishWriting` 保存（Toast「已保存中断前视频」）。
- **写盘失败**：`prepareWriter` 抛 `RecordingError.writerFailed`；`finishWriting` 未 completed → 返回 nil → Toast「录制文件写入失败」+ 失败触觉。
- **找不到显示器**：`makeStream` 抛 `RecordingError.noDisplay`。
- **导出**：先写同目录临时文件 `Recording-export-<UUID>.mp4`，成功后 `replaceItemAt`/`moveItem` 到目标（不覆盖已有目标文件直到成功），失败/取消清理临时文件。
- **启动失败清理**：catch 分支统一 `RecordingInputMonitor.shared.stop()` + `pipeline?.finish()` + 状态复位。

## 性能边界

- 码率自动：`clamp(w*h*0.12, 4Mbps, 24Mbps)`，H.264 High，关键帧间隔 60（`prepareWriter` 内实测日志输出 kbps）。
- 合成刻意只画**小画布**：按键条 ~720×110、点击环 160×160（源码注释：4K 全画布一帧 33MB，光分配就能把帧率打下来）。
- 事件保留：按键 1.6s / 点击 0.65s（TTL）；缓冲上限 keys 6 / clicks 12；同一键 0.08s 去重（防按住重复 keyDown）。
- SCStream `queueDepth=6`；采集/写盘队列 `kitnest.recording.stream`（userInitiated）+ `kitnest.recording.pipeline` + `kitnest.recording.camera`。
- 以上为源码常量；帧率稳定性、CPU 占用**未实测**。

## 已知限制 / 历史坑

1. **音频只能二选一**（系统声 / 麦克风）：mp4 双音轨在多数播放器只播第一条，用户会以为没录上——可解释的取舍（`ScreenRecorder.swift` 头注释）。
2. **暂停 = 丢帧不重排 PTS**：画面停住而不是插帧；恢复后时间轴连续。
3. **暂停与写盘必须同队列**（`14ab9c75`）：`setPaused` 与 `handleVideo/handleAudio` 曾异步竞态，暂停瞬间仍可能写入帧。
4. **开始录制保留已有目标文件**（`2b70007f`）：`uniqueOutputURL` 按时间戳命名并递增 `-N` 后缀，不覆盖既有文件。
5. **合成资源按需准备**（`91424842`）：`AVAssetWriterInputPixelBufferAdaptor` 仅在 camera/showKeys/showClicks 时创建，纯直通录制零合成开销。
6. **CGEventTap 依赖辅助功能/输入监控权限**：无权限时 tap 建不起来，按键/点击叠加静默关闭只留一条日志，不弹窗打断录屏（`RecordingInputMonitor` 头注释）；`AXIsProcessTrusted()` 判定、不主动申请。
7. **HUD 自己不入画**：`RecordingHUDController` 面板 `sharingType = .none`，否则每段录屏顶部挂着计时器。
8. **v274 误触修复（U03-003）**：设置页「停止并编辑」按钮去掉 `.defaultAction`——录制中在设置页按回车会把素材截断。
9. **编辑器定位是「最小可用集」**：只做剪头剪尾/静音/导出，刻意不做时间轴拼接/多轨/转场（源码注释：残缺版不如用 QuickTime）。
10. **状态清理历史**（`5ba1746f`/`83dcbc38`/`1990dccf`）：删除过无消费者状态、未读取选项副本、未实例化的外观草稿包装类——新增状态前先确认有读者。
