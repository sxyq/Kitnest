## 二、ArcZip 怎么"渲染"各种格式（源码级结论）

**它没有自己实现 Office 渲染。** 五层流水线里，真正出图的只有"解码层"：

| 格式 | 渲染方式 | 二进制证据 |
|---|---|---|
| 图片（png/jpg/heic/webp…） | **ImageIO** 缩略（`CGImageSourceCreateThumbnailAtIndex`） | ✅ |
| **PDF** | **CoreGraphics 直接渲染**（`CGPDFDocumentCreateWithProvider` + `CGPDFDocumentGetPage`），**不链接 PDFKit** | ✅ |
| 文本 / 代码 | **CoreText 自渲染**（`CTFramesetterCreateWithAttributedString` + `CTLineCreateTruncatedLine`） | ✅ |
| **Office（docx/xlsx/pptx/pages/key/numbers）** | **解到临时盘 → 交给系统 `QLThumbnailGenerator`**，带 `timeoutTask` 超时保护；主程序不链接任何 Office 库 | ✅ |
| 音视频 | AVFoundation + 系统 QuickLook | ✅ |
| 其他一切 | `SystemContentThumbnail` → QuickLook 兜底 | ✅ |

配套设计：
- **两段式加载**：先出缓存缩略图（秒开），后台再换高清
- **缓存 key = 归档指纹 + entryID + entryPath**（归档一改自动失效）
- **预生成索引**（`ArchivePreviewSeedStore`，目录 `ArcZipPreviewSeeds`）—— 后台批量生成好写盘，悬停时零解压
- **并发/内存控制**：`ArchiveThumbnailMemoryController` 淘汰、滚动时挂起低优先级任务

## 三、我们的实现（`ArchiveEntryThumbnail.swift`）

同样的分派思路，去掉预生成索引（悬停场景够用）：

| 格式 | 实现 |
|---|---|
| 图片 | `CGImageSourceCreateThumbnailAtIndex`（maxPixel = 2×显示尺寸） |
| PDF | `CGPDFDocument` 首页 + `CGContext.drawPDFPage`（白底） |
| 视频 | `AVAssetImageGenerator` 第 0.5 秒帧 |
| 文本/代码/json/md/csv… | `NSAttributedString.draw` 前 1200 字，白底等宽字体，底部渐隐 |
| Office / epub / rtf | 解到临时文件 → `QLThumbnailGenerator`（6 秒超时，避免 Office 首帧卡死整格） |
| 其余 | 不出图，继续用 `NSWorkspace.icon(for: UTType)` 类型图标 |

工程细节：
- 解压用现成的 `ArchiveCore.extractEntryToTemp`（7zz 子进程）
- **并发信号量 = 3**：36 个条目不会同时拉 36 个 7zz 进程
- 缓存 `NSCache`，key 带归档 mtime → 改包后自动失效
- 缩略图 46×46，白底圆角 + 0.5pt 描边 + 微阴影（看起来像纸质文档）

## 四、写回：原地覆盖，不产生备份

### 用户要求
> 「重新打包覆盖之前那个压缩包，而不是创建一个新的备份」

### 改动
`ArchiveBrowserWindow` 原先在首次修改前 `ensureBackup()` → 生成 `xxx.zip.bak`。
v123 **整个删掉**（3 处调用 + 函数本体 + `backupCreated` 状态）。

### 实测（7zz 的行为）

```
改前：-rw-r--r--  inode 197325168  t.zip
执行：7zz a -y t.zip note.txt
改后：-rw-r--r--  inode 197325177  t.zip
目录：note.txt  t.zip          ← 没有 .bak，没有临时文件残留
```

`7zz` 内部是「写临时文件 → rename 覆盖」，所以 **inode 会变，但路径不变、目录里不产生任何多余文件** —— 这正是"覆盖原包"的语义。

### 包内重命名（新增）

```bash
7zz rn t.zip note.txt renamed.txt   # 实测通过：包内路径改了，不产生新包
```

UI：归档浏览窗工具栏「重命名」+ 条目右键「重命名…」（`NSAlert` + 输入框）。
