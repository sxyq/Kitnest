### 2.2 Mini 窗口（真实截图证据 `OnboardingMiniWindow.png`）

- 尺寸约 560×380 pt，圆角 16，玻璃渐变底；
- 头部：文件图标 + 标题 + 「ZIP 压缩包 · 26 个项目」；右上角品牌标识「ArcZip Mini」；
- 路径条：‹ ↑ + 路径文本（斜杠分段）；
- 列表：图标 + 文件名 + 右对齐大小，**选中行整行系统蓝**；
- 底栏：左侧三枚 28 pt 圆形按钮（✕ 关闭、视图切换、**切换完整界面**）；右侧三枚药丸——主操作「⚡ 解压」紫色实底、次级「👁 预览 空格」、「▣ 全部解压」带回车符号；
- 交互：拖动条目**直接解压到拖放目标**；窗口置顶悬浮，Esc 关闭。

### 2.3 创建压缩包面板

- 用途预设（6 个 Flow：通用分享 / 邮件附件 / 长期归档 / 跨平台 / 加密传输 / 自定义），选中项紫色描边；
- 格式选择（ZIP/7z/TAR/GZ…）、压缩强度（存储/快速/均衡/极限）、密码与文件名加密、分卷（**1.2.5 新增**：按数量 2–999 或按大小 ≥1 KB，增减步进按钮 + 单位选择）；
- 「为每个项目创建单独压缩包」开关（1.2.5 新增）：显示「N 个压缩包」预计数量、每包卷数汇总；
- 底部：存储位置行 + 取消/创建。

### 2.4 进度窗口

- 380×280 pt 普通窗口（非面板），标题「任务队列」；
- 每个任务：类型图标 + 标题 + 进度条 + 百分比/速度/剩余；完成行变绿勾；失败行红字 + 「重试」；
- **1.2.5 新增设置**：保持置顶（`settings.progress.keep_on_top`）。

### 2.5 悬浮预览（弧线预览）

- 列表悬停 **1 秒**（`NSTrackingArea` + `DispatchWorkItem` + 全局事件监听），移出 0.25 s 收起；
- 内容：图片直接显示、文档渲染文本、音视频内联播放（1.2.5 设置：默认静音/自动播放/大小上限 10 MB–2 GB）；
- 弹层跟随条目、屏幕边缘翻转；按住鼠标拖动时抑制弹出。

### 2.6 密码本（1.2.5 新增界面）

- 设置页「密码本」：已保存密码列表（共 N 个）、自动保存开关、自动尝试解锁开关、独立密码保护（Touch ID / Apple Watch 快速解锁）；
- 解压时按组匹配：整组同密码的文件一次输入；单文件失败可「跳过此文件」，已解锁内容不受影响；
- Pro 边界：自动保存/自动解锁/预设属 Pro；手动输入密码始终免费。

### 2.7 应用安装（1.2.5 新增流程）

- 压缩包内含 `.app` 时提供「安装」动作：解压 → 校验包结构 → 读写隔离属性 → 写入/替换 /Applications（14 个阶段状态文案）；
- 失败详情对话框：阶段、来源、目标、系统、错误全文；应用正在使用时拒绝替换并提示退出。

## 4. 本轮落地明细（v273）

1. **打开与解压**（`ArchiveOpenBehaviorOptions`）：开关「双击时快速解压」+ 原包处理（保留/移到废纸篓）；`ArchiveQuickExtract` 实现：列举→冲突检测→解压到所在文件夹→可选回收原包；无法列举（加密/损坏）或同名冲突时回退浏览并 Toast 说明。
2. **悬浮预览**（`ArchiveHoverPreviewOptions`）：总开关（默认开）+ 上限 10 MB–2 GB（默认 100 MB，替换硬编码 96 MB）；`ArchiveHoverPreview.sizeCap/isEnabled` 实时读取。
3. **进度窗口**（`ArchiveProgressWindowOptions`）：保持置顶；`ArchiveProgressWindowController.applyKeepOnTop` 在创建/前置/偏好变化时应用（`UserDefaults.didChangeNotification` 观察者，窗口常驻也即时生效）。
4. **设置导航副标题**同步为四项能力描述。

延后项（不伪造、不加死开关）：

- 密码本：需要 Keychain + LAContext 生物解锁 + 自动匹配引擎；
- 应用安装：需要 14 阶段安装器与隔离属性处理；
- JAR 编辑 / 分卷创建 / 独立压缩包：引擎与创建面板重构；
- 视频/音频悬停预览：需要 AVPlayer 预览层，当前 `FileHoverPreview` 仅图片与文档。

## 5. 验证方式

- 设置页：`kitnest://settings?pane=archive` 截图核对四段结构；
- 双击直接解压：临时样本 `sample.zip` → `open -a Kitnest sample.zip`，验证解压落盘、原包处理与冲突回退（探针/脚本，不模拟鼠标）；
- 进度窗置顶：切换开关后查看窗口 `level`（调试日志）；
- 回归：既有浏览/解压/创建/Mini/悬停预览不受影响（默认值保持旧行为）。
