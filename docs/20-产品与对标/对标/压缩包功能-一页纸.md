# 压缩包功能 · 一页纸

> 不讲架构，不讲校验，只说「你点哪里、会看到什么」。
> 用一条线走完：**访达右键 ZIP →「用 FrsetNext 打开」→ 专属窗口**。

---

## 一、这条线长什么样

```
① 在访达里右键一个 ZIP
        ↓
② 选「用 FrsetNext 打开」
        ↓
③ 弹出专属窗口：左边是里面的文件，右边是预览，底下一排按钮
```

然后在这个窗口里能干 8 件事。

---

## 二、8 件事

| # | 你做什么 | 看到什么 | 现在 |
|---|---|---|---|
| 1 | 右键 ZIP →「用 FrsetNext 打开」 | 专属窗口弹出来 | **已做**（v167：双击 / 右键服务 / 打开方式 三个入口都通） |
| 2 | 看里面有什么 | 文件列表：名字 / 大小 / 压缩率；点文件夹能进去 | 有 |
| 3 | 点一个文件 | 右边出预览：Word / PPT / PDF / 图片 / 文本 | 半（Word/PPT 仍只有一张缩略图；照片已修） |
| 4 | 点「解压全部」或选中几个点「解压所选」 | 选个目标文件夹，开始解压，底下有进度 | 有 |
| 5 | 点「压缩」 | 选格式、强度，可设密码、可切分卷，生成新包 | 有 |
| 6 | 双击一个加密的 ZIP | 让你输密码，输对就进去 | 有 |
| 7 | 添加 / 删除 / 改名里面的文件，点「保存」 | **原地写回，不重新打包**，磁盘上还是同一个文件 | 有 |
| 8 | 把文件从窗口拖到桌面 | 只解出你拖的那一个 | 有 |

**结论：8 件里 7 件已经能用；只剩第 3 件的一半 —— Word/PPT 的翻页预览框。**

## 四、预览框支持什么

| 格式 | 现在 | 要做到 |
|---|---|---|
| PDF | 能滚动、能翻页 | 保持 |
| 图片（png / jpg / heic …） | 能看，能缩放 | 保持 |
| 纯文本 / Markdown | 能看，**还能直接改** | 保持 |
| **Word（.docx）** | 只有一张首图缩略图 | **能翻页的预览框** |
| **PPT（.pptx）** | 只有一张首图缩略图 | **能翻页的预览框** |
| Excel（.xlsx） | 只有一张首图缩略图 | 能看表格（可选） |
| 其他（压缩包套压缩包、字体等） | 显示类型图标 | 保持 |

> 为什么 Word/PPT 现在只有缩略图：它们靠系统 QuickLook 渲染，原来的写法是「取一张缩略图贴上去」。
> 要变成能翻页，得换成系统的**预览视图**（`QLPreviewView`），让它自己处理页数和滚动。

## 五、改文件为什么不用重新打包

| 动作 | 现在怎么做的 | 用户看到的结果 |
|---|---|---|
| 加一个文件 | 只把新文件追加进去 | 包变大一点，其余文件不动 |
| 删一个文件 | 只标记删除那一条 | 其余文件不动 |
| 改个名字 | 只改包内那条记录 | 其余文件不动 |
| 改文本内容 | 只替换那一个文件 | 其余文件不动 |

所以对一个 2 GB 的包改一个 3 KB 的文本，**不会重压 2 GB**，几秒就完。
磁盘上始终是同一个文件，不会冒出 `report 2.zip`、`.bak` 之类的东西。

## 六、那还要做什么

只做两件：

### 1. 右键「用这个打开」 ✅ 已完成（v167）

- 做法：`Info.plist` 登记 37 种压缩包扩展名（`LSHandlerRank: Alternate`，不抢默认）；
  新增右键服务「用 FrsetNext 打开」；`application(_:open:)` 补上文件 URL 分流
  （原来第一行 `guard scheme == "frsetnext"` 会把双击送来的文件全丢掉）。
- 实测：`open -a /Applications/FrsetNext.app 测试压缩包.zip` → 弹出「归档 · 测试压缩包.zip」860×592。
- 你现在可以：访达右键 ZIP → 服务 →「用 FrsetNext 打开」；或右键 → 打开方式 → FrsetNext；或直接双击。

### 2. Word / PPT 的预览框

- 现在：点一个 .pptx，右边只有一张首图，不能翻页、不能滚动。
- 要做：换成能翻页的预览视图，底下带「第 3 页 / 共 12 页 ← →」。
- 做完的效果：不进 Office、不解压到桌面，直接在窗口里翻完 12 页。

## 八、这轮（v129）到底改了什么

### 1. 右键「打开方式」里看不到 FrsetNext —— 已修

不是没做，是**声明写错了**。`Info.plist` 里同时写了：

- `LSItemContentTypes = public.archive, public.data`
- `CFBundleTypeExtensions = zip, 7z, rar, …37 个`

macOS 的规则是：**只要写了 `LSItemContentTypes`，就以它为准，扩展名列表直接被忽略**。
于是这个 App 只声明了"我能打开任意 public.data"，而 `.zip` 的真实类型是
`public.zip-archive`，两者匹配不上 —— 右键「打开方式」自然没有它。

去掉 `LSItemContentTypes` 后实测（`lsregister -dump`）：37 个扩展名全部绑定成功。

三种进入方式（现在都应可用）：

| 方式 | 操作 | 备注 |
|---|---|---|
| 服务菜单 | 右键 → 服务 → 用 FrsetNext 打开 | 已登记（`pbs -dump_pboard` 可见） |
| 打开方式 | 右键 → 打开方式 → FrsetNext | v129 修复；排位是「备选」，不抢你的默认 |
| 双击 | 直接把 zip 的默认程序设为 FrsetNext | 需你在「显示简介」里改一次 |

### 2. 照片预览「不太对」—— 已修

两个原因叠在一起：

| 原因 | 原来的表现 | 现在 |
|---|---|---|
| `readEntry` 写死 8 MB 上限 | 手机/单反原图（20–80 MB）直接提示「文件过大，请解压后用默认应用打开」 | 图片单独放宽到 **128 MB** |
| 整张解码 | 5000 万像素照片一次吃掉数百 MB，且缩到预览区反而糊 | ImageIO **降采样到长边 2600px**，内存十几 MB，Retina 下清晰 |
| EXIF 方向 | 竖拍照片可能躺着显示 | 降采样时按 EXIF **转正** |

### 3. 中转站悬停压缩包 —— 已改

原来：悬停只拿到一张 QuickLook 缩略图（多数就是 zip 图标），看不到里面有什么。

现在：和中转站里其它文件一样弹面板，但内容是**包内条目网格**（Word / PPT / 图片 / 文件夹
各自带系统图标），和面板首页、归档窗用的是同一个组件。

### 4. 已经确认「本来就是这样」的三处

| 场景 | 实际行为 |
|---|---|
| 面板首页悬停 zip | 已经是**直接展开包内条目网格**，底部还有「编辑归档」按钮进专属窗口 |
| 专属窗口 | 已经存在：左侧列表（≥260pt）+ 右侧预览（≥320pt）+ 工具栏（添加/删除/重命名/解压/保存）+ ⌘Z 撤销 + 面包屑 |
| 剪贴板里悬停 zip | 预览窗正文复用的就是同一个预览视图，文件类条目会走包内展开（需实机再确认一次） |

### 5. 还没做的

- **Word / PPT 翻页**：仍是一张首图缩略图，不能翻页、不能滚动。
- **预览气泡里直接删除/改名**：气泡里只有「解压到…」和「编辑归档」；删除要在专属窗口里做
  （破坏性操作放在随手可点的浮层里风险太高）。
