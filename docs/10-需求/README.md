## 行为条款补全（2026-11-24，审计包 03；从用户已明确的目标归纳，避免源码自我证明）

**刘海岛（Island）**
- 悬停展开（可延迟）与点击入口/深链固定打开并存；布局编辑、菜单跟踪、文本编辑期间不收起。
- 普通点击组件只挂「点击期间保护」，抬起即解除——鼠标移开按 `collapseDelay` 收起，不得永久锁住展开（v286）。
- 开合弹簧 0.42/0.80、收起 0.30、左右切页动效保持原曲线；指针流光属于直接操作，系统「减弱动态效果」时瞬时显示、不整段隐藏。
- 4 页组件 / 组件编辑 / 自定义默认页 / 多屏入口记忆 / 无刘海机型适配全部保留。

**触觉（Haptics）**
- 马达直连优先（手指离开触控板也有感），公开接口回落，不影响业务。
- 触发面 = 18 类真实业务事件；默认强度「中」；失败类事件强度不低于「中」；用户可按事件关闭。
- 物理手感（轻重是否合适）由用户本人确认，不以日志送达结果替代。

**存储（Storage）**
- 液面沿页面左侧弯曲边界**持续延伸到上半部**、融入顶部容量展示视觉区域；顶边不得截成水平直线。
- 左侧清理卡片清楚可读：轮廓在操作带以下全程不越进清单列；图块/文字不得覆盖控件点击区。
- 图块面积严格等于真实字节占用（含「可用空间」同口径），不为视觉好看改比例。
- 两指左退右进、一次手势只切一层；悬停压力场是指针直接操作，减弱动态时只去回弹不去跟随。

**录屏（Recording）**
- 以 `Features/Recording/模块说明.md` 与修改记录为准；录屏文件清理遵循「不留截图/录屏」纪律（验证素材用完即删）。

## 维护规则

- 规格的行为结论必须可被源码验证；与实现不一致时，先改规格（记录差异）再动代码。
- 问题记录写进对应规格的「问题记录」节，不单独建事件文档。
- 逆向测绘材料**保留证据属性**：引用时注明「原版行为」，不要写成「当前实现」。
