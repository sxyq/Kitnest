## 1. 你必须知道的环境事实（否则会踩坑）

1. **原版 Frset 是沙箱应用**，拷贝到 `/tmp` 直接运行会被拒（`sandbox_extension_issue_file_to_process failed`）。要程序化启动它，必须用「迷你 .app 引导」：把脚本写进 `/tmp/Xxx.app/Contents/MacOS/runner`（配 `Info.plist`、`LSUIElement=true`），执行**`/Applications/Frset.app/Contents/MacOS/Frset`**，再 `open -n`。
2. **App 有单实例守卫**：已有实例运行时，新实例会 `exit 0` 静默退出。注入采集才需要短暂停止原版；普通读取文档/机器码或使用当前可用的原生 UI 工具无需停原版。采集结束必须结束注入实例，再 `open -a /Applications/Frset.app` 恢复用户实例；仅调用 `open -a` 无法证明注入实例已被替换。
3. **历史 WorkBuddy 的 `screencapture` 失败**（`could not create image from display`），当时使用注入探针的 `CALayer renderInContext`。当前 Codex 原生截图已成功保存重建通用页，不能沿用旧限制推定当前没有权限。不同采集方式的白底/灰底色差须分开解释，最终视觉对照应使用相同方式。
4. 历史采集的合成键盘/鼠标事件未能驱动目标 SwiftUI 窗口；AppKit `performClick:` / `sendEvent:` 曾可用。当前 AX 已成功打开重建设置并确认五页签；不得将旧工具失败扩大为全部 UI 工具均不可用。
5. **`NSClassFromString` 只证明「类存在」，不证明「能无参构造」**——实测 13 个 Controller 的裸 `init` 全部崩溃。
6. **本机编译内存是瓶颈**：16GB + swap 常近满。`build.sh` 已改为 `-O -no-whole-module-optimization`，124 文件约 3 分钟；**typecheck 约 55 秒，迭代优先用 typecheck**。
7. **A6000 服务器是 Ubuntu/Linux，不能编译 macOS App**（无 macOS SDK / AppKit / SwiftUI），不要在该服务器编译；旧记录的 `ssh a6000` 也不能作为已确认可用的连接别名。
8. `ps`/`top`/`launchctl` 与 PyPI 限制是历史会话现象，不代表当前工具权限。PID 会变，需要定位原版时用 `pgrep -f '/Applications/Frset.app/Contents/MacOS/Frset'`；本轮文档整理未操作应用或服务器。
9. **程序化唤起 FrsetNext 用 URL scheme**（2026-10-16 新增，等价原版 `showSettingsWindow:` @objc 入口）：`open "frsetnext://settings?pane=general|search|tools|shortcuts|about"` 与 `open "frsetnext://statistics"`。辅助功能/录屏权限缺失时这是唯一可靠的窗口唤起路径。改 CFBundleURLTypes 后需 `lsregister -u <app> && lsregister -f <app>` 重新注册，且 app 要重启。
10. **窗口布局纪律（防回归，specs/07 §4.3）**：SwiftUI App lifecycle 下 `NSHostingView` 会把根视图 fitting size 折成窗口尺寸请求；根视图必须固定尺寸（设置/统计 = `.frame(width: 800, height: 530)`），**禁止** `.frame(maxHeight: .infinity)` 作根视图，否则窗口被反复请求撑到内容自然高（实测 1554pt），触发 `NSGenericException`（"more Update Constraints in Window passes than there are views"）进程即死。窗口控制器不设 `setFrameAutosaveName`（原版窗口固定尺寸）。
11. **`@State` 宏不可用**：本机 Command Line Tools 缺 SwiftUIMacros 插件，`@State` 编译报 "plugin for module 'SwiftUIMacros' not found"；全工程用 `@Stored`（`Sources/Core/StateCompat.swift`）替代。同理 SDK 的 `application:openURLs:` 被 Swift renamed import 为 `application(_:open:)`，参数是 `[URL]` 不是单个 `URL`。
