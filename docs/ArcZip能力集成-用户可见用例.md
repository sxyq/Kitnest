# ArcZip 能力集成 · 用户可见用例（待添加项）

> 2026-10-31 ｜ 配套：`docs/ArcZip能力集成规划-v2.md`（工程视角）、`arczip/work/docs/ArcZip-需求用例全景.md`（需求池）
> **本篇只收「用户能点、能看见」的交互**。系统内部校验、后台任务、构建声明一律不进用例表，
> 但在 §五 列清楚"被排除的是什么、为什么"。

---

## 一、口径

| 收 | 不收 |
|---|---|
| 用户主动点击/按键能触发的 | 后台自动执行的（索引重建、指纹校验） |
| 用户能在界面上看见结果的 | 只写日志或只影响内部状态的（写后比对、路径拦截） |
| 有明确入口位置的（工具栏/菜单/设置/浮层） | 纯代码层的重构与约束 |

一句话：**能不能"点出来"是唯一标准。**

当前 Archive 模块已融 29 个用例，本篇只列**还没做的、且用户能感知的 16 项**。

## 三、16 个待添加用例

### A · 浏览增强（5 项）

#### A1 打开检查器面板　`P0`

| 项 | 内容 |
|---|---|
| **入口** | 工具栏「信息」按钮 ／ 菜单「显示 → 检查器」／ `⌘I` |
| **触发** | 选中任一条目后点击；再点一次收起 |
| **看到什么** | 右侧 260pt 面板，四段：<br>**身份** 名称 / 完整路径 / 类型<br>**大小** 原始 / 压缩后 / 压缩率 / 节省<br>**属性** 压缩方法 / CRC / 是否加密 / 修改时间<br>**所属归档** 格式 / 条目数 / 文件与文件夹数 / 总解压后大小 |
| **多选时** | 换成汇总：已选 N 项 · 其中文件 M 项 · 原始合计 · 平均压缩率 |
| **无选中** | 显示归档级摘要（同上「所属归档」段） |
| **依赖** | `ArchiveEntry` 已有 size/packedSize/method/isEncrypted；CRC 需从 `7zz l -slt` 补解析 |

#### A2 查看最近打开　`P0`

| 项 | 内容 |
|---|---|
| **入口** | 主菜单「文件 → 最近打开」 |
| **触发** | 悬停展开子菜单 |
| **看到什么** | 最多 12 条，按时间倒序，显示文件名；分隔线下方「清除最近打开记录」；无记录时灰字「没有最近打开的压缩包」 |
| **点击后** | 直接打开该归档（已在窗口则前置） |
| **依赖** | 新增 `ArchiveRecentStore`（UserDefaults，80 行） |

#### A3 空格快速预览　`P0`

| 项 | 内容 |
|---|---|
| **入口** | 条目表 / 图标网格中选中条目后按 `空格` |
| **触发** | 空格键；再按一次关闭 |
| **看到什么** | 系统 QuickLook 全屏预览面板：图片、PDF、文本、Office、视频按系统能力渲染；底部显示文件名与大小 |
| **键盘** | `↑` `↓` 直接切到上/下一条目，预览跟随；`Esc` 关闭 |
| **依赖** | `QLPreviewPanel`；预览文件先解到临时目录并按「归档指纹 + 条目路径」缓存 |

#### A4 悬停预览气泡　`P2`

| 项 | 内容 |
|---|---|
| **入口** | 鼠标停在条目行上（不点击） |
| **触发** | 停留 300ms；移出 200ms 后收起 |
| **看到什么** | 浮层：缩略图（120pt）+ 文件名 + 大小 + 压缩方法；快速划过只显示最后停留的那一项 |
| **与 A3 的区别** | A3 是全屏、要按键；A4 是轻量浮层、纯鼠标 |
| **依赖** | 复用 `ArchiveEntryTile`（已有 46pt 规格，改成 120pt） |

#### A5 框选多个条目　`P2`

| 项 | 内容 |
|---|---|
| **入口** | 条目表空白处按住拖动 |
| **触发** | 拖出矩形框，松手选中框内所有行 |
| **看到什么** | 半透明选框；松手后底部计数「已选 5 项 · 共 128 项」 |
| **与现有多选** | 现有的 ⌘ 点选 / ⇧ 连选保留，框选是第三种方式 |
| **依赖** | `ArchiveEntryTable` 加手势 + overlay |

### B · 提取确认（3 项）

#### B1 选择同名冲突处理　`P1`

| 项 | 内容 |
|---|---|
| **入口** | 解压时目标目录已有同名文件，自动弹出 |
| **触发** | 点「解压全部」或「解压所选」后检测到冲突 |
| **看到什么** | 对话框，标题「目标位置已有同名项目」，四个按钮：<br>**合并**（同名文件编号保留）<br>**同时保留**（新建「名字 2」文件夹）<br>**覆盖**<br>**跳过**<br>底部勾选「记住我的选择，不再询问」 |
| **现状** | 现在 `7zz -y` 一律静默覆盖，用户没有任何选择 |

#### B2 决定原包去向　`P1`

| 项 | 内容 |
|---|---|
| **入口** | 解压完成后的提示条上，或「设置 → 归档 → 解压」 |
| **触发** | 解压成功后 |
| **看到什么** | 完成提示「已解压 24 个文件到 …」，附带两个按钮：「保留原包」「移入废纸篓」；设置里可设为「每次询问 / 始终保留 / 始终移入废纸篓」 |
| **注意** | 访达右键服务触发的解压**默认保留**，不弹这个提示 |

#### B3 查看错误详情　`P2`

| 项 | 内容 |
|---|---|
| **入口** | 任何失败提示上的「详情」按钮 |
| **触发** | 解压失败 / 密码错误 / 写入失败 / 只读目录 |
| **看到什么** | 详情面板：错误码 · 受影响文件列表 · 一句人话解释 · 恢复建议（如「请检查目标目录是否只读」）· 「复制诊断」按钮 |
| **现状** | 只有 `Toast` 一句话，用户不知道下一步做什么 |

### C · 编辑保护（3 项）

#### C1 处理外部改动　`P1`

| 项 | 内容 |
|---|---|
| **入口** | 点「保存」时自动检测；有外部改动则弹出 |
| **触发** | 打开归档后，文件被其他 App / 访达改过（大小或修改时间变了） |
| **看到什么** | 对话框「压缩包已被其他应用修改」，三个选项：<br>**重新载入**（放弃我的修改）<br>**合并并保存**（把改动写进最新版本，冲突项单独列出）<br>**另存副本**（保住两边） |
| **现状** | 直接覆盖，会静默吃掉别人的改动 |

#### C2 另存副本　`待定`

| 项 | 内容 |
|---|---|
| **入口** | 工具栏「另存副本…」 |
| **触发** | 点击 → 选保存位置 |
| **看到什么** | 标准保存面板；保存后原包不变，新文件出现在目标位置 |
| **为什么待定** | 你先前明确要求「原地覆盖、不产生 `.bak`」。这个入口是**手动**的，默认不生成任何额外文件 —— 是否要，等你拍板 |

#### C3 保存结果反馈　`P1`

| 项 | 内容 |
|---|---|
| **入口** | 保存动作结束后 |
| **触发** | 点「保存」 |
| **看到什么** | 成功：状态栏「已保存 · 128 个条目」，2 秒后淡出<br>失败：红色提示条 + 「重试」「另存副本」两个按钮 + 「详情」 |
| **现状** | 成功无反馈，失败只有一句 Toast |

### D · 系统入口（2 项）

#### D1 设为默认打开方式　`P0`

| 项 | 内容 |
|---|---|
| **入口** | ① 访达右键归档 →「打开方式」<br>② 设置 → 归档 → 格式关联 |
| **触发** | 点击格式行的开关，或右键选择 FrsetNext |
| **看到什么** | 设置页列出常见格式（zip / 7z / rar / tar / gz…）与「全部 33 种」展开；每行一个开关；顶部一行「以下 3 种格式未成功关联」的完成度提示 |
| **现状** | `Info.plist` 没有 `CFBundleDocumentTypes`，右键「打开方式」里根本没有 FrsetNext |
| **注意** | 声明用 `LSHandlerRank: Alternate` —— 不抢用户默认 |

#### D2 打开归档设置页　`P1`

| 项 | 内容 |
|---|---|
| **入口** | `⌘,` → 侧栏「归档」 |
| **看到什么** | 7 组选项，一页内分区：<br>**压缩** 默认格式 / 默认强度 / 默认用途预设<br>**解压** 冲突策略默认值 / 原包去向 / 辅助文件过滤<br>**浏览** 显示辅助文件 / 悬停预览开关 / 缩略图开关<br>**密码** 默认显示密码（方便中文输入法）<br>**格式关联** 见 D1<br>**文件盒** 启用 / 颜色 / 闲置收起秒数<br>**存储** 见 E2 |
| **现状** | 设置里完全没有归档相关页 |

### E · 外壳与存储（3 项）

#### E1 文件盒内浏览与图钉　`P2`

| 项 | 内容 |
|---|---|
| **入口** | 文件盒窗口：双击文件夹行 / 右上角图钉按钮 |
| **触发** | 双击进入子目录；图钉切换置顶 |
| **看到什么** | 顶部出现面包屑（盒 › 子目录）；图钉按下后窗口保持置顶、不被其他窗口盖住 |
| **现状** | 文件盒已能收集/压缩/8 色/闲置收起，但没有层级浏览与置顶 |

#### E2 清理归档临时文件　`P3`

| 项 | 内容 |
|---|---|
| **入口** | 设置 → 归档 → 存储 |
| **触发** | 进入该页时自动计算；点「清理」 |
| **看到什么** | 「预览缓存与临时文件占用 128 MB」+「清理」按钮；点完变「0 MB」，并提示「已释放 128 MB」 |
| **现状** | 临时文件只增不减，用户无处可清 |

#### E3 首次打开引导　`P3`

| 项 | 内容 |
|---|---|
| **入口** | 第一次打开任一归档时自动出现 |
| **看到什么** | 3 步卡片（这是什么 / 能直接改里面 / 可以拖出去）+「下一步」+「不再显示」 |
| **建议** | 优先级最低 —— 面板型工具的用户多半知道压缩包是什么；可不做 |

## 五、被排除的系统项（不进用例表，但仍要做）

| 规划里的项 | 为什么不算用例 |
|---|---|
| 写后校验 + 重放 | 后台比对条目数与路径集合，用户看不到过程，只在失败时才通过 C3/B3 露出来 |
| 路径安全补强 | 拦截 `../`、保留名等，正常使用时无感；被拦时才由 B3 显示 |
| SQLite 索引 | 纯后台缓存，命中与否用户只感知"快慢"，没有可点的入口 |
| 删除 12 个商业事件 | 代码清理，无界面 |
| `Info.plist` 加 `CFBundleDocumentTypes` | 声明文件；其用户可见的后果就是 D1 |
| 合并冲突的三类判定算法 | 算法；用户可见的是 C1 那个对话框 |

## 六、验收：每一项都要"点得出来"

| 编号 | 验收动作 | 通过判据 |
|---|---|---|
| A1 | 选中条目 → ⌘I | 四段齐全；多选变汇总；再按收起 |

| A5 | 空白处拖框 | 选框可见；松手计数正确 |
| B1 | 解压到已有同名目录 | 四选项各生效一次；勾「记住」后不再问 |
| B2 | 解压完成 | 提示条两个按钮；点击后原包进废纸篓 |

| E1 | 文件盒双击文件夹 / 按图钉 | 面包屑出现；窗口置顶 |
| E2 | 预览若干条目后进设置 | 占用非 0；点清理归零 |
| E3 | 首次打开归档 | 3 步卡片出现；「不再显示」生效 |
