## 6. 奔跑小猫（RunCat）全盘核对（2026-10-19 22:15）

全仓库检索 `run_cat / RunCat / 小猫 / catFrame`，命中 132 处，真正参与显示/计时的只有下面两处：

| 实现 | 位置 | 作用 | 计时 |
|---|---|---|---|
| 主图标覆盖层 `FSRunCatIconView` | `frset_barwidgets.m:1426-1442` | 在**主状态项按钮**上覆盖绘制奔跑小猫（唯一会动的猫） | 读 `g_runCatFrame` |
| 帧推进 `FSRunCatTick` | `frset_barwidgets.m:1492-1554` | 计算 CPU EMA → 速度倍率 → 推进 5 帧循环 | `NSTimer` 20Hz（`:1559`） |
| CPU 部件形态 `run_cat` | `frset_barwidgets.m:812` | **已废弃**：未知/存量 form 一律回退 `drawMini`（画 CPU 数值，不是猫） | 随 CPU 部件间隔（3s） |

“两只猫/两套时间”的实际成因：
1. **底层静态猫**：主图标样式是 `custom`（`menu-bar-icon-custom=1`），自定义符号很可能是猫；覆盖层只隐藏了 button 的子视图，**NSButton 自己绘制的 `button.image` 仍在**，从覆盖层透明区透出来 → 静态猫 + 动画猫同屏。
2. **两种节奏**：动画猫 20Hz 平滑推进、速度每 tick 变；CPU 数值/部件每 3s 才刷新 → 观感是两套时间。
3. **宽度裁切**：猫图按固定 56:36 绘制（高约 20 → 宽约 31pt），而 custom 样式是 `variableLength`（约 20-24pt），超出部分被按钮裁掉。

v82 修复：
- 接管期间把 `button.image` 清空为占位空图、`title` 清空（关闭小猫时发 `FrsetRunCatIconChanged`，Swift 侧强制重应用原样式/宽度）；
- 主状态项宽度按猫的 56:36 固定（约 33pt），关闭时恢复 `variableLength`；
- 绘制时若可用宽度不足，按宽度等比缩小，**不再裁切**；
- 速度档只在 CPU 部件刷新时刻更新（`FSBarModuleInterval(@"CPU")`），与菜单栏 CPU 数值同一节奏；动画帧仍 20Hz 平滑。
