# 规划：设置 → 常规（主页）→「个性化」栏目

**需求来源**（2026-10-19）：在设置主页加个性化栏目，调节 UI 相关设置。
本文件是规划稿，确认范围后再实现。

## 入口与形态

- 位置：设置 → 常规（主页）页内新增「个性化」分组（`formRow` 组，样式与「功能」组一致）。
- 生效方式：全部**即改即生效**（沿用部件设置页的 bump 重绘模式），无需重启。
- 存储：统一 `ui.*` 前缀偏好键（Preferences.Keys），与既有键共存。

## 明确不放进「个性化」的

- 功能开关（文件中转、暂停记录等）→ 留在「功能」组；
- 菜单栏部件形态/颜色/间距 → 已在「部件设置」页（v55）；
- 语言 → 已有「语言」行。

## 实现注意

1. `Theme` 的 static let（accent/cornerRadius/statsRowHeight 等）需改为
   `static var`（读 AppearanceState + Preferences），引用点全工程 ~40 处编译即可，
   不需要逐处改动（同名访问不变）。
2. 字号缩放只包主面板根视图（`PanelRootView`），设置窗/部件设置页不受影响，
   避免「设置界面自身被缩放」的自举问题。
3. 每项设置在页面内给出 3–5 个档位 + 「恢复默认」按钮；改布局类的项（密度/宽度）
   时面板即时调整并持久化。
4. 建议实现顺序：P0 的 4/5/6（半小时级）→ 1（强调色）→ 2/3（缩放与密度）；
   P1 等 P0 落地验收后做。
