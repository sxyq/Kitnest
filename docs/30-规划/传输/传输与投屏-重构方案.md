# 传输与投屏 重构方案（2026-10-21）

> 需求：中转站彻底重构——去掉 OPPO/局域网旧传输，改用 omdrop-owl 方式的
> 原生互传；「文件中转」改名「传输与投屏」，投屏接入 AndroMeld 的实现方式；
> 手机端有现成 App 则接入、没有则自研合并。构建产物及时清理；ADB 实测后置。

## 一、调研结论（关键事实）

### 图二：omdrop-owl（t4t5/omdrop-owl，AirDrop 协议路线）
- **它是什么**：Linux 上的 AirDrop 无线电后端——基于 Seemoo Lab 2019 年的
  OWL（用户态 AWDL 协议栈，C）+ OpenDrop（AirDrop 收发，Python），
  新增与路由器共用信道（AP 固定 6/44/149 信道），Wi-Fi 不断线双向互传。
- **⚠️ 平台约束**：**Linux 专用**（用户态注入无线帧，依赖 mac80211 驱动 profile，
  仅 MT7925 实测）。macOS 不走这条路——**Mac 本身就有原生 AWDL/AirDrop**。
- **⚠️ 许可证**：仓库**未声明 license** → 其代码不可直接复用/再分发。
  只能按协议思路自行实现，或调用系统能力。
- **手机端 App**：**不需要**——这是该路线的核心价值（iPhone 侧零安装，
  系统原生隔空投送直接收发）。不存在"安卓 App"（该路线是 iPhone↔非苹果）。
- **速度**：收 ~1.3MB/s、发 ~490kB/s（作者自测）；iPhone 每次随机 AWDL 地址。

**→ 我们的 macOS 落地（等效能力）**：
1. 发送到 iPhone：`NSSharingService(named: .sendViaAirDrop)`——系统级 AirDrop
   面板，选中即发，**iPhone 零安装**；
2. 从 iPhone 接收：macOS 系统 AirDrop 落盘 ~/Downloads → 监听入库到中转站；
3. 旧 OPPO 云端桥接 / 局域网扫码直传**全部下线**。

### 图一：AndroMeld（投屏路线）
- **它是什么**：Mac↔Android 融合（镜像投屏/融合模式/文件/剪贴板/通知/Handoff），
  官网 andromeld.catchingnow.com，独立开发者（冰箱作者）。
- **⚠️ 性质**：**商业闭源**（买断 ¥88 / 订阅；仅远程部署脚本开源）→ 不能接入
  其代码，只能**按它的实现方式自研**。
- **技术底座**：ADB（USB 调试）+ 视频流镜像 = 与开源 **scrcpy** 同路线
  （AndroMeld 的手机"辅助应用"是为增强功能；纯镜像只需 ADB，无需手机装 App）。
- **手机端 App**：AndroMeld 有自己的手机 App（闭源）；**我们不需要它**——
  scrcpy 路线手机侧零安装（ADB 授权即可）。
- **系统要求**：macOS 15+ / Android 12+（我们对齐 Android 12+）。

**→ 我们的 macOS 落地（等效能力）**：
1. 投屏模块：ADB 连接管理（USB/无线）+ scrcpy 引擎（镜像窗、音视频同步、
   旋转/置顶/快捷键按需后补）；
2. 无 scrcpy 时给引导（brew install scrcpy / 捆绑路径检测）；
3. **手机端无需任何 App**（ADB 授权即用）→ "有没有现成 App"的答案：
   两条路线都**不需要手机装 App**，不存在需自研的安卓端。

## 二、目标架构（Mac 端）

```
传输与投屏（原 文件中转）
├─ 隔空投送（传输）            ← 替代 OPPO 云端 + 局域网直传
│   ├─ 发送：NSSharingService.sendViaAirDrop（本地暂存/选文件 → 系统面板）
│   └─ 接收：监听 ~/Downloads（.download/新增文件）→ 自动进本地暂存
├─ 投屏（scrcpy 引擎）         ← AndroMeld 同实现路线
│   ├─ ADB 设备发现（USB / 无线配对，等待用户连手机实测）
│   ├─ 启动 scrcpy 镜像窗（分辨率/码率可配）
│   └─ 无 scrcpy → 引导安装
└─ 本地暂存（保留，作为空投发送源）
```

## 三、手机端 App 结论
| 路线 | 现成 App | 处置 |
|---|---|---|
| 空投互传（iPhone） | 无（系统原生） | 无需开发，iPhone 零安装 |
| 投屏（Android） | AndroMeld 有（闭源不可用） | **不自研手机 App**：scrcpy 路线零安装 |

即：两条路线都不需要手机装 App，无需合并开发安卓端。

## 五、v112 增补（2026-10-25，对标报告第一批落地）

> 详见 `docs/20-产品与对标/对标/综合对标分析.md` 路线图。

- **无线配对 UI**：`ADBWirelessEngine`——`adb mdns services` 发现 pairing/connecting 服务、`adb pair`（配对码）、`adb connect`；投屏区「无线连接」块（扫描列表一键连接 + 手动 IP:端口/配对码）。
- **剪贴板显式化**：scrcpy 显式 `--clipboard-autosync`，Toast 明示「剪贴板双向同步开」。
- **ADB 文件桥**：`ADBFileBridge`——暂存项推送到手机 `Download/FrsetNext/`（逐文件报数）；拉取该目录入本地暂存（`LocalTransferStore.add` 正式入索引）；「文件互传 · Android」区。
- **空投联动**：`.frsetAirDropFiles` 通知（App 层接线）——截图动作链「空投」（⌘D）+ 剪贴板两套右键菜单「隔空投送」（`ClipboardItem.airDropFileURL` 解析：图片/文件/文本文件）。

## 六、构建缓存纪律
