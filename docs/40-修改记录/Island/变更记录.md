## 重要变更条目
### 2026-11-24 岛外壳取样面与形变解耦，黑幕只在形变途中存在（本次）
- 需求/原因：用户「检查 NSGlassEffectView 的尺寸变更及 CAShapeLayer 遮罩重绘成本」「避免非几何状态更新导致材质重复创建」「不让隐藏状态持续执行昂贵绘制」「展开态呈现克制的深色玻璃质感」。
- 涉及文件与关键函数：`Features/Island/IslandSurface.swift`——`IslandMaterialHost` 增 `expandedSize/collapsedSize` 与 `targetSize(expanded:)`；`IslandMaterialView.applyGeometry(interpolated:radius:sampling:samplingInset:)` 成为唯一几何入口；`flushStats` 形变收尾结算；`glass.autoresizingMask = []`（否则父视图每帧插值时 AppKit 把玻璃拉回 bounds，等于每帧重建）；玻璃圆角改用该档**最终**圆角 `samplingInset`，不再逐帧写；`IslandMorph` 的整窗黑幕改为 `phase < 0.999` 才存在。
- 修改后行为：形变途中只有遮罩路径逐帧重算，玻璃取样面在展开开始时放大一次、收起收尾时缩回一次；展开静止态不再挂全尺寸黑幕层。外观逐像素一致（同一窗口截图前后对比无差异）。
- 已确认结果 / 未确认事项：实测（同一构建序列内前后对照）玻璃重建 12–16 次/次开合 → 展开 2 次、收起 0 次；遮罩重算 p95 0.006–0.017ms、layout p50 0.005–0.009ms；外壳材质实测 `NSGlassEffectView 通透度=68% 降透明=false`；岛展开首次布局 87ms（冷）/24–32ms（温），收起 4–9ms。未确认事项：120Hz 外接屏未接（本机 60Hz）。
