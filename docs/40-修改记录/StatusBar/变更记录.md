## 重要变更条目
### 2026-11-15 统一图标单选与动态预览（dd84fcde）
- 需求/原因：用户「被选择之后，它这些选项是要统一的」「上面的那个预览是要更新的」「选的是小猫，但是它没有动，下面选的是一个风扇」。
- 涉及文件与关键函数：SettingsPanes.swift、MenuBarIconStyle.swift、StatusBarMenuBuilder.swift、frset_barwidgets.m——Logo/动态风扇/日期/自定义图标/动态小猫共用五项单选；删除独立覆盖开关；分段控件最大宽度 350→430pt。
- 修改后行为：选择小猫时不再保留底层风扇动画和采样；预览风扇固定 2.6s 周期、小猫 8fps 演示（不启动真实 CPU 采样）；保存后应用正式菜单栏，取消从统一已保存样式恢复。
- 已确认结果 / 未确认事项：真实构建安装；键盘日期试选、取消恢复小猫、保存并应用、重启后小猫唯一选中；预览定时器生命周期验证（闭窗停、重开恢复）。未确认事项：无。

### 2026-11-16 小猫使用真实按钮图像替代空图片覆盖层（f598003f）
- 需求/原因：用户「实际的那个数据的小猫的左侧是有一个空白图片，点开是我们的界面，但是它是空白占位，认真排查一下」。
- 涉及文件与关键函数：MenuBarIconStyle.swift、frset_barwidgets.m——删除主图标空图和独立覆盖层；原生按钮显示原帧资源，模板图高 20pt、56:36 比例、状态项 34pt；帧变化才赋图。
- 修改后行为：主图标不再出现空白占位覆盖层；小猫沿用同一计时器，设置预览与点击、文件拖入、暂停标记保留。
- 已确认结果 / 未确认事项：菜单栏局部截图确认空白现象存在；正式和 Glow 均在运行。未确认事项：最终画面和点击待用户主动重开确认（当时输入/焦点限制）。

### 2026-11-16 先读取已保存小猫配置再应用主图标（207f0843）
- 需求/原因：用户「小猫的左侧有空白图片，点击打开我们的界面，这个还是存在，请你完成」——空白槽定位为旧 PID 残留；另修启动递归（图标应用直接读未加载 g_cfg）。
- 涉及文件与关键函数：frset_barwidgets.m——FSRunCatIconApplySavedConfiguration 改为复用 FSBarCfgRaw（函数签名与行号不变）。
- 修改后行为：启动不再因图标应用/关闭通知递归；正式小猫继续 34pt 主状态项及 20pt 模板帧。
- 已确认结果 / 未确认事项：旧 PID 89285 退出后空白槽随正式条消失；新 PID 34311 启动后 16:06 截图显示小猫且无左侧空白，16:06:40 日志已有主面板打开记录。未确认事项：无。

### 2026-11-07 拖文件到菜单栏图标 → 转入弹框（b7790c45）
- 需求/原因：用户「请你去做完啊，剩下的这部分。把这整个需求全都做完」（拖文件到图标转入）。
- 涉及文件与关键函数：新增 StatusItemDropProxy（NSStatusBarButton 上挂透明 NSView 收拖放，hitTest 返回 nil 不挡点击）；落下动作先开面板再发 .frsetTransferIntake(urls)；弹框从 TransferDockView 迁到 PanelRootView；云端分支未登录发 .frsetOpenTransferLogin、已登录 uploadBatch；本地分支 LocalTransferStore.add(urls:)。
- 修改后行为：拖文件到菜单栏图标弹出云端/本地转入框；开合面板不受影响；拖入时图标着强调色底提示。
- 已确认结果 / 未确认事项：build.sh EXIT=0；func_table/codegraph 已重跑。未确认事项：逐分支拖拽实测未全部记录。

### 2026-11-08 悬挂架开关纳入状态栏菜单签名（0596dd73）
- 需求/原因：菜单有进程内缓存（v128 为流畅度），signature 只含 GlobalEntries 三个开关——用户开着悬挂架去点菜单，看到的还是「没有这一项」的旧菜单。
- 涉及文件与关键函数：状态栏菜单缓存签名（MenuCache/菜单签名计算）纳入悬挂架开关。
- 修改后行为：开关悬挂架后菜单立即反映新结构。
- 已确认结果 / 未确认事项：随 v261 批次构建。未确认事项：单独实测记录未附（根因与修法明确）。

### 2026-11-03 彻底排查「点其他地方不收起」：菜单栏放行范围过大（3baa2c19）
- 需求/原因：用户「那个鼠标点击其他地方自动收缩又没了 请你彻底排查」。逐条核对收起三路信号（本地点外/app 失活/resignKey）后定位三处根因。
- 涉及文件与关键函数：TransientWindowCenter.handleLocalClick 对整条菜单栏一律 return（改为只放行自家状态项，新增 StatusBarController.statusItemFrames）；NSWorkspace.didActivateApplicationNotification 兜底收起；PanelController.hide 增加 0.6s 超时强制进 performHide 并用 isHiding 防重复。
- 修改后行为：点系统菜单栏项（时钟/WiFi/输入法）也会收起浮层；前台应用切换即收起；预览关闭回调丢失不再挂住面板。
- 已确认结果 / 未确认事项：重启后开面板→切 Finder，日志「点外收起（前台应用切换 → 访达）」「hide: 开始收起」，窗口列表里面板已消失。未确认事项：无。
