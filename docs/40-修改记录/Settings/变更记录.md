### 2026-11-22 侧栏拆成三级，入口与交互、截图与录屏分小节（13287c82）
- 需求/原因：用户「这部分的设置需要进一步拆分分类，拆成三级，而不是二级」。
- 涉及文件与关键函数：SettingsNavigation.swift——新增 SettingsSidebarSection（一级目录 → 二级小节 → 页面，22/38 两级缩进）；入口与交互拆 4 节（主面板/菜单栏与快捷键/刘海工作台/悬浮窗），截图与录屏拆 3 节（截图/钉图与图帘/录制与自动化）；页面少的目录保持两层不硬加。
- 修改后行为：小节可各自折叠；深链与搜索落地自动展开一级目录和所在小节；点开目录顺手展开当前页所在小节；搜索结果显示三级路径（如「截图与录屏 › 钉图与图帘 › 钉图」）。
- 已确认结果 / 未确认事项：安装版 940×720 实拍「收起态」「钉图」两页，三级缩进、选中态、折叠箭头正常；函数 4,285 / 声明 11,439，reconcile 全绿。未确认事项：无。

### 2026-11-22 打开动画在预览里真实回放，修「点了没反应」（a49d1438）
- 需求/原因：用户「这里点了没有反应是那个打开动画切换，那说明是在预览中需要给出来」。根因：预览跟随系统「减弱动态效果」降级成瞬间切换，而正式面板走 CAAnimation 本来不降级。

- 修改后行为：预览不再随「减弱动态效果」降级；打开动画切换立即可见渐变展开。
- 已确认结果 / 未确认事项：安装版 940×720、60fps 录屏逐帧读预览区亮度，切换后 131.7→217.9 连续爬升约 0.37s 后稳定，确认渐变展开而非跳变；函数 4,282 / 声明 11,428。未确认事项：无。
