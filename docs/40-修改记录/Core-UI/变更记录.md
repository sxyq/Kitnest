### 2026-11-24 玻璃分层收口：底衬+霜感预合成单层、材质开关真正落地（本次）
- 需求/原因：用户「每个窗口只保留必要的背景采样层」「避免重复的整窗着色和磨砂层」「内容卡片优先使用轻量填充」「Personalization 默认 .solid 与用户预期不一致」「部分卡片同时使用渐变、描边、高光和阴影」「玻璃配置迁移可能覆盖用户参数」。
- 涉及文件与关键函数：`Core/UI/Support.swift` 新增 `Theme.glassTint(for:midnight:)` / `cachedDynamicColor` / `composite`（A=a1+a2(1-a1)，C=(C1·a1+C2·a2(1-a1))/A，离线算成一层，按 通透度×磨砂×midnight 缓存）；`GlassSurface` 两个 fill → 一个；`GlassTintOverlayView` 两个全尺寸 subview → 一层 CALayer（删掉其 `layout`）；`GlassSurface` 去掉 `.id(p.material)`（切卡片材质不再拆掉整窗玻璃重建）；`WhiteGlassCard` 去掉斜向高光与投影（同卡不再四层叠加）；`GlassCard` 读 `material`：纯色卡片走 `readingBase`（不透明），毛玻璃走 `cardFill`；`Personalization` 默认 `.vibrancy` + `ui.materialLookVersion` 一次性迁移（旧默认 solid → vibrancy，显式选择保留）。
- 修改后行为：同一块玻璃从「模糊 + 底衬 + 霜感」三层降到两层（模糊 + 单层着色）；四个滑块语义不变、全部仍生效；「背景材质」从空转变成真实开关；用户改过的玻璃参数不被迁移覆盖。
- 已确认结果 / 未确认事项：本机 `ui.panel.material=solid → vibrancy`、`ui.materialLookVersion=1` 实测迁移生效；面板窗口实测 `NSGlassEffectView material=vibrancy`，整屏裁剪可见背景色透上来（底部随背后窗口呈暖绿）。未确认事项：暗色壁纸下的对比度只做了离屏取样，未逐壁纸回归。

### 2026-11-23 结构面真玻璃与材质分层修复（bb98d6ba）
- 需求/原因：用户「重点修复 Kitnest 刘海灵动岛展开窗口、菜单栏主面板的玻璃质感差、材质层级混乱、掉帧和开合迟滞问题」「允许调整玻璃材质的实现与视觉配方，但禁止以删除既有动画、减少功能、改变界面布局或降低截图画质作为优化手段」。
- 涉及文件与关键函数：Core/UI/LiquidGlass.swift、Core/Runtime/Personalization.swift、Features/Island/IslandSurface.swift、Features/Panel/Presentation/{FloatingPanel,PanelRootView}.swift。材质语义：结构面恒为真玻璃采样（旧实现把背景材质 .solid 传给窗口玻璃，卡片设置能关掉整窗玻璃）；Personalization 玻璃观感迁移只迁仍等于旧出厂默认（0.93/0.35/0.5/0.4）的项；降低透明度时两层半透明色层退化为一层不透明底。重复绘制层：刘海双黑幕（玻璃 tint 黑 0.32 与全幅黑幕 0.32 叠加、展开实际不透明度 0.54）改为黑幕只做收起 1→展开 0 过渡、深色程度由玻璃 tint=外壳通透度单独给出；刘海描边在系统折光时不叠仿玻璃亮边；主面板底部工具条去掉第二套整面层。性能：LiquidGlassBackground.updateNSView 补签名防抖（v282 同款）；FloatingPanel.applyPersonalizedMaterial 签名去掉「背景材质」。
- 修改后行为：设置与执行一致（滑块写 68% 通透就不再糊成灰毛玻璃）；切卡片材质不再重采样整窗玻璃；动画轨迹不变。
- 已确认结果 / 未确认事项：build.sh 完整构建部署；launch_smoke 冷启动通过；reconcile 全绿（4,350 函数）；改前/改后实机截图对比（主面板玻璃采样、刘海展开为深色玻璃、无双黑幕）。未确认事项：genie 预渲染 14–28ms、布局 77–148ms 为改前基线，本轮只动材质不动动画轨迹。
