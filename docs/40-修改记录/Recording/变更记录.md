## 重要变更条目
### 2026-11-20 在同一队列处理暂停与音视频写盘（14ab9c75）
- 需求/原因：「代码安全质量保证……代码整理、代码精简」，逐函数读取实际回调——写帧与结束轨道交叉风险。
- 涉及文件与关键函数：ScreenRecorder.swift——沿现有 stream 队列处理视频、两种互斥音频及暂停，去掉独立麦克风队列；首帧建立写入会话后才写音频；结束先在原管线队列停设备，再排至写入队列结束轨道并移交 writer。
- 修改后行为：暂停与写盘串行化，消除交叉写坏容器的窗口；首帧时间戳和暂停丢帧保留。
- 已确认结果 / 未确认事项：以真实录制保存验证。未确认事项：无。

### 2026-11-20 开始录制时保留已有目标文件（2b70007f）
- 需求/原因：「去一个一个查看，性能优化空间、死代码、未调用代码……把 Commit 写清楚、写详细」——准备写入器前的删除操作会误删已有录制。
- 涉及文件与关键函数：ScreenRecorder.swift——移除准备写入器前的删除操作；目录只创建一次并沿原错误出口报告失败；注册屏幕及音频输出成功后才准备写入器，同名编号保留。
- 修改后行为：开始录制不再删除既有目标文件；失败报告路径不变。
- 已确认结果 / 未确认事项：以正式构建及实际录制入口验证。未确认事项：无。

### 2026-11-20 异步读取编辑视频时长并复用素材（004c3562）
- 需求/原因：「性能优化空间……每完成一部分，清理一部分就提交一部分」——安装版保存后主线程停顿 5.9 秒。
- 涉及文件与关键函数：RecordingEditorWindow.swift、ScreenRecorder.swift——AVAsset.load(.duration) 异步加载时长，去掉主线程同步 duration；播放器使用同一已加载 AVAsset；沿 asset 身份丢弃过期结果。
- 修改后行为：保存后不再卡主线程；读取失败直接提示。
- 已确认结果 / 未确认事项：正式构建后实测。未确认事项：无。

### 2026-11-20 仅在叠加录制时准备合成资源（91424842）
- 需求/原因：「性能优化空间、死代码、未调用代码……代码整理、代码精简」。
- 涉及文件与关键函数：ScreenRecorder.swift——普通屏幕帧直接写入，不再创建像素缓冲适配器；CIContext 与颜色空间延迟至第一帧合成；摄像头、按键与点击的原合成入口保留。

- 已确认结果 / 未确认事项：由本批正式构建和实际录屏入口完成。未确认事项：无单独耗时对比。

### 2026-11-14 按展示对象收紧预览尺寸并恢复录屏完整画面（32f70f7b）
- 需求/原因：用户「部分预览界面大小不合理，需要一个一个截图尝试，站在 UIUX 设计师角度调整」；实测发现 Retina 素材被固定 960×540 范围裁切。
- 涉及文件与关键函数：RecordingAppearancePreview.swift 等（同批含 Personalization/Pin/Curtain/Search/CaptureAppearanceSample）——录屏合成按 CGImage 实际像素范围出图，指针/点击/按键采用对应像素倍率，删除固定 960×540 裁切；水印和录屏保留 480pt 可读宽度并居中。
- 修改后行为：录屏预览显示完整画面（Retina 不再被裁）；各预览尺寸按展示对象收紧。
- 已确认结果 / 未确认事项：真实构建，安装版逐页打开 9 个相关设置预览截图；录屏页发现问题后修改并重新构建复核。未确认事项：该提交跨 Settings/Recording，此处记 Recording 侧。

### 2026-11-08 1Capture C 档录屏五件套落地（a60aaf29）
- 需求/原因：对齐 1Capture 的录屏能力（B/C 档批次；录屏五件套为其中 C 档）。
