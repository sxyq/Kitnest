## 重要变更条目

### 2026-11-26 暂存截图清理复用文件时间
- 需求/原因：性能审阅发现目录裁剪的排序比较器会对同一 PNG 反复读取修改时间，排序结束后又读取一次。
- 涉及文件与关键函数：`Capture/Screenshot/ScreenshotManager.swift`（`pruneStagingDirectory`）。
- 修改后行为：枚举时每个 PNG 读取一次修改时间，排序和保留/删除判定共用该值；保留 200 张、硬上限 400 张及 3 天规则。
- 已确认结果 / 未确认事项：外置工作树全量类型编译待本轮完成；未安装运行版实测清理耗时。

### 2026-11-26 仅文本马赛克按开关预热
- 需求/原因：完整审阅发现编辑器无论是否启用「仅文本马赛克」都会预热 Vision 文本模型。
- 涉及文件与关键函数：`Capture/Annotation/AnnotationEditorWindow.swift`（`AnnotationCanvasView.init`）。

- 已确认结果 / 未确认事项：外置工作树全量类型编译待完成；首次启用交互待实机确认。

### 2026-11-24 截图链路四阶段重构：冻结与显示解耦、光标屏优先级、会话预算（v293）
- 需求/原因：用户「高负载下按快捷键数秒才进入截图」「多屏冻结时序」「不能因为 Kitnest 自己激活破坏还没冻结的画面」。49cd59ed 核实：① 第一块抓完即 `NSApp.activate + makeKeyAndOrderFront`，非镜像双屏下会改掉副屏尚未冻结的画面，且副屏先完成会抢键盘焦点；② 每条抓屏通道各自 4s，BMP→PNG→SCK 可串行叠加 12s；③ 覆盖层每次鼠标移动整屏填 35% 黑并重绘整屏 backing store；④ 每个覆盖层 init 都在主线程枚举一次全量窗口列表。
- 涉及文件与关键函数：`ScreenshotManager.beginCapture`（四阶段：冻结→建不可见窗→统一上屏→交互；删镜像特判）、`showOverlays`（新增，activate 一次 + 光标屏 key）、`makeOverlay`（新增）、`streamScreenSnapshots`（透传 budget，`onReady` 改 async 以在第一块冻结后取窗口列表）、`closeOverlays`（显式 `snapshot = nil`）、`ScreenSnapshot.CaptureBudget` + `captureScreenForScreenshot`、`NativeRegionCapture.captureScreenOnDisplay/run`（deadline + URL 直读解码）、`ScreenshotOverlayView`（冻结帧进 `CALayer.contents`、静态压暗层、`CAShapeLayer` 十字准线、`OverlayCanvas` 局部失效、提示排版缓存、`hitTest` 恒自身、`collectWindowHits` 会话级共享）。
- 修改后行为：全部屏幕冻结完成后才激活一次；光标屏 `makeKey`，其余 `orderFront`；覆盖层显示的是触发时冻结帧（激活不再改变用户看到的画面）；整轮共用一个 deadline，剩余不足 300ms 不再开 PNG 回退；BMP 不再 `Data(contentsOf:)` 多一次 14.7MB 拷贝。
- 已确认结果 / 未确认事项：`check.sh` 全量 typecheck PASS。**未确认**：真实首帧/可交互时延、双屏冻结时序、满载 20 样本、内存峰值与回落、黑屏率——需用户授权时段实测；`orderFront` 返回仍不得当作首帧。

### 2026-11-23 高负载截图响应提速与存储手势命中修正（86bd8c97）
- 需求/原因：用户原话「大幅降低高负载时从按下截图快捷键到截图选区真正可操作的延迟」+「参考 hub 的按需加载、增量更新、缓存复用和数据访问优化，降低 CPU、内存、磁盘 IO 与无效后台工作」。
- 涉及文件与关键函数：`Features/Capture/Screenshot/ScreenshotManager.swift`（采集通道、多屏抓取、图像校验、连按去重）；`Features/Monitor/Storage/StorageManagerWindow.swift`（存储手势命中区）。
- 修改后行为：采集通道由 PNG 输出改为 BMP（同帧 meanMaxDiff 0.01）；2560×1440 实测 389→204ms（空闲）、424→198ms（8 核满载），PNG 最慢 1487ms。多屏抓取并发化（并发度 2，光标所在屏优先，每屏冻结好立刻铺覆盖层）；双屏首块可交互 3365/3859→266ms（满载）。图像校验合并为一次 32×32（同时给出透明度与纯色结论）。连按快捷键由截图代次 + screencapture 可取消（30ms 轮询）防抢 WindowServer；已授权时跳过跨线程权限探测（10.4ms→4.9/0.0ms）。
- 已确认结果 / 未确认事项：build.sh 完整构建并原子部署；launch_smoke.sh 冷启动通过；函数表 4317 条、台账 4317 条、reconcile 全绿；空闲/满载两类场景各实测 1 次以上。
