### 2026-11-13 修复隐藏目录的模糊搜索漏项（ba81c700）
- 需求/原因：用户「当前的这个文件夹，它就搜不到，在主页的上面，就是状态栏点开的那个全局搜索里。然后其他这些也有部分搜不到……并完成修复」。
- 涉及文件与关键函数：Features/Toolbox/Search/FileNameIndex.swift、SearchSectionView.swift——按字节子序列扫描完整索引，移除 180ms 扫描截断、2500 条前部候选截断与长路径分档；目录路径展开 ~/、移除末尾 /。
- 修改后行为：隐藏目录可被模糊搜索命中；按正式模糊得分保留前 200 条候选；32 字符以上保留连续匹配；本机路径不显示或自动抓取网页结果。
- 已确认结果 / 未确认事项：真实 build.sh 构建并安装；安装版 imagehtmldeck / image html deck / 完整目录路径均显示 image-html-deck 目录；fileindex 入口扫描 1,240,856 条，目标查询 329.5ms（逐路径正则旧版 20,172.1ms 已改字节扫描）。未确认事项：无。
