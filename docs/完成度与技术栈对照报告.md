## 3. "体验一模一样"差距清单（按优先级）

**P0（核心体验）**
1. **行为对照 0/45**——`tests/行为对照表.md` 45 项全部未测。体验等价的验收动作本身还没跑，这是第一优先级。
2. 主面板条目**预览 Popover**（悬停看大图/全文）。
3. 菜单栏**通知条**（图标旁滚动提示，复制成功等场景）。
4. 设置窗口**「搜索」页签**（原作 5 页签之一；内容仅测绘到"搜索行为配置"一句，需注入钩子回查）。
5. **22 语言本地化**（.lproj × 22 实证；现为纯中文）。
6. 原作**快捷键默认绑定表**（待查 #7；现有用户录入体系就绪，缺默认值）。

**P1（高频可见）**
7. 长截图**自动滚动捕获 + 长图编辑器**（现仅手动多选拼接）。
8. 钉图**控制条 + 缩放 HUD + 小模式提示**。
9. 剪贴板大列表 **NSTableView 化**（顺带解锁右键 tracker/hover 抑制/顶部滚动 6 个交互类——见 §5 性能项）。
10. **统计窗 UI**（数据层已就绪）。
11. 权限引导窗（现内联 alert）。
12. 日历周折叠交互 + 2022-24 节假日。

**P2（低频/打磨）**
13. 外观管理（亮/暗/Midnight）。14. 欢迎窗/WhatsNew/评价请求。15. 图标彩蛋 + 设置页撒花。16. 工具编辑 UI（ToolEditSheet）。17. 划词翻译触发入口。18. 面板区段排序 + 更多菜单。

**有意的行为差异（记录在案，非缺陷）**
- 翻译：原版用系统 **Translation 框架**（otool 实证，macOS 15+），重建走 LLM——离线/在线体验不同，若要保真可补系统翻译路径。
- OCR Worker IPC：原版有独立 Helper（历史崩溃点），重建直连 Vision。
- TinyPNG：原版走在线 API，重建本地压缩。
- Pro/遥测/钥匙串：**从源头不存在**（优于原版的汇编补丁方案）。

## 4. 技术栈对比（原版二进制实证 vs 重建）

| 维度 | 原版 Frset 1.3.12 | 重建 FrsetNext | 评注 |
|---|---|---|---|
| 语言/运行时 | Swift（5.6+ ABI，`__swift56_hooks` 实证）+ Swift Concurrency 混合 GCD | Swift 5 模式 + 相同并发模型 | **同族** |
| UI | AppKit + SwiftUI 混用 | 相同 | 一致 |
| 数据流 | Combine `@Published`（Publisher 特化符号密集实证） | 相同 | 一致 |
| 数据库 | libsqlite3 直连（schema 已全）+ CoreData 链接（疑遗留） | libsqlite3 直连 | CoreData 未复刻（无使用证据） |
| 截图 | ScreenCaptureKit + CG | 相同 | 一致 |
| OCR | Vision + Worker Helper IPC | Vision 直连 | 有意取舍 |
| 翻译 | **Translation 框架 + NaturalLanguage**（系统级离线翻译） | LLM 翻译 | **行为差异**（见 §3-18） |
| 加密 | CryptoKit + Security（钥匙串，已被补丁中和） | AES-256-CBC + PBKDF2 文件（零钥匙串） | 按你的指令，**重建更干净** |
| 遥测/崩溃 | Sentry + PostHog + MetricKit | 无 | 按你的指令 |
| 商业化 | StoreKit + _StoreKit_SwiftUI | 无 | 按你的指令 |
| 架构/体积 | universal（x86_64+arm64）**29MB** | arm64 单架构 **5.6MB** | 重建轻 80% |
| 最低系统 | macOS 13.0 | macOS 13.0 | 一致 |
| 本地化 | 22 语言 | 中文 | 差距（§3-5） |
| 构建链 | Xcode（推断） | 裸 `swiftc` 脚本（本机无 Xcode） | 工程链差异，产物等价 |

**结论：技术栈与原版同族同构，无需换栈。** 重建在"干净度"上优于原版（零遥测/零 Pro/零钥匙串），在体积上轻 80%。

## 5. 性能分析与优化路线（具体可执行）

**先说基准**：原版同栈（Swift 原生），不存在"换栈能拿到的数量级收益"；性能差异只可能来自实现细节。参考基线：Stats.app（同类型菜单栏工具）在 M5 实测 **0.3% CPU / 43MB RSS**（`rea-evidence/perf-measurement-20261014-1212.txt`），这是我们的对标线。

| 优先级 | 优化项 | 现状 → 目标 | 预期收益 |
|---|---|---|---|
| **P1** | **OCR 检索索引化**：`ClipboardOCRTextStorage.matchingDedupeKeys` 现为磁盘有界扫描（≤2000 份 .txt） | 改 **SQLite FTS5 虚拟表**（ocr_text(dedupe_key, content)），写入时同步索引 | 剪贴板搜索从 O(n) 文件 IO → O(log n)；万级条目 <1ms |
| **P1** | **剪贴板大列表 NSTableView 化**：现 SwiftUI LazyVStack | 回归原作的 NSTableView 路线（spec 05 的行交互 6 类本就依赖 NSView 容器） | 万级条目滚动流畅度对齐原版；顺带补齐 6 个交互类 |
| **P1** | 搜索防抖 200-300ms（clipboard-audit 已建议） | `searchText` 逐键触发 reload + OCR 扫描 | 输入期 CPU 尖峰消除 |
| **P2** | 主线程磁盘 IO 异步化：AppNameResolver / 缩略图读取 | 已有缓存；改为后台队列 + 异步发布 | 滚动零卡顿 |
| **P2** | 监测采样与 UI 刷新对齐：采样 Timer 与状态项刷新合并调度 | 减少 wake 次数 | 电耗/空闲 CPU 向 Stats 0.3% 对齐 |
| **P3** | 图片缓存磁盘 LRU；`CGEventTap` 事件监听默认开启（有辅助功能权限时）替代 0.5s 轮询 | 轮询为兜底已极廉价（单 syscall） | 实时性 0.5s→即时 |

**明确不建议**：换 Tauri/Electron/跨端框架——会失去原版级原生体验（毛玻璃面板/全局热键/ pasteboard 语义），且体积/内存反而爆炸（Electron 空壳 ≈150MB）。当前栈就是性能上限最高的选择。

## 6. 收官路径（建议顺序）

1. **跑行为对照**（45 项，同机双开原版+重建）→ 差异回填 `tests/行为对照表.md`；

4. P1/P2 按 §3 顺序清缺口；
5. 每轮之后 `./tools/check.sh` 守门 + 重新打包冒烟。
