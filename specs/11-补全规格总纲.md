**方法论（specs/02 §4 已验证，照用）**：
1. **类型名 xref 法**：在 cstrings 里定位类型名字符串地址 → 在 disasm.txt 里找 `adrp xN, page` + `add xN, xN, #off` 引用 → 得类方法区 → 逐函数窗读；
2. **字符串考古**：中文 UI 文案/偏好键 → xref → 定位使用点（SwiftUI body 闭包/设置写入）；
3. **数据法**：`defaults read` 实测键值（热键表/开关默认值——**优先于反汇编**；已实测原作偏好域 `com.maoux.frset` 无热键绑定，默认表在代码常量）；
4. **四源对齐**：汇编 + defaults + 探针截图（`frset/rea-evidence/ui-probe/`、`final-test/`）+ 既有 schema。

**⚠️ 实测修正（2026-10-15，所有探索代理必读；含 re-clipboard/re-popover/re-settings 实战勘误）**：
- **类名（`__swift5_typeref` 段，mangled 形式）不经 adrp+add 引用**（Swift 类型元数据走相对指针）——xref 对类名 VA 无效。定位类区用：① 相邻 UI 文案锚点反查；② `frset/rea-evidence/tab-removal/` 的 `da.py`/`refs.py` 函数窗；③ **chained-fixup 解码公式**（specs/02 §3：`VA = raw & 0xFFFFFFFFF | 0x100000000`）解析 __objc_classlist/methodlist——re-popover 已实证。
- **一键工具 `/tmp/frset-re/xref.py`**：`python3 xref.py "文案" [--context N]` → 文本VA→代码地址→反汇编上下文。仅对 adrp+add 型引用有效。
- **中文 UI 文案不在二进制字符串段**（re-clipboard mmap 级验证：独立中文标签零 VA，二进制内中文仅 whatsNew/日志 9 句）——UI 文案在 `.lproj` 资源（键面=英文句，re-settings 实证 793 键）。抽法：`plutil -convert xml1 en.lproj/Localizable.strings`。
- **配套工具**（探索代理共建）：`/tmp/re14/stubs.py`（1188 条 ObjC stub→selref 映射——**otool -tvV 不含 __objc_stubs，选择器调用必须经它反查调用者**）、`/tmp/re14/strat.py`（虚拟地址读字符串）、`/tmp/keys.py`（Swift 小字符串 movz/movk 解码，≤15 字节键名不进字符串段）。
- **首批判定锚点（已实证）**：0x100b43d30 "单击或按空格预览"、0x100b43d10 "双击或按 ↩ 复制"、0x100b43da0/0x100b43d70（Frset 提示条）、0x100b57d50 "悬浮剪贴板交互调整为单击预览、双击粘贴。"——**主面板/悬浮窗交互为「单击预览、双击(↩)复制/粘贴」**，与重建版现行为（单击=复制）存在关键差异。
- **"支持双击快捷键唤起"（0x100b57910）= 双按可配置修饰键唤起**（DoubleTapModifier/DoubleTapShortcutDetector/AppKitDoubleTapMonitor 族，间隔常量 1000 推断 ms）——非菜单栏图标双击；菜单栏图标彩蛋归 specs/13。
