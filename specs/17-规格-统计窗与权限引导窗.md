## 0. 一句话结论

**统计窗**：`StatisticsWindowController`（SwiftUI + NSWindow 底座）呈现「概览大数字卡 + GitHub 式活动热力图（hover 延时 tooltip）+ 最近 30 天分解柱状图」三层版面，全部数据来自 `statistics.sqlite` 的 `usage_daily_metrics(day, event_name, count)`（ⓘ 页脚 "DATA IS STORED LOCALLY ON YOUR MAC" 强调本地）；埋点由 `StatisticsManager` 经专用串行队列 `com.frset.statistics.queue` 批量落库，事件全集 = **54 个枚举事件 + 5 个裸串事件**（§4 全清单）。**权限引导窗**：`PermissionWindowController` + `PermissionPromptModel` 在 6 类功能被权限阻断时弹出（划词翻译/粘贴到其他 App ×2/屏幕录制 ×2/划词工具快捷键 ×2/自动粘贴），提供「Enable（跳系统设置）」与「Maybe Later」两个动作，跳转实现为**新旧两套 `x-apple.systempreferences:` URL 级联 + `com.apple.systempreferences` bundle id 兜底**（0x1000b6400 实证）；日历权限不走此窗，走日历页内联提示。

## ⚠️ 重建版 schema 差异（必改项）

**重建版 `Database.swift` 的 `daily_stats(day, capture_count, screenshot_count, ocr_count, tool_count, ai_request_count)` + `bumpStat(column:)` 为早期臆测结构，与原作不符。** 原作为**事件名驱动的窄表**：

```sql
CREATE TABLE IF NOT EXISTS usage_daily_metrics (
    day TEXT NOT NULL,
    event_name TEXT NOT NULL,
    count INTEGER NOT NULL,
    PRIMARY KEY (day, event_name)            -- ON CONFLICT(day, event_name) 实证
);
CREATE TABLE IF NOT EXISTS app_meta (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL
);                                            -- 已知 key: 'install_date'
```

实现本规格时必须迁移：删 `daily_stats` 建表与 `bumpStat`，改 `AnalyticsEvent` 枚举 + `record(_:)`。证据：建表 SQL @0x100b53b80、app_meta 建表 @0x100b53c30、install_date 读写 @0x100b53e40/0x100b53e80。

## 5. 统计窗查询骨架（8 条 SQL → UI 映射）

```swift
// Q1 全量按事件总计 → __totalCounts [String:Int]
SELECT event_name, SUM(CASE WHEN count > 0 THEN count ELSE 0 END)
FROM usage_daily_metrics GROUP BY event_name;                                  -- @0x100b541e0

// Q2 指定日按事件 → __todayCounts（eventNames 为 metricConfigs 绑定的事件集）
SELECT event_name, CASE WHEN count > 0 THEN count ELSE 0 END
FROM usage_daily_metrics WHERE day = ? AND event_name IN (<joined>);           -- @0x100b54160

// Q3 活跃天数 → __activeDaysCount
SELECT COUNT(DISTINCT day) FROM usage_daily_metrics
WHERE event_name IN (<joined>) AND count > 0;                                  -- @0x100b540f0+0x100b54784

// Q4 每日总计（热力图 activityMatrix）→ [(day, total)]
SELECT day, SUM(CASE WHEN count > 0 THEN count ELSE 0 END) FROM usage_daily_metrics
WHERE day >= ? AND event_name IN (<joined>) GROUP BY day ORDER BY day ASC;     -- @0x100b53f90

// Q5 每日按事件（最近 30 天分解柱图）→ [(day, event, count)]
SELECT day, event_name, CASE WHEN count > 0 THEN count ELSE 0 END
FROM usage_daily_metrics WHERE day >= ? AND event_name IN (<joined>)
ORDER BY day ASC, event_name ASC;                                              -- @0x100b54040

// Q6 单事件总计（metricConfigs 单卡/tooltip）
SELECT COALESCE(SUM(CASE WHEN count > 0 THEN count ELSE 0 END), 0)
FROM usage_daily_metrics WHERE event_name = ?;                                 -- @0x100b53a10

// Q7 评分请求口径（reviewRequestUsage）
SELECT COALESCE(SUM(CASE WHEN count > 0 THEN count ELSE 0 END), 0)
FROM usage_daily_metrics WHERE event_name IN ('history_copy','screenshot_capture');  -- @0x100b53ef0

// Q8 导出全量 / 导入合并（事务）
SELECT day, event_name, count FROM usage_daily_metrics ORDER BY day ASC;       -- @0x100b53d00
INSERT INTO usage_daily_metrics (day, event_name, count) VALUES (?, ?, ?)
ON CONFLICT(day, event_name) DO UPDATE SET count = MAX(usage_daily_metrics.count, excluded.count, 0);  -- @0x100b53d50
```

`<joined>` = `Set<String>`（实例属性，self+0x30）转 Array 后 `joined(separator: ",")`（0x1006af368-0x1006af3d4 实证：`_$sSayxGSKsMc` Set→Array + `joined(separator:)`）。所有查询对 `count <= 0` 归零处理（`CASE WHEN count > 0`）。

**写入**：`record(event:)` → TimeZone.current + DateFormatter（**dateFormat = `yyyy-MM-dd`**，0x1006b1128 小字符串实证）→ `INSERT … VALUES(?,?,1) ON CONFLICT(day,event_name) DO UPDATE SET count = MAX(0, count)+1`（0x1006b1050）。

## 6. 权限引导状态机

```
功能动作 X（§3 矩阵之一）
  │ preflight：AXIsProcessTrusted / CGPreflightScreenCaptureAccess
  ├─ 已授权 → 正常执行
  └─ 未授权
      ├─ 屏幕录制链路：UserDefaults hasRequestedScreenRecordingPermission?
      │     ├─ false → 置 true（本次算"已请求"）→ 弹窗
      │     └─ true  → 弹窗（或降级为横幅态 ⬜）
      └─ 弹 PermissionWindow（258×268，styleMask 0x8003，§1c P6b）
            model.isVisible = true
            title = L10n(kind, feature)          # 实测文案见下表
            [启用 Enable]  → onEnable → openSystemSettings(kind)     # 0x1000b6400 级联
            [稍后再说 Maybe later] → onMaybeLater → onClose → isVisible = false
            appActivationObserver：用户从系统设置返回时复检
            ├─ 已授权 → onAuthorizationGranted → record(permission_granted) → 收窗
            └─ 未授权 → 保持/可重试
```
