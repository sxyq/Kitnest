## 4. 默认绑定表（全量 10 条）★核心产出

历史切片注册函数 0x1005c1094：遍历 10 个动作（枚举原始值 0..9，数组 @0x100c79b30 恒等映射），对每个动作：
1. 构造工具 id 字符串（switch @0x1005c11d8，块表 @0x100991b80）；
2. 与「已启用/已自定义」清单比对（0x1005c1308–0x1005c1338，`_stringCompareWithSmolCheck`）；命中 → 跳过（该工具由自定义注册路径接管）；
3. 未命中 → 内置默认 switch（0x1005c14b0）取 keyCode(w19)/modifiers(w20)，事件 id = `'FRST'(0x46525354) | id<<32`，`RegisterEventHotKey(key, mods, hotKeyID, GetApplicationEventTarget(), 0, &ref)` @0x1005c167c。

交叉验证：
- 语义自洽：⌥C=取色（Color）、⇧⌘V=悬浮剪贴板（粘贴语义）、⇧⌥* 组合避开 macOS 系统 ⇧⌘ 截图系列；工具 id 字面量表 @0x100afe16b 与各字符串构造块逐一吻合（`openFrset` 为编译器外提的枚举 0 常量，0x1005c11b8–0x1005c11cc 构造，0x1005c1300 直接收尾）。

### 4.1 当前安装版默认返回链（2026-10-15）

- 当前输入：`/Applications/Frset.app/Contents/MacOS/Frset` 的 arm64 薄片 `/tmp/Frset-cur-arm64` 与 `/tmp/frset-disasm-cur.txt`。
- `0x10076ab0c` 是快捷键页面本地化分支；相邻 `0x10076ab24` 构造截图动作显示行。取值链为 **`0x10076b0e0 → 0x1006a7e40 → 0x1006a7a5c`**，末函数读取用户覆盖或返回默认键码/掩码。

## 5. 运行时分发链

```
[注册期]（App 启动，swift_once 初始化：token 0x100c84860 / 0x100c88a60）
  ToolShortcutManager
  ├─ 0x1005c1094  对 10 工具逐个：id ∉ 已自定义清单 → RegisterEventHotKey(默认表, id 1..11)
  │               （先 bl 0x1005c0e34 注销旧注册；三处 UnregisterEventHotKey @0x1005c0ecc/f88/fe8）
  ├─ 0x1005c1844  CGEventTapCreate(kCGSessionEventTap=1, headInsert=0, listen=1,
  │               mask=0x1C00 keyDown|keyUp|flagsChanged) → CFMachPort + 主 RunLoop Source
  │               → CGEventTapEnable(true)          [回调 0x1005c2ed0→0x1005c38e0]
  └─ 0x1005c1d94  读自定义绑定（defaults 键 toolShortcuts）：每条
                  counter=[obj+0x28]（上限 0x3E8=1000，溢出回卷 1000）→
                  RegisterEventHotKey(key, mods, 'FRST'|counter<<32) @0x1005c2248；
                  注册成功 → counter+1 回写（自定义热键 id 从 1000 起递增）

[运行期]
  Carbon 事件（kEventClassKeyboard/kEventHotKeyPressed）
  → 处理器 0x1005c336c（断言锚点 Frset/ShortcutRuntimeCoordinator.swift）
     GetEventParameter('----'/'dhik' = EventHotKeyID, 8B) @0x1005c3414
     ├─ id ≥ 1000：bl 0x1005c3c4c —— UserDefaults 反查自定义绑定（objectForKey→String 桥接）
     └─ id < 1000：内置表直配
  → DispatchQueue.main / MainActor Task（swift_task_create，两闭包 0x1005c2d84 / 0x1005c2850）
  → id→行为分发 0x1005c2ca0：w0∈{−2,−1}→0x1005c19b4（重启 CGEventTap+重置行为枚举=3）；
     id∈{10,11}→0x1005c2bf4；id=12→0x1005c2a70
  → ToolShortcutExecutionCoordinator（实例键 _toolShortcutExecutionCoordinator）执行对应工具

  CGEventTap 路径（键事件）：0x1005c38e0 读 kCGKeyboardEventKeyCode(field 9)/flags/timestamp
  → 与 Carbon 路径汇合至 0x1005c3660（同一打包格式 sig|value<<32）→ 同上分发
```

组合冲突处理：⬜ 未探明（见 §8）。已知结构性事实：自定义注册走独立 id 空间（≥1000）且先注销后重注册（0x1005c0e34；UnregisterEventHotKey ×3）；同一函数内 `swift_isUniquelyReferenced_nonNull_native` + 数组增删（0x1005c1684–0x1005c1710）暗示注册表条目在册即替换。

## 9. 行为对照条目（供 tests/行为对照表.md 记录）

下列为原版期望行为，本轮均未新做实测；与 §7 当前实现状态分开阅读。
