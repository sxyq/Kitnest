## 4. 默认绑定表（全量 10 条）★核心产出

注册函数 0x1005c1094：遍历 10 个工具（枚举原始值 0..9，数组 @0x100c79b30 恒等映射），对每个工具：
1. 构造工具 id 字符串（switch @0x1005c11d8，块表 @0x100991b80）；
2. 与「已启用/已自定义」清单比对（0x1005c1308–0x1005c1338，`_stringCompareWithSmolCheck`）；命中 → 跳过（该工具由自定义注册路径接管）；
3. 未命中 → 内置默认 switch（0x1005c14b0）取 keyCode(w19)/modifiers(w20)，事件 id = `'FRST'(0x46525354) | id<<32`，`RegisterEventHotKey(key, mods, hotKeyID, GetApplicationEventTarget(), 0, &ref)` @0x1005c167c。

修饰键为 Carbon 掩码：optionKey=0x800、shiftKey=0x200、cmdKey=0x100、controlKey=0x1000。

|---|---|---|---|---|---|---|---|

交叉验证：
- 语义自洽：⌥C=取色（Color）、⇧⌘V=悬浮剪贴板（粘贴语义）、⇧⌥* 组合避开 macOS 系统 ⇧⌘ 截图系列；工具 id 字面量表 @0x100afe16b 与各字符串构造块逐一吻合（`openFrset` 为编译器外提的枚举 0 常量，0x1005c11b8–0x1005c11cc 构造，0x1005c1300 直接收尾）。
- `onboardingOpenFrsetHotKeyTriggered`（0x100770094 引用）证明「呼出 Frset 热键」是独立引导事件 → `openFrset` = 呼出主面板。
- 每条 id 与 t2 跳转表、直跳路径双源一致（§3.2）。

事件 id 语义：`< 1000` 为内置默认/预置绑定（1–11）；`≥ 1000` 为用户自定义（见 §5）。**id 10 在默认表中未出现**（分发器 0x1005c2ca0 另有 id 10/11/12/−1/−2 分支，见 §9）。

## 5. 运行时分发链

```
[注册期]（App 启动，swift_once 门控：token 0x100c84860 / 0x100c88a60）
  ToolShortcutManager
  ├─ 0x1005c1094  对 10 工具逐个：id ∉ 已自定义清单 → RegisterEventHotKey(默认表, id 1..11)
  │               （先 bl 0x1005c0e34 注销旧注册；三处 UnregisterEventHotKey @0x1005c0ecc/f88/fe8）
  ├─ 0x1005c1844  CGEventTapCreate(kCGSessionEventTap=1, headInsert=0, listen=1,
  │               mask=0x1C00 keyDown|keyUp|flagsChanged) → CFMachPort + 主 RunLoop Source
  │               → CGEventTapEnable(true)          [回调 0x1005c2ed0→0x1005c38e0]
  └─ 0x1005c1d94  读自定义绑定（defaults 键 toolShortcuts）：每条
                  counter=[obj+0x28]（上限 0x3E8=1000，溢出回卷 1000）→
                  RegisterEventHotKey(key, mods, 'FRST'|counter<<32) @0x1005c2248；
                  注册成功 → counter+1 回写（自定义热键 id 从 1000 起递增）

[运行期]
  Carbon 事件（kEventClassKeyboard/kEventHotKeyPressed）
  → 处理器 0x1005c336c（断言锚点 Frset/ShortcutRuntimeCoordinator.swift）
     GetEventParameter('----'/'dhik' = EventHotKeyID, 8B) @0x1005c3414
     ├─ id ≥ 1000：bl 0x1005c3c4c —— UserDefaults 反查自定义绑定（objectForKey→String 桥接）
     └─ id < 1000：内置表直配
  → DispatchQueue.main / MainActor Task（swift_task_create，两闭包 0x1005c2d84 / 0x1005c2850）
  → id→行为分发 0x1005c2ca0：w0∈{−2,−1}→0x1005c19b4（重启 CGEventTap+重置行为枚举=3）；
     id∈{10,11}→0x1005c2bf4；id=12→0x1005c2a70
  → ToolShortcutExecutionCoordinator（实例键 _toolShortcutExecutionCoordinator）执行对应工具

  CGEventTap 路径（键事件）：0x1005c38e0 读 kCGKeyboardEventKeyCode(field 9)/flags/timestamp
  → 与 Carbon 路径汇合至 0x1005c3660（同一打包格式 sig|value<<32）→ 同上分发
```

冲突裁决：⬜ 未探明（见 §9）。已知结构性事实：自定义注册走独立 id 空间（≥1000）且先注销后重注册（0x1005c0e34；UnregisterEventHotKey ×3）；同一函数内 `swift_isUniquelyReferenced_nonNull_native` + 数组增删（0x1005c1684–0x1005c1710）暗示注册表条目在册即替换。

## 7. 源码骨架（衔接重建 Toolbox/ShortcutManager.swift）

```swift
// 原作语义还原（重建侧落到现有 ShortcutRegistry + 新增 ToolShortcutManager）

enum ToolShortcut: String, CaseIterable {           // id 字面量表 @0x100afe16b
    case openFrset, screenshot, colorPicker, openAndSearch, floatingClipboard
    case screenshotOCR, screenshotTranslate, screenshotCopy, screenshotPin
    case translateSelection                                         // id 11；id 10 缺省未用
}

struct ToolShortcutDefaults {                        // 常量表（0x1005c14b0 switch）
    // (tool, keyCode, modifiers, hotKeyID) —— hotKeyID = 'FRST' | n<<32
    static let table: [ToolShortcut: (UInt32, UInt32, UInt32)] = [
        .openFrset:            (0x00, 0x800, 3),   // ⌥A
        .screenshot:           (0x01, 0x800, 1),   // ⌥S
        .colorPicker:          (0x08, 0x800, 2),   // ⌥C
        .openAndSearch:        (0x03, 0x800, 4),   // ⌥F
        .floatingClipboard:    (0x09, 0x300, 5),   // ⇧⌘V
        .screenshotOCR:        (0x01, 0xA00, 6),   // ⇧⌥S
        .screenshotTranslate:  (0x11, 0xA00, 7),   // ⇧⌥T
        .screenshotCopy:       (0x08, 0xA00, 8),   // ⇧⌥C
        .screenshotPin:        (0x23, 0xA00, 9),   // ⇧⌥P
        .translateSelection:   (0x02, 0xA00, 11),  // ⇧⌥D
    ]
}

final class ToolShortcutManager {                    // 注册期
    // 1) 逐工具：若 defaults["toolShortcuts"] 已含该工具 → 跳过默认注册
    // 2) 否则 RegisterEventHotKey(默认表) @ GetApplicationEventTarget，id = 默认表 n
    // 3) 自定义绑定：hotKeyID 自 1000 递增（上限 1000 溢出回卷），签名 'FRST'
    // 4) CGEventTap(mask 0x1C00, listen-only) 挂主 RunLoop —— 补充键监听
}

final class ShortcutRuntimeCoordinator {             // 运行期（Carbon 处理器）
    // GetEventParameter → EventHotKeyID
    // id ≥ 1000 → defaults 反查自定义绑定；否则内置表 id → ToolShortcut
    // DispatchQueue.main / @MainActor Task → ToolShortcutExecutionCoordinator.execute(tool)
}
```

重建衔接点：现 `ShortcutManager.swift` 已有 Carbon 注册/重绑/冲突框架 —— 需新增：① `ToolShortcutDefaults` 常量表 + 启动批量注册（跳过已自定义工具）；② id 双空间（默认 1..11 / 自定义 ≥1000）与 `'FRST'` 签名一致；③ `ToolShortcutExecutionCoordinator` 接收枚举分发；④ EnablePrompt/两 tip 的 UserDefaults 门控。

## 9. 行为对照条目（回填 tests/行为对照表.md 用）

1. 出厂态（defaults 无 `toolShortcuts`）下，10 个工具快捷键为内置默认表：⌥A 呼出主面板、⌥S 截图、⌥C 取色、⌥F 打开并搜索、⇧⌘V 悬浮剪贴板、⇧⌥S 截图OCR、⇧⌥T 截图翻译、⇧⌥C 截图复制、⇧⌥P 截图钉图、⇧⌥D 划词翻译。
2. 用户自定义过的工具不再注册默认绑定（注册期按已自定义清单跳过），其绑定由 `toolShortcuts` 恢复并占用 ≥1000 的独立热键 id 空间。
3. 热键触发经 MainActor 异步派发（非处理器内联执行），UI 操作不阻塞 Carbon 事件线程。
4. EnablePrompt 启用引导卡片全生命周期仅出现一次（`hasPresentedToolShortcutEnablePrompt_v1` 一次性写入）。
5. 划词首次执行提示：仅首次出现，easeOut 0.16s 动画；消费后写 `hasSeenSelectedTextExecutionTip=true`。
6. 双击快捷键首次提示同套路（`hasSeenDoubleTapShortcutTip_v1`）。
7. 热键签名 'FRST'（0x46525354），与重建 ShortcutManager.swift 的 signature 常量一致。
