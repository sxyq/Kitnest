## 2. 数据模型（schema 实测，重建直接对齐）

### 2.1 Swift 模型（与 SQL 字段一一对应）
```swift
struct ClipboardItem: Codable, Identifiable {
    let id: String                      // UUID 字符串
    let type: ClipboardItemType         // text / image / file / richtext (推断枚举)
    var content: String?                // 短文本内联
    var title: String?                  // 卡片标题
    var subtitle: String?               // 副标题（来源/尺寸等）
    let timestamp: Date                 // REAL epoch
    let sourceApp: String?              // 来源应用（bundle id 或名）
    let imagePath: String?              // 图片文件（App Support 相对路径）
    let thumbnailPath: String?          // 缩略图
    let isGeneratedByTool: Bool         // 工具生成（工具箱产物回流）
    let isNote: Bool                    // 笔记标记（笔记=特殊剪贴板条目）
    let sourceToolAnalyticsId: String?  // 工具来源追踪
    let sourceToolKeyword: String?
    let textPath: String?               // 长文本落盘路径
    let richTextPath: String?           // 富文本落盘
    let fullTextCharCount: Int?         // 长文本元数据
    let fullTextLineCount: Int?
    let sourceInput: String?            // 生成来源输入（工具/翻译）
    let fileIconKey: String?            // → file_type_icons
    let imageDimensionUnit: String?     // 图片尺寸单位
    let payloadKey: String?             // 通用载荷键
    let storageBytes: Int               // 存储占用
    let dedupeKey: String               // 去重键（UNIQUE）
    var aliasTitle: String?             // 重命名标题
}
struct Tag: Codable { let id: String; var name: String; var colorHex: String
                      let createdAt: Date; var updatedAt: Date }
```

### 2.2 SQL（重建原样复用，已实测）
```sql
clipboard_items( id PK, type, content, title, subtitle, timestamp REAL,
  source_app, image_path, thumbnail_path, is_generated_by_tool INT, is_note INT,
  source_tool_analytics_id, source_tool_keyword, text_path, rich_text_path,
  full_text_char_count, full_text_line_count, source_input, file_icon_key,
  image_dimension_unit, payload_key, storage_bytes INT DEFAULT 0,
  dedupe_key UNIQUE, alias_title )
索引：timestamp DESC / (type,timestamp) / (is_generated_by_tool,timestamp) / (is_note,timestamp)
tags( id PK, name, color_hex, created_at, updated_at ) + UNIQUE(name NOCASE)
clipboard_item_tags( item_dedupe_key, tag_id, created_at ) PK 复合 + FK 级联
file_type_icons( icon_key PK, handler_bundle_id, icon_path, updated_at )
paywall_unlocked_items( dedupe_key PK, unlocked_at )   -- 历史遗留，可丢弃
```

## 3. 行为清单

| # | 行为 | 细节（推断标注） |
|---|---|---|
| B1 | 捕获 | 轮询 NSPasteboard.changeCount（或事件触发）；取"最新一项"；多类型优先级：图片 > 文件 > 富文本 > 文本 > URL |
| B2 | 去重 | `dedupe_key` 计算（推断=类型+内容哈希/文本摘要）；UNIQUE 约束兜底；重复项可能更新时间戳置顶 |
| B3 | 入库 | DatabaseManager 事务写入；长文本（超过阈值）落盘 `text_path`，字段存元数据 |
| B4 | 缩略图 | 图片生成 thumbnail_path（ImageIO） |
| B5 | 清理 | 双调度：时间保留期（免费/Pro 档已除，用满档）+ 容量上限；清理时同步删文件+DB 行 |
| B6 | 标签 | 创建（名+色）/分配/按标签过滤；`is_note=1` 的笔记条目也走此表 |
| B7 | 编辑 | 独立编辑窗；编辑会话并发安全（`ClipboardItemEditSession`）；保存更新 content/alias_title |
| B8 | 浮动窗 | 独立置顶小窗（240×290 实测），位置持久化 `floatingClipboard.originX/Y/width/height` |
| B9 | AI 摘要 | 对选中条目调用 LLM（见 09 号规格），结果以新条目/编辑形式呈现 |
| B10 | 工具回流 | 工具箱产物以 `is_generated_by_tool=1` 进历史（可过滤） |
| B11 | 搜索 | 文本检索（content/title/alias_title/OCR 文本），高亮命中 |
| B12 | 每日统计 | `last_clipboard_capture_date` + statistics.sqlite 埋点 |
| B13 | 大文本预览 | Markdown/JSON 高亮渲染（`Preview*PreferenceStore` 控制渲染开关） |
