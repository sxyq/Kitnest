# A. 工具箱（ToolManager 体系）

## A.1 类清单
`ToolManager`（注册/执行）｜`ToolManagementView/Row`（列表 UI）｜`ToolEditSheet`（编辑）｜
`ToolCustomConfig` / `ToolCommandDescriptor` / `ToolOperationMode` / `ToolSettings` / `ToolExecutionSource`｜

## A.2 具体工具
| 工具 | 类群 | 行为 |
|---|---|---|
| 时间戳转换 | `TimestampTool`/`Converter`/`Settings`/`Precision`/`OutputType` | Unix ↔ 日期；秒/毫秒/纳秒精度 |
| IP 查询 | `IPAddressTool`/`PresentationState`/`UsageTracker`/`AnchorView` | 本机/公网 IP |
| TinyPNG | `TinyPNGWindowController`/`WorkerClient`/`TaskViewModel`/`OutputDirectoryStore`/`ThumbnailCache` | 图片压缩（网络 API + 缩略图缓存） |
| 代码预览 | `CodePreviewScrollView`/`AxisLockView` | 代码渲染预览 |
| 变量名转换 | `VarNameSettings`(+转换器) | camel/snake/pascal… |
| 翻译 | `TranslationToolSession`（→09 号） | 划词翻译 |
| 自定义 AI 工具 | `CustomAIToolStore`（→09 号） | 用户提示词工具 |

# D. 钉图（8 类）

`PinnedScreenshotManager`｜`PinnedScreenshotWindow`+`ContentView`｜`ControlsWindow`/`ControlsHostView`｜`SmallCloseButton`｜`ScaleMenuButton`+`ScaleHUD`｜`SmallModeTipWindow`

行为：截图/图片钉在屏幕（置顶窗，可移动/缩放/关闭）；缩放 HUD；缩略小模式。骨架=NSWindow(.borderless, .floating) + 拖拽缩放。

# E. 取色器（5 类）

`ColorPickerManager`｜`ColorPickerWindow`｜`ColorPickerOverlayView`｜`ColorPickerMagnifierView`（+源文件 `ColorPickerMagnifierView.swift`）

行为：全局取色（吸管）→ 放大镜像素取点 → 复制色值（HEX/RGB）。骨架=overlay+`CGDisplayCreateImage` 像素读取。
