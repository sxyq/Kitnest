## 5. 外观四态实现（探明问题 ②）

- 生效范围：全窗（NSApp.effectiveAppearance + SwiftUI preferredColorScheme 双通道）〔⬜ 悬浮剪贴板/钉图等子窗是否跟随未逐窗验证〕。

## 7. SettingsRouter 与辅助管理器（探明问题 ④）

### 7.1 路由
- `SettingsRoute`（enum，RawString）：`general / search / tools / shortcuts / about`（+`pro` 残留 case，UI 已不可达）；子路由 `aiProviders / toolSettings / customAITool / tagManagement`（反射串簇 @0x100afb240-0x100afb29e）。
- 页内跳转场景清单：
  1. 通用页「AI 服务商 → 管理」按钮 → `.aiProviders`（截图：管理按钮 + "1 个服务商"；lproj 'AI provider'）；
  2. 工具页工具行 → `.toolSettings`（时间戳/变量命名等工具设置，"Timestamp Settings"/"Variable Naming Settings"）；
  3. 工具页自定义 AI 工具 → `.customAITool`（`customAITools` 键簇 @0x100b4dbc1）;
  4. 通用页「标签管理 → 编辑」→ `.tagManagement`（TagManagementNameField 类名 @0x100ace000）；
  5. 快捷键页（由 Toolbox 模块供数据，见重建 SettingsModule 注记）。
- 实现：`@Published var route: SettingsRoute?` + 窗口内容 switch；子路由以 sheet/导航切换〔⬜ 原作切换动画/返回方式未逐帧验证〕。
